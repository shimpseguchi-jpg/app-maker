# ことづてむら 試作（M0）の手順書

「ことづてむら」を作り始める前に、**学校の iPad と学校のアカウントで動くかどうか** を確かめるための小さな試作です。
ゲームではありません。7つのことを1つずつ試し、結果を自動でスプレッドシートに残します。

| | 確かめること | ○ なら | × なら（作りをこう変える） |
|---|---|---|---|
| 1 | 開いた子どもの、学校のアカウントが分かるか | 子どもを自動で見分けられる | 最初の1回だけ「組と番号」を選ぶ方式にする |
| 2 | iPad の中に、続きのデータを保存できるか | 途中でやめても続きから遊べる | 毎回スプレッドシートから続きを読みこむ |
| 3 | 読み上げの声が鳴るか | 問題文の 🔊 が使える | 録音した声を入れる |
| 4 | カメラで紙を撮って送れるか | 紙に書いた文を写真で送れる | 紙は「書いた」記録だけにする |
| 5 | 画面に指で字を書いて送れるか | 手書きで送れる | 手書きはなくし、紙とキーボードにする |
| 6 | カードを指で動かして並べられるか | カードを並べる遊びができる | タップだけで並べる操作にする |
| 7 | クラス全員が同時に送っても、記録が欠けないか | 授業で一斉に使える | 送るときに少しずつずらす |

かかる時間：準備 20分（パソコン）、先生が1台で試す 10分、クラスで試す 5分。

## はじめに確かめること

- 学校で **Google Workspace（学校の Google アカウント）** を使っていること
- 子どもの iPad の Safari が、**学校のアカウントでログインしたまま** になっているか（分からなければ ICT 担当の先生に聞いてください。ログインしていない iPad では、開くとログインの画面が出ます。それも大事な結果です）
- 学校・自治体の決まりで、次のことをしてよいか
  - 先生の Google ドライブに、**スプレッドシート1つ**（記録）と **フォルダ1つ**（試しに撮った写真と手書き）を作る
  - 子どものメールアドレスは **先頭の2文字とドメインだけ**（例：`ab…@school.ed.jp`）を記録に残す。名前は扱わない
  - 写真は **紙だけ** を写す（顔や名前が写らないようにする）
  - 試し終わったら、ぜんぶ消す（いちばん下の「あとかたづけ」）

## 準備（パソコンで1回だけ）

1. **学校の Google アカウント** でログインしたブラウザで https://script.google.com を開き、「新しいプロジェクト」を押す
   - 左上の「無題のプロジェクト」を押して、名前を「ことづてむら 試作」に変える
2. 最初からある `コード.gs` の中身をぜんぶ消して、[`Code.gs`](Code.gs) の中身を貼る
   - GitHub で `Code.gs` を開き、右上のコピーのボタン（Copy raw file）を押すと、中身をまるごとコピーできる
3. 左の「ファイル」の **＋** →「HTML」を押し、名前を **`m0`** にする（`.html` は自動でつく）
   - 中身をぜんぶ消して、[`m0.html`](m0.html) の中身を同じようにコピーして貼る
4. 保存する（💾 のボタン、または Ctrl+S / ⌘+S）
5. 上のほうにある関数を選ぶところで **`setup`** を選び、「実行」を押す
   - 「承認が必要です」と出たら「権限を確認」→ 自分の学校アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たときは「詳細」→「ことづてむら 試作（安全ではないページ）に移動」
   - 「許可」を押す。許可するのは次の3つです。このスクリプトが自分で作ったもの以外のファイルにはさわりません
     - スプレッドシートを作って、記録を書く
     - ドライブにフォルダを作って、画像を入れる
     - 開いた人のメールアドレスを見る（1 を確かめるため）
   - 学校の設定で止められて進めないときは、ICT 担当の先生に相談してください（それも大事な結果です）
6. 下に出る「実行ログ」に、**スプレッドシート** と **しゃしんのフォルダ** の URL が出る。スプレッドシートを開いておく
   - 中に「けっか」と「どうじ」の2つのシートがある
7. 右上の「デプロイ」→「新しいデプロイ」→ 種類の選択（⚙️）で「ウェブアプリ」
   - 説明：`試作`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**「（学校・自治体名）内の全員」**（「全員」にはしない。1 が確かめられなくなるため）
   - 「デプロイ」を押す
8. 出てきた **ウェブアプリの URL**（`…/exec` で終わる）をコピーする
   - 先生が1台で試すとき：そのままの URL
   - クラスで試すとき：URL の最後に **`?mode=class`** をつけたもの（例：`https://script.google.com/a/macros/…/exec?mode=class`）
9. 子どもの iPad に URL を届ける（Google Classroom に投稿するのがいちばんかんたん）

## 試す1：先生が1台で（10分）

**子どものアカウントでログインしている iPad** で、そのままの URL を開きます（先生のアカウントで開くと、1 で「子どものアカウントが分かるか」を確かめられないため）。
iPad は横向きにして、上から順に試します。各項目の右に ○ か × が出て、スプレッドシートの「けっか」シートにも1行ずつ増えます。

| | すること | 見るところ |
|---|---|---|
| 1 | 開くだけ | 子どものアカウント（メールアドレス）が出れば ○ |
| 2 | 開くだけ | 「ひらいた かいすう：1 かいめ」と出れば ○。**次の日にもう一度開いて、2 かいめ になるか** も見てください |
| 3 | 音を大きくし、消音を切ってから「🔊 よむ」→「きこえた」か「きこえない」 | 声の速さや聞きとりやすさもメモしてください |
| 4 | 紙に「ねこ」と書き、「📷 しゃしんを とる」で撮る | 「おくれた！」と出れば ○。カメラが開かなければ「カメラが ひらかなかった」を押す |
| 5 | マス目に指で「ねこが」と書いて「📨 おくる」 | 「おくれた！」と出れば ○。書けなければ「かけなかった」を押す |
| 6 | カードを指で動かす・タップして、文を作る | 「せいかい！」と出れば ○。動かせなければ「うごかせなかった」を押す。**1年生が自分でできるか** も見てください |
| 7 | 「1けん おくる」を押す | 「1 / 1 とどいた」と出れば ○ |

できれば、子どもに 4〜6 をやってもらい、迷ったところをメモしてください。

## 試す2：クラス全員で（5分）

1. 全員の iPad で、**`?mode=class` をつけた URL** を開いてもらう
   - 「せーの」で全員いっしょに開くと、授業の始まりに一斉に開いたときの様子も確かめられます
   - 開けなかった子がいたら、人数と出た画面（ログイン画面・エラーなど）をメモしてください
2. 全員の画面に大きな「せーので おす」が出たら、「せーの」の合図で同時に押してもらう
3. 少し待つと、子どもの画面に大きく ○ か × が出る
   - 送れなかったときは、自動で何度か送り直します（最長40秒ほど）
4. 先生の iPad（そのままの URL の画面）の 7 で、押してから3分以内に「**まとめを みる**」を押す
   - 「iPad ◯だい・◯けん とどいた」と出ます。**押した子の人数と同じ** なら ○ です
   - 「おくりなおし」の数が多いときは、同時に送れる数の上限に当たっています（送り直しで全部とどいていれば問題ありません）

余裕があれば、先生の画面の「5けん おくる」も試してください（1台から5件を同時に送る、きびしめの試しです）。

## 結果の送りかた

- スプレッドシートを、開発者に **閲覧者** として共有するか、画面の写真を送ってください
  - スプレッドシートには、子どものメールアドレスの一部（先頭2文字とドメイン）、iPad の番号（ランダムな文字）、iPad の情報（機種やブラウザの種類）が入っています。名前は入っていません
  - 学校の決まりで共有できないときは、上のメモだけで十分です
- **しゃしんのフォルダは共有しないでください**。開発者には、画像の大きさと送るのにかかった時間が分かれば足ります（スプレッドシートに残っています）

## あとかたづけ

1. Apps Script の画面で「デプロイ」→「デプロイを管理」→ 試作のデプロイを選んで「アーカイブ」（URL が使えなくなります）
2. ドライブで、スプレッドシート「ことづてむら 試作（M0）けっか」とフォルダ「ことづてむら 試作（M0）しゃしん」をごみ箱に入れる
3. https://script.google.com で、プロジェクト「ことづてむら 試作」をごみ箱に入れる

## 開発者むけ

- `Code.gs`：サーバー側。`setup` でスプレッドシートとフォルダを作り、ID をスクリプト プロパティに覚える。画面から呼ぶのは `whoami` `saveCheck` `saveImage` `burst` `burstSummary` の5つ（名前が `_` で終わる関数は画面から呼べない）
- `m0.html`：画面。依存ライブラリなし。1つのファイルなので、ビルドせずにそのまま GAS に貼れる
- 送れなかったときは 1・2・4・8・16秒（＋ばらつき）待って、最大6回まで送り直す。GAS は1つのアカウントで同時に動かせるのが30件までで、「自分として実行」では全員の分が先生1人に数えられるため
- テスト：`node kotozute/tools/test_m0.mjs`（Playwright が必要）。GAS のかわりの「にせもの」（スプレッドシート・ドライブ・`google.script.run` をメモリの中で動かすもの）の上で、`Code.gs` と `m0.html` を同じページで動かし、1〜7 とクラス用の画面をひととおり確かめる
