# ことづてむら

小学1年生むけの、**文を組み立てる力** を伸ばすゲームです（開発準備中）。
どうぶつの村のたのまれごとを、ことばカードで文にして届けます。最後は自分で書きます。
学校の iPad で、Google Apps Script のウェブアプリとして使う前提です。

- 光村図書（1年）の単元の時期とねらいに合わせた13の章
- 先生は、クラス全員の記録と書いた文を Google スプレッドシートで見られる

要件定義は [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md)、キャラクターと各章のたのみごとは [`docs/DESIGN.md`](docs/DESIGN.md)。

## 今あるもの

- [`m0/`](m0/README.md)：**試作（M0）**。作り始める前に、学校の iPad と学校のアカウントで動くかを先生に確かめてもらうための小さなウェブアプリと手順書（アカウント・保存・読み上げ・カメラ・手書き・カード・クラス全員で同時に送る、の7つ）

## テスト

```sh
node kotozute/tools/test_m0.mjs   # 試作を GAS のかわりの「にせもの」の上で動かして、ひととおり確かめる（Playwright が必要）
```
