# せかいの どこかに うまれたら

小学1〜3年生むけの「世界のどこかに生まれて、その国の暮らしを体験する」ゲームです。
いま生まれてくる赤ちゃんの一人として、**実際の出生数に比例した確率** で世界 193 か国のどこかに生まれ、0さいから **その国で大人になる年齢**（多くの国は18さい。韓国19・タイ20・エジプトとインドネシア21）までを体験し、最後にその後の進学・仕事・人生をみじかく読んで終わります。
ブラウザだけで動きます（ビルド不要）。iPad・スマホの縦横どちらでも遊べます。

> 「80億分の1」（1in8b.life）の「統計どおりに世界のどこかに生まれる」というアイデアから着想した、**オリジナル** の子ども向け作品です。
> 元の作品のコード・文章・絵は使っていません。病気・事故・戦争・死など、低学年には重い出来事は扱いません。

## 「80億分の1」へのオマージュ

元の作品のコード・文章・絵は使わず、遊びのしくみだけを子ども向けに取り入れています。

- **えらべるのは「うまれる」ことだけ**：国・おとこのこ/おんなのこ・名前（その国によくある名前）・まち/いなか（都市人口の割合）・きょうだいの何番目 が決まる
- **うまれる かくりつ と めずらしさ**：「1,000人に5人」のような確率と★1〜5。「きょう この国で生まれた赤ちゃんは約○人」
- **年齢で変わるアイコン**：👶 → 👦👧 → 🧑 → 👨👩 → 👴👵
- **おまかせ（神の視点）**：タイトルで「おまかせ」をオンにすると、選択もすすむのも自動。はやさ 1・2・4ばい
- **じんせいの きろく**：0さいからの出来事を年齢つきで記録し、最後に一覧で表示。「きろくを コピー」で共有用の文章をコピー
- **これまでの じんせい**：過去30回分の人生をタイトルから見返せる
- **いのちも統計どおり**：その国・男女の生命表で何歳まで生きるかが決まる。こどものうちに亡くなる人生もある（死因は「びょうき」「じこ」「としを とって」だけ。戦争・暴力・自殺は描かない）。保護者ページの「やさしい モード」で、成人まで亡くならないようにできる

## 統計にもとづく人生のしくみ

うまれたときに、その国の統計の割合で次のことが決まります（すべて `js/main.js` の `born()` と `grownUp()`）。

| できごと | 使う統計 |
|---|---|
| 何歳まで生きるか | 生命表（下） |
| 家の暮らし向き | 1日3ドル未満・8.30ドル未満で暮らす人の割合 `SI.POV.DDAY`・`SI.POV.UMIC` |
| 小学校・中学校を最後まで終えるか（やめる年齢） | 修了率 `SE.PRM.CMPT.ZS`・`SE.SEC.CMPT.LO.ZS` |
| こどものうちに働く | 7〜14歳で働くこどもの割合 `SL.TLF.0714.ZS` |
| 18歳未満の結婚（女の子） | 18歳までに結婚した女性の割合 `SP.M18.2024.FE.ZS` |
| 大学など | 中学校を終えた人のうち、高等教育総就学率にあう割合 |
| こどもの数・こどもが幼いうちに亡くなる | 合計特殊出生率・5歳未満死亡率 |

**生命表**（`js/data.js` の `lifeTable()`）：0歳は乳児死亡率 `SP.DYN.IMRT.IN`、1〜4歳は5歳未満死亡率 `SH.DYN.MORT` の残り、5〜24歳は5歳きざみの死亡確率 `SH.DYN.0509`〜`SH.DYN.2024`、25〜59歳は成人死亡率 `SP.DYN.AMRT.MA/FE`（15〜60歳）の残りを年齢とともに増える形（ゴンペルツ）で配分、60歳以上はゴンペルツで延ばし、平均寿命 `SP.DYN.LE00.MA/FE.IN` に一致するよう調整。
シミュレーションで、平均寿命と5歳未満死亡率がデータと ±1 程度で一致することを確認しています（例：ナイジェリア男性 平均寿命54歳・5歳未満死亡 116/1000、日本女性 87歳・2/1000）。

## ゲームの流れ

| ねんれい | ばめん | かなう確率（📊統計 / 🎲ゲームの目安） |
|---|---|---|
| うまれる | 国・名前・男女・まち/いなか・暮らし向き・きょうだい | 出生数・都市人口・貧困率・出生率 |
| 0さい | かぞく（よむだけ） | |
| 3さい | いえの くらし：電気・水・料理・あいさつ・まめちしき（よむだけ） | 電気・水の割合 |
| 6さい | **えらぶ**：しょうがっこうに いく / いえを てつだう | 📊 小学校修了率 |
| 10さい | **えらぶ**：ゆめ（4つから） | |
| 12さい | **えらぶ**：ちゅうがっこうへ / はたらきに でる（学校に行っていない子は **できごと**：こどもの しごと） | 📊 中学校修了率÷小学校修了率 / 📊 働くこども |
| 15さい | **できごと**（女の子）：18さいより前の結婚 | 📊 18歳までに結婚した女性 |
| 成人 | **えらぶ**：だいがく / はたらく / まちに でる | 📊 大学など就学率÷中学校修了率（中学を終えていないと 0%） |
| 就職 | **えらぶ**：ゆめの しごと / おきゅうりょうの しごと / はたけ・ぼくじょう・りょう | 🎲 ゆめ（大学が必要な仕事は大学を出ていないと 0%）/ 📊 賃金労働者の割合 `SL.EMP.WORK.ZS`（大学卒は +25 🎲） |
| けっこん | **えらぶ**：けっこんする / ひとりで くらす | 🎲 80% |
| そのあと | こども・こどもを亡くす・まご・引退・最期（よむだけ） | 出生率・5歳未満死亡率・生命表 |

- 選ぶと、緑（かなう）と赤（かなわない）のゲージの上を針が動いて止まり、結果が決まる
- **しあわせ**（0〜10）：結果ごとに良いこと（＋1）か大変なこと（−1）がランダムに起こる。かなっても大変なことはあり、かなわなくても良いことはある。最後に「かなった数」と「しあわせ」を並べて見せる
- 亡くなる年齢は生まれたときに生命表で決まり、その年齢より後の場面には進まない

## データ

数字はすべて **世界銀行 World Development Indicators** の各国の最新値です（国連・WHO/UNICEF・UNESCO・ILO などの統計がまとまっています）。
`node tools/sekai_data.mjs` を実行すると API から取り直して `js/stats.js` を作りなおします（年に1回くらい）。2010年より古い値は使いません。

| 項目 | 指標 |
|---|---|
| 生まれる確率 | 人口 `SP.POP.TOTL` × 出生率 `SP.DYN.CBRT.IN` |
| きょうだい | 合計特殊出生率 `SP.DYN.TFRT.IN` |
| 電気・水・トイレ | `EG.ELC.ACCS.ZS`・`SH.H2O.BASW.ZS`・`SH.STA.BASS.ZS` |
| 進学 | 高等教育総就学率 `SE.TER.ENRR`（100% をこえる国は 100%） |
| 仕事 | 農業で働く人の割合 `SL.AGR.EMPL.ZS` |
| 100にんむら・まめちしき | 0〜14歳 `SP.POP.0014.TO.ZS`・都市人口 `SP.URB.TOTL.IN.ZS`・インターネット `IT.NET.USER.ZS`・森林 `AG.LND.FRST.ZS`・国土 `AG.LND.TOTL.K2` |

- 国名は日本語（CLDR）をもとに、漢字をひらがなにしたもの
- 値がない国は同じ大陸の平均で補い、画面に ※ をつける
- 出生の多い 40 か国（世界の出生の約 77%）には、首都・あいさつ・料理・スポーツ・まめちしき（`js/data.js` の `CONTENT`）を書いてあり、3さいの「いえの くらし」に出る。ほかの国は数字から作るまめちしきになる。国を増やすときは `CONTENT` に1行足すだけ
- 成人年齢は `ADULT`（書いていない国は18さい）

ゆめの仕事に大学が必要なもの（おいしゃさん・せんせい・かがくしゃ・うちゅうひこうし）は、大学に進んだときだけかないます。かなわなかったときは、その国の農業の割合で「はたけ・ぼくじょう・りょう」か「町の仕事」になります。
