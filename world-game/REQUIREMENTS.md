# 世界統一ゲーム（仮）要件定義 ドラフト v0.3

> 小説『スプライトシュピーゲルIV テンペスト』II章「第一の死者」で、ミッターマイヤーが証人6人に遊ばせる
> 卓上ゲーム（作中タイトル〝リヴァイアサン〟＝〝世界統一ゲーム〟）を、**一人で遊べるデジタルゲーム**にする。
>
> 本書はたたき台。`【要決定】` が付いた項目は末尾の「未決事項」で確認する。
>
> **決定済み（v0.2）**：自国1国＋AI 5国／GM（実況・コメント役）あり／イベントは手作りデータ＋連鎖／大人向け／実在国はパロディ程度。
>
> **決定済み（v0.3）**：1プレイ30〜60分・上限50年／成功確率は常に表示／崩壊後は数年経つと復帰の可能性あり／国の数値は原作に出てくるものをそのまま使う／ダッシュボード型の画面／ほぼ現実どおりの架空の世界地図。

---

## 1. コンセプト

- プレイヤーは架空の国家の元首。毎ターン（＝1年）、国と世界の状況を見て政策を選び、**成功確率つきのダイス判定**で結果が決まる。
- 自国を豊かにするだけでは終わらない。**ある国の成功が別の国の破綻を生む**（パーム油→森林破壊、高金利→途上国の破産、食糧特許→略奪…）。
- ゲームオーバーは3つ：**核戦争／地球環境の破綻／一国による世界征服**。
- ゴールは「世界が統一的に運営される未来」。到達のしかたは一つではない（作中「ゴールは何百とある」）。
- 体験の芯：作中の証人たちのように、架空なのに「自分の国が壊れていく」実感と、全員で乗り越えたときの喜びを味わう。

## 2. 原作から読み取れるルール（観察メモ）

| 作中の描写 | ゲームの仕組みとしての解釈 |
|---|---|
| 小国旗・国章バッジ・カード式電子パネル・多面体ダイス・国連バッジ | 自国の表示／政策選択UI／判定用ダイス／国際機関の段階表示 |
| パネルに〝世界と自国の状況〟の簡略データ表が出る | 国家パラメータ＋世界パラメータのダッシュボード |
| 「一巡につき一年が経過」 | 1ラウンド＝1年。各国が順番（時計回り）に1手ずつ |
| スタートは200X年、70カ所で紛争、資源枯渇目前、条約の6割が賞味期限切れ | 初期状態は「すでに危機的」 |
| 最初に各元首が〝基本政策〟を決める（技術優先・教育・中継貿易・治安・税制優遇・金利操作・核開発…） | ゲーム開始時に国家方針（＝国の性格）を選ぶ |
| 選択肢ごとに成功確率が表示され、ダイスで判定。「5%以下を的中＝大成功」「2%の核開発を一発で成功」 | 確率は状態から計算。低確率×高効果／高確率×低効果のトレードオフ |
| 結果は「成功／やや成功／失敗／大失敗」など段階がある | 判定結果は4〜5段階 |
| GMが「さて、どうする？」と状況を突きつける（食糧危機、南極の石油、北極戦争、テロ、難民、水危機…） | 年ごとの世界イベント＝その国への問いかけ |
| 状況によって「選択肢がほとんどない」「選択肢が復活」 | 選べる政策は状態でフィルタされる |
| クーデターで政権崩壊→パネルがオフ（しばらくお休み）→新元首が選ばれ復帰 | 自国崩壊＝一時離脱・復帰ルール |
| 提携・条約・制裁・派兵・空爆・国連決議・国際法廷 | 外交アクション（他国との関係値） |
| 国連の解体→世界政府準備委員会→史上初の世界総選挙→世界議会で最初の議題が全会一致 | 終盤の勝利ルート（国際機関の段階を進める） |
| 「勝手に飲んではいけない水」＝水管理法、撤廃して水が自由に飲める世界に | 世界的な共通課題を「全会一致」で解決するとクリア |

## 3. 一人用への翻案（案）

**決定**：プレイヤーは**自国1国**を操作し、残り5国は性格の違う**AI元首**（作中の証人6人がモデル）。
さらに作中のミッターマイヤーにあたる **GM（ゲームマスター）** が進行役として登場し、状況の提示・判定の宣言・プレイヤーへのツッコミや称賛を適宜入れる（4.8）。

## 4. 機能要件

### 4.1 ゲームの流れ

1. **国の抽選**：あらかじめ決めた主要国16カ国（国名・初期値は固定）から6カ国を**ランダムに抽選**し、そのうち1つが自国になる（ルールは [`MAP.md`](MAP.md)）。シード値で同じ組み合わせを再現でき、基本政策を選ぶ前に1回だけ引き直せる。自国の初期値を見て、基本政策を1〜2個選ぶ。国名は変えられないが、ゲーム中の政策・イベントで変わることがある。
2. **AI 5国の性格**：残り5カ国に性格（4.6）をランダムに割り当てる。
3. **ラウンド（1年）**：
   1. 世界ニュース：その年の世界イベントを提示（GMのせりふ風）。
   2. 各国が時計回りに手番。自国の手番では、状況に応じた選択肢（3〜5個）から1つ選ぶ。各選択肢に**成功確率と予想される影響**を表示。
   3. ダイスを振る演出 → 判定 → 自国・他国・世界のパラメータ変化。
   4. 波及効果の解決（他国の成功／失敗が自国に来る）。
   5. 年次まとめ（年表に1行追記）。
4. **終了判定**（4.9）。

作中で GM や証人が口にした数値・状態を、そのままパラメータにする。カッコ内は作中での登場のしかた。

- 数値の多さで画面が埋まらないよう、ダッシュボードでは分類ごとに折りたたみ、危険域の数値だけを強調する（4.11）。

### 4.3 政策と判定

- 政策はカテゴリ別：経済／教育・技術／資源・エネルギー／食糧・水／治安／外交／軍事／国際機関。
- 各政策は「前提条件」「基本成功率」「成功率の補正（教育が高いと＋など）」「成功時・失敗時の効果」「他国・世界への波及」をデータで持つ。
- 判定：d100 を振り、成功率以下なら成功。結果は **大成功／成功／やや成功／失敗／大失敗** の5段階（閾値は調整）。
- 画面には多面体ダイスを転がす演出。
- **成功確率は常に表示する**（作中のパネルと同じ）。タップすると内訳（基本値＋国力・識字率・治安などの補正）が見られる。大成功・大失敗の確率も併記する。

### 4.4 世界イベント（GMの「さて、どうする？」）

- 年ごとに、世界状態と過去の結果から次のイベントを選ぶ（例：代替エネルギー開発 → 穀物価格高騰 → 食糧危機）。
- イベントは**連鎖**する（南極の石油発見 → 南極戦争 → 北極でも → 双極戦争）。
- **決定**：イベントは手作りデータで持ち、前提条件（世界・各国の状態、過去に起きたイベント）と連鎖先をデータに書く。同じイベントでも状態によって選択肢・確率が変わるようにして、組み合わせで展開の幅を出す。

### 4.5 波及効果

- 一国の結果が他国・世界の数値を動かすことを必須とする（このゲームの肝）。
- 例：パーム油の大増産 → 森林減少・他国の木材価格高騰／高金利の開発援助 → 援助先の破綻・連鎖倒産／核開発 → 周辺国の緊張・制裁。

### 4.6 AI 元首（5国）

作中の証人たちの選択傾向をモデルにした性格（名前は変える）：

| 性格 | 傾向 |
|---|---|
| 技術立国 | 産業・技術優先。他国の技術を取り込む |
| 教育・文化 | 長期投資と協調。人道介入には慎重 |
| 中継貿易 | 物流・関税・提携で稼ぐ。現実的 |
| 秩序・強国 | 治安と軍事。介入・空爆も辞さない |
| 金融 | 金利・援助・規制で影響力を持つ |
| 野心家 | 核開発など高リスクの賭けに出る |

AIは「自国の利益」と「世界の存続」の重みが性格ごとに違う。崩壊しかけた国は過激化する。

### 4.7 国家の崩壊と復帰

- 政情・治安・経済などが閾値を下回る、または元首の暗殺・クーデターが起きると → **その国のパネルがオフ**（手番なし）。
- **復帰**：崩壊から数年（例：3年）経つと、毎年、新政権が立つかの判定を行う（確率は国内状況と他国の援助・派兵で変わる）。成功すると新元首として復帰。数値は崩壊時の悪い状態から再開。
- 自国が崩壊している間、プレイヤーは世界の動きを見守る（年送りを早送りできる）。他国の援助や派兵が復帰の確率を上げるので、崩壊前の外交が効く。
- 50年の上限までに復帰できなければ、その結果のままエンディングへ。

### 4.8 GM（進行役・コメンテーター）

**決定**：GM は**ミッターマイヤー**（作中の人物をそのまま登場させる）。

作中の描写から読み取れる人物像：

- 自分で考えたゲームを、心底楽しそうに仕切る（遊ぶ人の真剣な反応に嬉しそうに微笑む、拍手する）
- 危険な選択には先回りして釘を刺す（「核戦争が起きたらゲームオーバーだ」）
- 結果は判事のように淡々と宣告する。良い判断は素直に褒め、甘い判断は突き放す
- 証人たちにからかわれても動じない（「皇帝様」と呼ばれる）
- 最後は参加者と同じ目線で喜びを分かち合い、記念日に名前を付ける

ゲームでの描き方：

- **役割**：
  - 年の始まりに世界情勢を語り、「さて、どうする？」と選択を迫る
  - ダイス判定の結果を宣言する（「成功だ。実に強運だ」「失敗。世界はそんなに甘くない」）
  - プレイヤーの選択にコメントする：核開発を選べば「核戦争が起こったらゲームオーバーだぞ」と釘を刺す、低確率を当てれば驚く、他国を見捨てれば皮肉を言う
  - AI 元首たちの反応（喜ぶ・怒る・泣く）を短いせりふで差し込む
  - 節目（崩壊・戦争勃発・世界総選挙・クリア）で長めの語り
- **実装**：生成AIは使わず、状況タグ（例：`dice.critical_success`、`player.chose_nuclear`、`world.co2_high`、`ai.collapsed`）ごとにせりふのテンプレートを複数持ち、変数（国名・確率・年）を差し込んでランダムに選ぶ。同じせりふの連続を避ける。
- **口調**：大人向け。皮肉と温かさが同居する。作中のせりふをそのまま使わず、オリジナルの文で書く。
- **見た目**：顔のイラストは使わず、名前と短いせりふ（と小さなアイコン）で表す。
- **注意**：作中の人物名をそのまま使うので、一般公開する場合は名前の扱いを見直す（個人で遊ぶ範囲では問題にしない）。
- **設定**：GMの発言頻度（多い／ふつう／少ない）を切り替えられる。

### 4.9 終了条件

- **ゲームオーバー**：核戦争（核使用の連鎖）／環境破綻（環境値が限界）／世界征服（一国が軍事・経済で他を支配）。
- **クリア（世界統一）**：国際機関の段階を進め、世界政府の最初の議題を全会一致で可決する。
- **複数エンディング**：どの課題を全会一致で解決したか、何年かかったか、何人が犠牲になったかで結末とスコアが変わる。
- **上限は50年**。50年目を終えたらタイムアップのエンディング（世界の状態で内容が変わる）。

### 4.10 世界地図

- **ほぼ現実どおりの地形**（大陸・海・南極・北極）に、架空の国境と架空の国名を置く。国旗・特徴は作中のように「〇〇っぽい」パロディ。
- 国は46カ国で、国名・初期値はすべて固定：主要国16（うち6カ国をランダムに抽選して自国＋AI 5国にする）と背景国30。詳細は [`MAP.md`](MAP.md)。
- 6国（自国＋AI 5）は色付きで目立たせ、背景国は淡く表示する。
- 地図上に表示するもの：紛争地域、戦争・派兵の矢印、核保有、破綻国、資源（油田・森林・水）、氷の範囲（温暖化で縮む）、水没する沿岸部、提携・同盟の線。
- 国をタップするとその国の数値を表示する。
- 地図データは自前の簡略化した SVG（外部ライブラリ・タイルなし）。

### 4.11 画面（ダッシュボード型）

iPad 横画面を基準にした1画面構成（案）：

- **上部**：西暦・世界パラメータのゲージ（CO₂、紛争数、緊張、資源）・国際機関の段階
- **中央**：世界地図
- **左**：自国の数値（分類ごとに折りたたみ、危険域を強調）
- **右**：AI 5国の元首（国旗・パネルのオン／オフ・関係値・直近の行動）
- **下**：GMのせりふ欄と、選択肢カード（成功確率・予想される影響つき）、ダイス

### 4.11.1 タップで拡大・国の情報の見え方（おとな・1ねんせい共通）

- ニュースと GM の吹き出しはタップすると大きく表示。地図・自国のステータス・政策カードは 🔍 で拡大（拡大したカードからそのまま選べる）。どこかをタップすると閉じる。
- 国の情報（地図や各国の欄をタップ）は大きなウィンドウで表示し、**仲のよさで見える内容が変わる**。
  - 提携している、または関係 70 以上：すべての数値が正確に見える
  - 関係 40〜69：「高い／ふつう／低い」などおおまかにしか見えない（財政・国債・ゲリラなどは「？」）
  - 関係 40 未満：人口・GNP・兵士のおおよその数と、核を持っているかだけ
  - 1ねんせいモードでは、くわしい→バー、すこし→「おおい／ふつう／すくない」、ほとんど→おかね・へいたい以外は「？」
- 背景国（小さな国）の情報はいつでも見える。

### 4.11.2 ニュースと数値・成功率の連動

- ニュースの下に、そのニュースで実際に動いた数値を「→ セルバ共和国：産業↓↓ GNP↓　世界：CO₂↑」の形で出す（1ねんせいは絵と矢印）。3カ国以上で同じ数値が同じ向きに動いたら「小国◯カ国」「各国」にまとめる。
- **情勢**：一部のニュースは、しばらくのあいだ関係する政策の成功率を上下させる（例：世界恐慌の4年間は経済の政策 −15、世界的大流行の3年間は医療支援 +10・貿易 −10、協調の成功例のあと5年間は外交・国際機関 +10）。対象国だけ／対象国以外に効くものもある。一覧は `js/data/situations.js`。
- 情勢は右側の欄に一覧で出し、カードには「📰 情勢 −10」、確率の内訳には「情勢：世界恐慌 −15」と出す。AI も同じ成功率で判断する。

### 4.11.3 ニュースのカード（Reigns 風）

- 年のはじめのニュースは、画面の中央に**カードで1枚ずつ**出す。裏（📰 せかいの ニュース）をタップしてめくると、見出し・対象国・GM の語り・動いた数値・情勢が読める。読み終わるまで政策の手番に進まない（ニュースを読まずに進めてしまうのを防ぐ）。
- 多くのニュースでは、めくったカードを**左右にスワイプ（またはボタン）して自国の態度を2択で決める**。例：経済危機 →「自国の市場を守る（資本↑ 評価↓ 国際機関の信頼↓）」／「各国と協調して支える（財政↓ 評価↑ 国際機関の信頼↑）」。選択肢と効果はニュースの種類ごとの共通の組（`js/data/reactions.js`）。ニュースの対象が自国のときは「国民に寄りそう／強い態度で乗り切る」。
- どちらの選択肢にも得と損があり（1ねんせいの絵の表示でも ↑ と ↓ が必ず両方出る）、でたらめに選んだときの世界への影響はほぼ釣り合う。自動プレイ（800回）で、結末の割合は反応なしの版と ±2% 程度。
- 効果はダイス判定なしで、その場で自国に効く。選んだ結果はカードの上と、ニュースの欄に「✋ 自国の反応：…」として残る。核のボタン・世界議会の投票など、別の決定があるニュースには2択を付けない。自国が崩壊中はカードを出さずに進む。
- キーボードでも操作できる（Enter：めくる、←／→：選ぶ）。

### 4.12 火種（一国から世界へ広がる問題）

- ある一国で起きた問題（感染症・銀行破綻・飢饉・内戦・放射能汚染・核物質の流出・大河のダム・債務・小惑星）が、各国の支援しだいで封じ込められるか、世界規模に広がるかが決まる。
- **深刻度と期限は秘匿**。期限と悪化の速さは火種ごとにランダムで、画面には場所・種類・経過年数しか出ない。様子は GM のせりふでほのめかされるだけ。
- 正しい支援はカードに表示しない。現実の知識と GM のヒントで見抜く。封じ込めは協調の成功例になる。
- 詳細は [`POLICIES_EVENTS.md`](POLICIES_EVENTS.md) 4.9。

### 4.13 1ねんせいモード（小学1年生向け）

タイトル画面で「おとな／1ねんせい」を選ぶ。中身の計算はおとなと同じで、見せ方・ことば・長さだけを変える。

- **ことば**：ひらがなの分かち書きを基本に、カタカナの言葉はカタカナ（エネルギー・ニュース・カード・国名「ステラの くに」など）、小学1年生で習う漢字80字はその漢字で書く（人・水・大きな・お金・年・出目など。2年生以上の字はひらがなのまま＝「くに」「うみ」）。データはひらがなで持ち、表示の直前に `js/ui/kidify.js` の辞書で置きかえる。重いテーマ（核・紛争・感染症など）は残し、ことばをやわらげる。辞書の漢字がすべて1年生の字であること、ブラウザでの通しプレイで1年生以外の漢字やカタカナになっていない言葉が出ないことを自動チェックする。
- **国のステータス**：8つ（💰おかね／🏠くらしの あんしん／🍚たべもの／💧みず／🛡へいたい／📚べんきょう／⚡えねるぎー／🤝なかよし）。中の約28項目から計算した 0〜100 のバーで見せ、低いと ⚠。
- **成功確率**：「でめが 63 いかなら せいこう」と表示する（％は使わない）。
- **カード**：毎回3枚。効果は「じぶん 💰↑ 🏠↓」のように絵とやじるしで見せる。
- **世界のゲージ**：🌏ちきゅう／⚔けんか／⚡ぴりぴり／🤝きょうりょく の4つ。
- **長さ**：20かい（約15分）。1かいで2〜3年すすみ、20かいで約50年ぶんの世界の変化を体験する。
- **難しさはおとなと同じ**：手番が少ないぶん、政策の効き目を 2.5 倍、できごとを 1.6 倍にし、できごとは1かいに2〜3こ起こす。世界の悪化も少し上乗せする。自動プレイで、結末の割合（クリア・環境の破綻・時間切れ）がおとなとほぼ同じになるよう合わせた。
- **GM**：ミッターマイヤー。火種のほのめかしも同じ表記で行う。

## 5. 非機能要件（案）

- 既存の「かずまほ」「アルカナンバー」と同じく、**依存なしの素の JavaScript（ES Modules）＋PWA**。iPad 横画面基準、ブラウザだけで動く。GAS 1ファイル版も出せる構成。
- セーブは localStorage に自動保存。
- 1プレイ 30〜60分程度、**上限50年**。途中セーブ・再開できる。
- 生成AIは使わない。イベント・政策・GMのせりふはすべて手作りデータ。完全オフラインで動く。
- **対象は大人**。核・テロ・内戦・虐殺・難民など重いテーマを原作どおりの重さで扱う。表現は描写より「数字と選択の結果」で突きつける方針。
- **実在の扱いはパロディ程度**：国名は架空（例：作中の〝○○っぽい国旗〟のように、実在国を連想させる国旗・地理・特徴）。事件も実在の出来事を連想させる架空名にする（「北極戦争」「水管理法」など作中同様の造語は可）。実在国名・実在人物名・実在の事件名は直接出さない。
