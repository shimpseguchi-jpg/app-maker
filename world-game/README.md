# 世界統一ゲーム（仮）

小説『スプライトシュピーゲルIV テンペスト』の作中で、ミッターマイヤーが証人6人に遊ばせる卓上ゲーム（〝世界統一ゲーム〟）を、**一人で遊べるブラウザゲーム**にしたものです（個人制作のファン作品。国名・事件名は架空です）。

- 要件：[`REQUIREMENTS.md`](REQUIREMENTS.md)
- 政策・世界イベント：[`POLICIES_EVENTS.md`](POLICIES_EVENTS.md)
- 世界地図・国の初期値・配置：[`MAP.md`](MAP.md)

## あそびかた

1. 主要国16カ国から6カ国が抽選され、そのうち1つがあなたの国になります（シード値で同じ組み合わせを再現できます。1回だけ引き直し可）。
2. 基本政策を1〜2個選んで開始。
3. 毎年、世界イベントが起き、各国が時計回りに1つずつ政策を選びます。どの政策にも**成功確率**が出ていて、**100面ダイス**で判定します（確率の1/10以下で大成功、96以上の失敗は大失敗）。
4. 年のはじめのニュースは**カードで1枚ずつめくって**読みます。多くのニュースでは、Reigns のようにカードを左右にふって自国の態度を2択で決めます。
5. GM（ミッターマイヤー）が状況を語り、結果を告げ、あなたの選択にコメントします。
6. ときどき、ある一国で**火種**（感染症・銀行破綻・飢饉・内戦など）が起きます。各国が正しく支援すれば封じ込められ、まちがえれば世界規模に広がります。深刻度と期限は知らされず、GM のせりふでほのめかされるだけです。
7. **クリア**：国際機関を「国連 → 国連の解体 → 世界政府準備委員会 → 世界総選挙 → 世界議会」と進め、世界議会の最初の議題を全会一致で可決する。協調の成功例を3つ積めば、国連の解体を経ずに準備委員会へ進めます。
8. **ゲームオーバー**：核戦争／地球環境の破綻／一国による世界征服／自国の併合。50年でタイムアップ。

## 1ねんせいモード

タイトル画面で「1ねんせい」を選ぶと、小学1年生向けになります。

- ひらがなの分かち書き＋カタカナ語＋小学1年生で習う漢字（80字）
- 国のステータスは8つ（おかね・くらしの あんしん・たべもの・みず・へいたい・べんきょう・えねるぎー・なかよし）
- 成功確率は「でめが 63 いかなら せいこう」
- 20かい（約15分）。難しさはおとなと同じ

## 動かし方

依存ライブラリなしの素の JavaScript（ES Modules）です。HTTP で配信すれば動きます。

```sh
cd world-game
python3 -m http.server 8124
# → http://localhost:8124/
```

iPad の横画面を基準にしています。Safari で「ホーム画面に追加」すると全画面で起動し、オフラインでも遊べます。セーブはブラウザ内（localStorage）に自動保存されます。

### 学校で配る（GAS 版）

学校の Google Workspace の中だけで動く版もあります。子どもの学校アカウントごとに、セーブが一人一つ、先生のスプレッドシートに保存されます。作り方と設定の手順は [`gas/README.md`](gas/README.md) にあります。

```
js/data/policies.js   基本政策10・政策90（成功確率・補正・効果・波及）
js/data/events.js     世界イベント80（条件・効果・差し込む政策・連鎖先・GM の語り）
js/data/events_more.js 追加の世界イベント69（南極・北極、いま・過去・未来の問題、火種）
js/engine/sparks.js   火種（一国から世界へ広がる問題）の深刻度・支援・封じ込め／拡大
js/data/gm.js         GM（ミッターマイヤー）のせりふ・AI 元首の反応
js/data/kid.js        1ねんせいモードの ことば（国名・政策・できごと・せりふ）と 8つの ステータス
js/data/mapdata.js    地図（tools/build_map.mjs で生成）
js/engine/core.js     成功確率・判定・国力・隣接
js/engine/effects.js  効果の文字列（'self.industry+m' など）の適用
js/engine/game.js     世界の生成・1年の流れ・核のボタン・世界議会の投票・終了判定
js/engine/tick.js     年末の経済・社会・環境の変化
js/engine/ai.js       AI 元首の判断（性格ごとの重み）
```

### 開発用ツール（`tools/`）

- `node tools/test_data.mjs` … データの整合（政策・イベントの参照、地図、抽選ルール、シード値の再現性）
- `node tools/sim.mjs 400` … AI が自国も操作して何百回も遊び、結末の割合・世界の推移・国ごとの成績・イベントの発生率を出す（バランス調整用）
- `node tools/e2e.mjs` … ブラウザでロボットが最後まで遊ぶ通しテスト＋スクリーンショット（Playwright が必要。先に `python3 -m http.server 8124` を起動）
- `node tools/build_map.mjs` … Natural Earth（world-atlas）の国境から地図データを作り直す（`cd tools && npm install` が必要）

地図データは [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）をもとにしています。
