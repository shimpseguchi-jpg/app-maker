# GAS 版（Google Apps Script のウェブアプリ）

学校の Google Workspace の中だけで動く版です。

- **セーブは一人一つ**：子どもの学校アカウントごとに、先生のスプレッドシートに自動で保存されます。別の端末でログインしても「つづきから」で再開できます。
- **子どもに許可画面は出ません**：Google にログインしていれば、そのまま遊べます。
- **先生は一覧で見られます**：スプレッドシートで、だれが・どのモードで・何年目まで進んだか、結果と点数が見られます。
- ゲームの中身はふつうの版と同じです（オフライン起動・ホーム画面アプリだけは使えません）。

## ファイル

| ファイル | 中身 |
|---|---|
| `Code.gs` | サーバー側（ページを返す・セーブを読み書きする） |
| `index.html` | ゲーム本体を1つにまとめたもの（`node tools/build_gas.mjs` で作る。手で直さない） |
| `appsscript.json` | 設定（タイムゾーン・必要な権限・公開範囲） |

## はじめての設定（先生が一度だけ）

1. 学校のアカウントで <https://script.google.com> を開き、「新しいプロジェクト」を作る。名前は「世界統一ゲーム」など。
2. 左の ⚙「プロジェクトの設定」で、「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックを入れる。
3. エディタに戻り、`appsscript.json` の中身を、このフォルダの `appsscript.json` に置きかえる。
4. `コード.gs` の中身を、このフォルダの `Code.gs` に置きかえる。
5. 「ファイル」の ＋ →「HTML」で、名前を **`index`** にして作り、中身をこのフォルダの `index.html` に置きかえる。
6. 上の関数の選択で **`setup`** を選んで「実行」。許可を求められるので、先生のアカウントで許可する。
   実行ログに「セーブの保存先：https://docs.google.com/…」と出れば成功です。先生のドライブに「世界統一ゲーム セーブ」というスプレッドシートができます。
7. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校のドメイン）内の全員**
   「デプロイ」を押すと、ウェブアプリの URL が出ます。
8. その URL を Classroom などで子どもに配る。

## 先生のスプレッドシート

| 列 | 中身 |
|---|---|
| アカウント | 子どものメールアドレス |
| 更新 | 最後に保存した日時 |
| モード・年・国 | 1ねんせい／おとな、ゲームの中の年、自分の国 |
| じょうたい | プレイ中・クリア・タイムアップ・環境の破綻・核戦争・世界征服・併合された |
| 点数 | おわったときの点数 |
| 設定・セーブ1〜8 | ゲームのデータ（ふだんは隠してあります。手で書きかえないでください） |

- **ある子のセーブを消したいとき**：その子の行を削除します（次に開いたときは「あたらしく はじめる」から）。
- スプレッドシートを消してしまっても、次に遊んだときに新しく作り直されます（それまでのセーブは消えます）。

## ゲームを新しくしたとき

1. `index.html`（必要なら `Code.gs` も）を新しいものに置きかえる。
2. 「デプロイ」→「デプロイを管理」→ ✏ 編集 → バージョン「新バージョン」→「デプロイ」。
   こうすると **URL は変わりません**（「新しいデプロイ」にすると URL が変わります）。

## 注意

- 個人の Gmail アカウントで公開すると、ほかの人のアカウントが分からないため、セーブは「その端末だけ」になります（ゲームは遊べます）。学校のアカウントで公開してください。
- セーブは数秒ごとにまとめて送ります。遊び終わってすぐにタブを閉じても、たいていは間に合いますが、最後の1手が残らないことがあります。
- 外に出ていく通信は、文字の見た目用の Google Fonts だけです（読めない環境でも、ふつうの文字で遊べます）。

## 開発者向け

```sh
cd world-game/tools && npm i && cd ..
node tools/build_gas.mjs     # gas/index.html を作る
node tools/test_gas.mjs      # Code.gs を、にせのスプレッドシートでたしかめる
python3 -m http.server 8124 &
node tools/e2e_gas.mjs       # にせの GAS で、クラウドへのセーブと「つづきから」をたしかめる
```
