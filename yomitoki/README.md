# よみとき でんしゃ 〜ぶんしょうだい とっくん〜

小学1年生むけの、**文章題の「文意理解」と計算練習**のための学習ゲームです。
教科書（「3つの かずの けいさん」など）と同じ形の問題を、ことばだけ（絵なし）で出題します。
iPad の横画面を基準にした、ブラウザだけで動くアプリです（ビルド不要）。

## ねらい

文章題が苦手な子の多くは、計算ではなく **「何を聞かれているか」「どの数を使うか」「ふえる？へる？」** でつまずきます。
また「数が出てきたら全部たす」「“おりた”があったらひく」のような **ことばだけで決める解き方** をしがちです。
このアプリは、その部分を分けて、くり返し練習します。

## 1問の流れ（4ステップ）

| ステップ | すること | まちがえたとき |
|---|---|---|
| 1 よむ | 問題文を読む（絵は出さない）。文の長さに応じて、数秒は次に進めない | − |
| 2 きかれて いる | 「いま でんしゃに のって いる ねずみの かず」など3択から選ぶ | 最後の「？」の文を黄色で示す。2回目で答えを示す |
| 3 しき | **文の中の数をタッチ** して式をつくる（数は自分で打たない） | 原因ごとに、読み直す文だけを示す（下の表） |
| 4 こたえ | 計算して答えを書き、**単位**（ひき・こ・ほん…）を選ぶ | 3つの数は「まず前の2つ」のヒント。単位は「何の数？」 |

式のまちがいは、原因を見分けて対応します。

| 原因 | 示し方 |
|---|---|
| 使わない数を使った（ベンチの うさぎ など） | その数と文を示し「聞かれていることと関係ある？」 |
| 数を読み落とした | 使っていない数の文を示す |
| ＋と−のまちがい | その文の動詞（「おりました」など）に線を引き、**「ふえる？ へる？」のミニクイズ** |
| ひけない順番 | 「はじめの かずは どれ？」 |

## 甘やかさないしくみ

- 各問題 ⭐3 から始まり、**まちがえるたび・ヒントを使うたびに ⭐−1**（よみあげ・絵のヒントもそれぞれ ⭐−1）
- 答えはすぐ見せない。2回まちがえると〇の図で説明するが、**そのあと必ず自分で式をつくり直す**
- **あわてんぼう ロック**：問題が出てすぐ（2.2秒以内）にまちがえると、4秒間「もういちど よもう」で待たされる
- 読みちがい（聞かれていること・数・＋−・単位）をした問題は
  - その場で、**2問あとに同じ形の別の問題**がもう一度出る
  - **とっくんノート**に入り、**別の日に2回、ノーミスで解けるまで消えない**
- 問題の種類ごとに習熟度（0〜5）をもち、ノーミスで解くと1つ上がる（**1日1回まで**）。まちがえると0に戻り、すぐまた出る
- 「きょうの とっくん」は習熟度の低い種類ほど多く出る。今のレベルの種類がすべて習熟度2以上（＝別の日に2回ノーミス）になると次のレベルへ

## 問題の種類

| Lv | 種類 | 例 |
|---|---|---|
| 1 | ふえると いくつ | でんしゃに ねずみが 5ひき のって います。3びき のりました。 |
| 1 | へると いくつ | あめを 8こ もって います。3こ たべました。 |
| 1 | あわせて いくつ | あかい はなが 4ほん、しろい はなが 3ぼん。あわせて なんぼん？ |
| 2 | ちがいは いくつ | りんごは みかんより なんこ おおい？／すくない？ |
| 2 | 3つの かず（ふえる・ふえる／へる・へる／ふえる・へる） | 5＋3＋2、10−3−2、5−2＋4（教科書と同じ形） |
| 3 | つかわない かずが ある | 「じてんしゃも 3だい とまって います。」がまざる |
| 3 | あわせて から へる | ひだりに 7ひき、みぎに 3びき。8ひき おりると？（7＋3−8） |
| 3 | きかれて いる ことに ちゅうい | 「おりたのは あわせて なんびき？」（“おりた”なのに たしざん） |

### 問題文のバリエーション

同じ種類の問題でも、次の要素を毎回ランダムに組み合わせます（1種類あたり数十〜千数百とおりの文の形。`node yomitoki/tools/test_problems.mjs` で数を確認できます）。

| 要素 | 例 |
|---|---|
| 場面（ふえる・へる 15種） | 電車・バス・木の鳥・公園・あめ・シール・駐車場・クッキー・ふでばこ・本だな・どんぐり・ふうせん・池・金魚の水そう・あり |
| 場面（くらべる・あわせる 10種） | 花だん・電車の車両・男の子と女の子・くだもの・みずうみ・いぬとねこ・ふうせん・えほんとずかん・バスとトラック・えんぴつ |
| 書き出し | 「でんしゃに ねずみが 5ひき のって います」／「ねずみが 5ひき でんしゃに のって います」、1文にまとめる／2文に分ける |
| 動詞 | のりました／のって きました、たべました／わけて あげました、とんで いきました／とびたちました など |
| つなぎことば | つぎに・しばらく して・すこし たって／その つぎに・それから・そのあと／そこへ・（なし） |
| 聞き方 | 「なんびきに なりましたか」「のこりは なんびき」「いま なんびき のって いますか」「ちがいは なんこ」など |
| 名前 | あおいさん・はるとさん・みおさん など10人 |
| 数の順番（ちがい） | 多いほうが**あとに**出てくる文もまぜる（「先の数 − 後の数」と覚えないように） |
| 使わない数の位置 | はじめ・途中・質問の直前のどこにでも入る。同じ単位の数（ほん と ノートの「さつ」など）もまざる |
| 数え方 | 「ひき／びき／ぴき」「ほん／ぼん／ぽん」「ひとり／ふたり」「さつ」「だい」「わ」も正しく書き分け |

## ほかのモード

- **ことば しわけ**：「2ひき おりました」「ちがいは なんこ」「おりたのは あわせて なんびき」などのカードを、たしざん／ひきざんに分ける。まちがえたカードは後ろに戻り、1つにつき +3秒
- **けいさん れっしゃ**：10問の計算（10まで／3つの数／まぜる／10のまとまり／くりあがり・くりさがり）。まちがえると、似た問題が1問ふえる。ノーミスでゴールしたときだけ自己ベストに残る
- **おうちの かたへ**（かけ算の問題で保護者だけが開ける）：種類ごとのノーミス率・習熟度、まちがいの種類の内訳、「ふえる？へる？」の正答率、それにもとづくアドバイス。レベル・よみあげ・ロック・文字の大きさの設定

## 設定（おうちの かたへ）

- レベル：自動 / 1 / 2 / 3
- よみあげ：ヒント扱い（⭐−1・初期値）/ いつでも / なし。文字を読むこと自体が難しい場合は「いつでも」に
- あわてんぼう ロック：オン（初期値）/ オフ
- 文字の大きさ・音

## つくり

```
index.html
css/style.css
js/main.js            起動・画面の大きさ合わせ・ホーム
js/data/problems.js   文章題の生成（場面・種類・数・答え・式のチェック）、ことばカード
js/engine/coach.js    習熟度・とっくんノート・出題の選び方・記録
js/engine/calc.js     計算問題の生成
js/ui/solve.js        文章題を解く画面（4ステップ・ミニクイズ・説明・あわてんぼう ロック）
js/ui/diagram.js      〇の図（ヒント用・説明用）
js/ui/sort.js / calc.js / parent.js   ことば しわけ・けいさん れっしゃ・おうちの かたへ
tools/test_problems.mjs  問題生成のチェック（全種類 × 400問）
tools/e2e.mjs            ブラウザでロボットが通しで遊ぶテスト（Playwright）
```

```sh
node yomitoki/tools/test_problems.mjs
npx http-server -p 8123 -c-1 .   # → http://localhost:8123/yomitoki/
node yomitoki/tools/e2e.mjs      # OUT=フォルダ でスクリーンショットを保存
```

Google Apps Script で配る場合は、`gas/yomitoki.html` を名前 **`yomitoki`** で追加し、URL の最後に `?game=yomitoki` をつけます（手順は [`gas/README.md`](../gas/README.md)）。
