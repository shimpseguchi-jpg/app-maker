# アルカナンバー（ARCANUMBER）

「かずまほ」をベースにした、小学生向けの **本格デッキ構築ローグライク** です。
Slay the Spire のデッキ構築、Magic: The Gathering のカード同士のシナジー、Balatro のコンボと倍率の気持ちよさを、算数と組み合わせました。
iPad の横画面を基準にした、ブラウザだけで動くゲームです（ビルド不要）。

## ゲームの流れ

1. 主人公（3人）・学年（1〜3年）・難しさを選ぶ
2. マップで道を選んで進む（たたかい／つよい敵／たきび／おみせ／たからばこ／なぞ）
3. 3章のボス「ゼロの おう」を倒せばクリア

## デッキづくり（パック開封）

冒険のはじめに、6種類のパック（ほのお・みず・もり・いかずち・やみ・ぎん）から **3つ選んで開封** します。
パックは1つ5枚（同じ属性のルーン3枚＋よくあるカード1枚＋めずらしい／レアのカード1枚。ぎんのパックは いろいろな属性のルーンと むしょくのカード）。
タップでパックを破り、カードを1枚ずつめくります。めずらしいカードは裏面の時点でうっすら光ります。

その後、**はじめのカード（12枚）＋開封したカード（15枚）から 10〜20枚を選んでデッキを組みます**。
- 右側に「なかみ」（属性ごとの枚数、ルーンの数字のグラフ）と「つくりやすい役」（例：ペア：5が3枚／じゅうのわ：3と7）が出るので、数を見ながら組める
- 迷ったら「おまかせ」で自動構築（守りと倍率のカードも最低限入れる）
- 使わなかったカードは **サイドボード** に残り、🔥たきびの「くみなおす」でいつでも入れ替えられる
- おみせで **パック（🪙6）** を買える。ボスを倒すと **ボスのパック**（レアが出やすい）
- デッキの形で強くなるカード：「ひとにぎりのまほう」（デッキ12枚以下なら ×3）、「たいぐんのまほう」（デッキ5枚ごとに ちから+8）、属性の「こころ」シリーズ（手札・山札・捨て札に残った枚数を数える）

## たたかい：ちから × ばいりつ

毎ターン、手札から最大5枚を「じゅもん」に並べて「はなつ！」。

- **ルーン**（数字 1〜10、5つの属性）は、その数だけ **ちから** を足す。マナは不要
- 並べたルーンの組み合わせで **役** が決まり、役ごとに基本の ちから と ばいりつ が入る
- **スペル**（マナを使う）は置いた位置で効果が出る：+ばいりつ、×ばいりつ、もう一度数える など
- **ダメージ = ちから × ばいりつ**。カードもアルカナも **左から順番に** 処理されるので、`+2倍率 → ×2` と `×2 → +2倍率` では答えが変わる

### 役（ポーカーの役を算数向けに作り直したもの）

| 役 | 条件 | 基本 |
|---|---|---|
| ひとつ | 組み合わせなし | 5 × 1 |
| ペア | 同じ数 2枚 | 10 × 2 |
| じゅうの わ 🔢 | 足して 10 になる 2枚（3と7） | 15 × 2 |
| ツーペア | ペア 2組 | 20 × 2 |
| かいだん | 3つ続きの数 | 25 × 3 |
| スリーカード | 同じ数 3枚 | 30 × 3 |
| いろそろい | 4枚以上すべて同じ属性 | 35 × 4 |
| くくの わ 🔢 | かけ算ができる 3枚（2・3・6 → 2×3=6） | 40 × 4 |
| ながい かいだん | 5つ続きの数 | 40 × 4 |
| フルハウス | 3枚 + 2枚 | 40 × 4 |
| フォーカード | 同じ数 4枚 | 60 × 7 |
| いろかいだん | 5つ続き かつ 同じ属性 | 100 × 8 |
| ファイブ | 同じ数 5枚 | 120 × 12 |

「ほしの しょ」で役のレベルを上げると、その役が強くなります（Balatro の惑星カードに相当）。

## 3つのゲームから取り入れたもの

| 元ネタ | このゲームでの形 |
|---|---|
| Slay the Spire | マナ（毎ターン3）とカードのコスト、敵の行動予告、守り（ブロック）、カード報酬・強化・削除、分岐マップ、エリートとボス、インスタント／けっかい（パワー） |
| MTG | 5つの属性（ほのお＝倍率、みず＝守りと手札、もり＝ちからを育てる、いかずち＝くりかえし、やみ＝代償と大技）。「🔥ルーンを数えるたびに…」のような誘発型の けっかい と、属性をまたぐシナジー |
| Balatro | ちから×ばいりつ の計算、役とレベル、左から順に効く **アルカナ（最大5つ、並べ替え・売却可）**、+倍率と×倍率の順番、利子（コイン5枚ごとに1枚）、ショップの品ぞろえ入れ替え、ルーンの強化（きらめき・ほむら・ガラス・きん・にじ）、ボスの「のろい」（ちからが半分、ペア禁止、奇数を数えない など） |

## 算数の学び

- **たし算**：ルーンの数を足して ちから を作る。じゅうの わ（10 の補数）
- **かけ算**：ダメージは ちから × ばいりつ。くくの わ（2×3=6 のような九九の組）、×倍率カード
- **計算の順番**：+ と × の順番で結果が変わることを、カードの並べ方で体験する
- **偶数・奇数**：アルカナ「ぐうすうの つえ／きすうの つえ」、のろい「ぐうすう／きすうの のろい」
- **わり算**：利子（コイン ÷ 5）、「みずの たて」（ちから ÷ 2）、「はんぶんの のろい」
- **けいさん チャレンジ**：はなった後、`ちから × ばいりつ = ?` を選択肢から選ぶ。当たるとダメージ 1.5 倍。学年で問題の出し方が変わる（1年はくり返しのたし算、2年は分けて計算するヒント、3年は見積もり）
- **なぞ**マス：学年別クイズ（時計、お金、規則性、図形、足の数、道順パズル など）

## 操作（iPad 向け）

- カードを **タップ** でじゅもんに入れる／外す。**ドラッグ** で並べ替え。**長押し** で説明
- 敵をタップでねらいを変える。アルカナをタップで説明と並べ替え
- 🔄 いれかえ：いらないカードを選んで引き直す（1ターン1回）
- 🔍 みとおし：ダメージを先に見る（そのターンはチャレンジのボーナスなし）
- 文字は「ひらがな／漢字（ふりがな）／漢字」から選べる

## 開発

```sh
npx http-server -p 8123 -c-1 .   # リポジトリのルートで起動 → http://localhost:8123/arcanumber/
node arcanumber/tools/test_hands.mjs   # 役の判定
node arcanumber/tools/test_score.mjs   # スコア計算（順番による違いなど）
node arcanumber/tools/sim.mjs          # AI が何百回も冒険してバランスを確認
node arcanumber/tools/e2e.mjs          # ブラウザでロボットが通しプレイ（Playwright が必要）
```

```
arcanumber/
  index.html / css/style.css
  js/data/      cards（ルーン・スペル・インスタント・けっかい）, hands（役）, arcana, scrolls, enemies, heroes, events, quiz
  js/engine/    score（ちから×ばいりつ）, battle, run（マップ・報酬・お店）
  js/ui/        battle（スコア演出）, screens, modal, cardview, bg（うずまき背景）, fx
```
