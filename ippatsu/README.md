# いっぱつ しょうかん（仮）

小学1年生むけのカードゲーム（企画中）。

- **国語のテスト**で山札（＝HP）がふえ、**算数のテスト**でパワー（かけられる数）、**英語のテスト**でれんげき（かける数）が上がる
- テストのたびにカードパックをあけて、3まいから1まいえらぶ（点数が高いほど いいカードが出やすい）
- バトルは手札5まいからカードをくみあわせて、**パワー × れんげき** のダメージ。ボスは「いっぱつ」でたおさないとなおる
- サイコロ・コイン・ルーレットのカード、毎回くじで決まるボスのじゃくてん、あか・あお・みどりをそろえる「3きょうかコンボ」
- 3教科をそろえるとトロフィーがもらえ、特殊な効果のスペシャルカードがふえる

要件定義と企画は [`docs/DESIGN.md`](docs/DESIGN.md)。
