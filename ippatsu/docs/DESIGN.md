# いっぱつ しょうかん（仮） 要件定義メモ

小学1年生むけ。**テストをうけると召喚獣がつよくなり、カードをくみあわせてボスを「いっぱつ」でたおす** カードゲーム。

- 発想：「テストの点で召喚獣がつよくなる」×「かけ算」×「ワンターンキル（1ターンで決める）」
- 対象：小学1年生（ひらがなが読める〜読みはじめ。漢字は1年生で習う80字まで）
- 遊ぶ場所：家の iPad（横画面）。1日10〜15分
- ねらい：国語・算数・英語を **毎日すこしずつ、3教科まんべんなく** やりたくなる
- 第2版：「カードゲームとしての面白さとランダム性がないと1年生は飽きる」を受けて、バトルとごほうびを作り直した（6章・5章）

## 決定事項

| 項目 | 決定 |
|---|---|
| 国語のテスト | HP（＝山札のカードの枚数）がふえる |
| 算数のテスト | かけられる数（＝パワー）がふえる |
| 英語のテスト | かける数（＝れんげき）がふえる |
| 3教科そろえる | トロフィーがもらえ、特殊な効果のカード（スペシャルカード）がふえる |
| 対象 | 小学1年生 |
| いちばん大事にすること | **カードゲームとしての面白さとランダム性**。毎回ちがう手札、ドキドキする「運」の見せ場、カード集め |

数値・名前・細かいルールはすべて仮。まだ決まっていないことは 11章。

---

## 1. 1年生むけの前提

- **かけ算はまだ習っていない**（九九は2年生）。いきなり「×」を見せず、**「💪3 が 👊4かい」→ 3、6、9、12 と数えながら当たる** 演出にする。
  - これは2年生の教科書の「1つ分の数 × いくつ分」そのもの。**かけられる数＝1回のパワー（1つ分）、かける数＝れんげき（いくつ分）** とすると、教科書の意味とぴったり合う。
  - 式「3×4＝12」は小さく添える（2年生のかけ算の予告）。数える演出は1年生の「2とび・5とび」の数え方にもつながる。
- **英語は学校で習っていない**（外国語活動は3年生から）。文字は読ませず、**音を聞いて絵をえらぶ** だけにする。
- 文字はひらがな中心で、**問題・選択肢・ボタン・カードの説明をすべて読み上げる**。🔊 ボタンでいつでももう一度聞ける。
- カードの効果は **絵文字＋数字** だけでわかるようにする（💪+3、👊×2、🎲）。くわしい説明は読み上げで。
- 計算は子どもにさせない。カードを置くたびに **画面が計算して見せる**（数が変わるのを見ること自体が学び）。
- 操作はタップだけ（ドラッグや長押しが要る操作は置かない）。
- 負けても何も失わない。運が悪かったときの救いも用意する（6.5）。

## 2. コアループ

```
がっこう（ホーム）
  → テストをうける（国語／算数／英語。1回5問）
  → 点数で召喚獣がレベルアップ ＋ カードパックをあける（3まいから1まいえらぶ）
  → その日に3教科そろうとトロフィー → にじいろパック（スペシャルカード）
  → ボスにちょうせん：手札からカードをくみあわせて「いっぱつ！」
  → 勝つ：たからばこ ／ 負ける：「あと○！」と、どの教科できたえるかのヒント
```

ランダム性は **4か所** に置く：カードパック、毎ターンの手札、サイコロやコインのカード、ボスの「じゃくてん」のくじ。
テストの点が **ステータス（運に左右されない成長）**、カードが **運とドキドキ** を受けもつ。

## 3. 召喚獣とステータス

| ステータス | 中身 | 伸ばす教科 | はじめ（仮） |
|---|---|---|---|
| 📚 たいりょく | 山札のカードの枚数。これがHP（＝何回チャレンジできるか） | 国語 | 12まい |
| 💪 パワー（かけられる数） | 召喚獣のきほんのパワー。赤のカードで上のせ | 算数 | 1 |
| 👊 れんげき（かける数） | 召喚獣のきほんのれんげき。青のカードで上のせ | 英語 | 1 |

**ダメージ ＝（きほんのパワー＋カード）×（きほんのれんげき＋カード）× ボーナス**

- 最初に3つのタマゴから1つえらぶ（見た目だけで、強さは同じ）。名前をつけられる。
- 召喚獣のレベル（3つのステータスの合計）で見た目が進化する（3段階）。
- 召喚獣のキャラクターと世界観は、すべてこのゲームのために作る（12章）。

## 4. テスト

### 4.1 共通

- 1回5問。1問20点の **100点満点**。点数を大きく見せる（「100てん！」の演出）。1回2〜3分。
- 答え方：国語と英語は絵の選択肢（3〜4択）、算数はテンキー（アルカナンバーの「うでだめし」と同じ）。
- **🤔 わからない** ボタンを置く。押すと答えをやさしく見せて、次はやさしい問題にする（まちがいの音は鳴らさない）。
- まちがえたら正解とひとことの解説を見せる。
- 正解するとむずかしく、まちがえるとやさしくなる（アルカナンバーの「うでだめし」と同じ適応型）。
- **⭐ ボーナスもんだい**：ときどき金色の問題が出る（くじ）。正解するとパックがもう1つもらえる。

### 4.2 ごほうび

テスト1回で **2つ** もらえる。

1. **けいけんち**（運に左右されない成長）：点数がそのまま けいけんち。メーターがたまるとレベルアップ。
   - 国語：📚 そのとき あけるパックから **もう1まい** えらべる（山札が多くふえる）
   - 算数：💪 きほんのパワー +1
   - 英語：👊 きほんのれんげき +1
   - レベルが上がるほど要る点数がふえる。0点でも、うけただけで けいけんち +10。
2. **カードパック**（ランダム）：その教科の色のパックを1つあける。**3まい見て1まいえらび**、山札に入れる。
   - レア度は「ふつう」「✨きらきら」「🌈にじいろ」。点数が高いほど いいカードが出やすい。
   - **100点なら、3まいのうち1まいは きらきら以上が かならず出る。**
   - パックをあける演出（ふくろがやぶれて、カードが1まいずつめくれる）を大事にする。

### 4.3 問題の中身（1年生）

**国語**（絵をみて えらぶ）

| 段階 | 問題 |
|---|---|
| 1 | 絵にあう ことばをえらぶ（ひらがな。「ねこ」「いぬ」） |
| 2 | 小さい「っ」「ゃ・ゅ・ょ」、のばす音（「きって／きて」「でんしゃ／でんしや」） |
| 3 | カタカナのことば（「パン」「バス」） |
| 4 | 漢字のよみ（1年生の80字。山・川・日・月・火・水 …） |
| 5 | はんたいのことば・なかまのことば |
| 6 | 「は・を・へ」えらび（「わたし（は）がっこう（へ）いく」） |

**算数**（テンキーで こたえる。アルカナンバーのうでだめし レベル1〜4を流用）

| 段階 | 問題 |
|---|---|
| 1 | かずをかぞえる（10まで。絵が5こずつ並ぶ） |
| 2 | いくつといくつ（10になる組み合わせ） |
| 3 | 10までのたし算・ひき算 |
| 4 | くり上がり・くり下がり（20まで） |
| 5 | 大きな数（120まで）・とけい（なんじ・なんじはん） |

**英語**（音をきいて 絵をえらぶ）

| 段階 | 問題 |
|---|---|
| 1 | いろ（red, blue, yellow …） |
| 2 | どうぶつ（cat, dog, lion …） |
| 3 | かず（one〜ten） |
| 4 | くだもの・たべもの |
| 5 | あいさつ（Hello. / Good morning. → 場面の絵をえらぶ） |
| 6 | アルファベットの大文字（音をきいて文字をえらぶ） |

## 5. カード

カードは4色。**色が教科**で、色を見れば何をするカードかわかる。

| 色 | 教科 | 役わり |
|---|---|---|
| 🟥 あか | 算数 | 💪 パワー（かけられる数）をふやす |
| 🟦 あお | 英語 | 👊 れんげき（かける数）をふやす |
| 🟩 みどり | 国語 | 📚 カードをひく・まもる・山札をもどす。**3きょうかコンボに要る** |
| 🟨 きん | トロフィー | スペシャル。ルールをかえる |

## 6. バトル：くみあわせて、いっぱつ！

### 6.1 ルール

1. 山札をまぜて、**手札を5まい** ひく。ボスが出る。
2. **ボスの じゃくてん** を くじで決める（ルーレットがまわる。6.3）。
3. 手札から カードをえらんで **コンボのわく（3つ）** に置く。置くたびに「💪○ × 👊○ ＝ ○」が変わって見える。
4. **「しょうかん！」** を押すと、召喚獣が出てきて、カードが1まいずつ光る → 🎲がころがる・🪙がまわる → れんげきの回数だけ数えながら当てる。
5. **ボスは「いっぱつ」でたおさないと、すぐになおる**（毎ターンが1回勝負＝ワンターンキル）。
   - ダメージがボスのHP以上 → かち！
   - たりない → 「おしい！ あと ○！」。ボスのこうげきで 山札が1まい（ボスによって2まい）けずられる。
6. 使ったカードはすてる。使わなかったカードは手札にのこる（**つよいカードを次のターンまでとっておける**）。手札が5まいになるまでひいて、3へ。
7. 山札がなくなったら まけ（召喚獣がつかれて もどってくる）。

- **山札が多い（国語）ほど、チャレンジできる回数がふえる**。テストでえらんだカードの1まい1まいが、手札にまわってくる。
- **🌈 3きょうかコンボ**：あか・あお・みどりを1まいずつ わくに置くと **ダメージ ×2**。3教科をまんべんなく、がそのまま「つよい出し方」になる。
- わくは3つから。トロフィーを5こ集めると4つ、15こで5つにふえる（長い目標）。
- **🤖 おまかせ** ボタン：いちばんつよい組み合わせを置いてくれる。迷ったときや、つよい出し方を見て覚えるのに使う。
- 1回のバトルは2〜3分。れんげきが多いと演出が長くなるので、5回目からは速くする（タップでとばせる）。

### 6.2 評価とごほうび

- ★ かち ／ ★★ 3ターン以内 ／ ★★★ **1ターンめでたおした（ワンターンキル！）**
- 勝つと **たからばこ** が3つ出て、1つえらぶ（中身はカード・シール・パックのどれか）。
- 1ターンめでたおすと、たからばこが1つふえる。

### 6.3 ボスの じゃくてん（毎回くじで決まる）

毎回ちがうので、同じボスでも「きょうは🎲が大当たり」のように戦い方が変わる。

| じゃくてん | こうか |
|---|---|
| 🎲に よわい | サイコロの目が2ばい |
| 🐝に よわい | はちの れんげきが2ばい |
| 🟥／🟦／🟩に よわい | その色のカードのこうかが2ばい |
| 🌈に よわい | 3きょうかコンボが ×3 |

### 6.4 ボスの とくせい（ボスごとに決まっている。あとのステージで出る）

| とくせい | ルール | 必要になる教科 |
|---|---|---|
| かたい | パワーが5より小さいと きかない | 算数 |
| バリア | 最初の3回の当たりは バリアにふせがれる | 英語 |
| はやい | 1ターンに2まい けずる | 国語 |

### 6.5 運が悪かったときの救い

ランダム性は楽しさの中心だが、運だけで負けつづけると1年生はいやになる。

- 1回のバトルで1回だけ、手札をぜんぶ **ひきなおし** できる。
- 同じボスに3回つづけて負けたら、そのボスに強い **おうえんカード** を1まいもらえる。
- 負けても カードもステータスも へらない。
- 負けたら「あと ○ だった！ 💪パワーが たりないね。さんすうで きたえよう」のように、どの教科をやれば勝てるかを見せる。

### 6.6 試算（`tools/sim.mjs` の前の、ざっくりした自動対戦）

「いちばんダメージが大きい組み合わせを出す」方針で3000回ずつ試した。強さは毎日3教科をやったときの見こみ。

| 強さ（きほん パワー×れんげき・山札） | ボス（HP） | 勝つ割合 | 1ターンめで勝つ割合 |
|---|---|---|---|
| はじめ（1×1・12まい） | ボス1（8） | 99% | 88% |
| はじめ | ボス2（15） | 63% | 34% |
| 3日め（2×2・21まい） | ボス3（25） | 96% | 49% |
| 3日め | ボス4（35） | 73% | 28% |
| 3日め、でも国語をやらなかった（2×2・16まい） | ボス4（35） | 32% | 15% |
| 1しゅうかん（3×3・35まい） | ボス6（60） | 97% | 42% |
| 1か月（5×5・51まい・わく4） | ボス10（120） | 100% | 68% |

- 新しいボスに初めて挑むと「勝ったり負けたり」、勉強してくると安定して勝てる。
- 1ターンめで決まるのは3〜5割くらいで、毎回ドキドキする。
- 国語をやらないと山札がたりず、勝ちにくくなる（32% と 73%）。
- 後半は勝ちやすすぎるので、ボスのHPやとくせいで調整する。

## 8. おうちのひと向け

- 入り方：ボタンを3秒長押しして、大人むけの計算を1問とく（子どもが入りにくくする）。
- 教科ごとの点数の移り変わり、まちがえた問題、続けた日数。
- 設定：1日のテストの回数の上限、トロフィーの条件、読み上げの速さ、文字のモード、データの書き出し／読みこみ。

## 9. 非機能要件

- iPad の Safari・横画面が基準。スマホでも最低限遊べる。
- ブラウザだけで動く（インストール・ビルド不要）。ホーム画面に追加すればオフラインでも遊べる（PWA）。学校の iPad 用に Google Apps Script 版も作れるようにする（`gas/` と同じ）。
- セーブはブラウザ内（localStorage）に自動保存。書き出し／読みこみでバックアップできる。
- 個人情報を外に送らない。広告・課金・外部との通信なし（フォントの読みこみは除く）。パックやたからばこに **お金は一切からめない**。
- 読み上げは Web Speech API（端末の音声）。英語は英語の声を使う。端末に声がないときは画面で知らせる。
- ボタンとカードは指で押しやすい大きさ（目安 64px 以上）。1回のテストもバトルも5分以内で区切れる。
- 作りはこのリポジトリのほかのゲームと同じ：素の JavaScript（ES Modules）、絵は絵文字と SVG、音は WebAudio。
- ルール（バトル・成長・パック・問題の生成）は画面から分けて、Node でテストと自動プレイができるようにする。乱数はシードつき（テストで同じ結果を出せるように）。
- 流用するもの：`js/text.js`（ひらがな／漢字の切りかえ）、`js/audio.js`、アルカナンバーの「うでだめし」の問題生成と適応のしくみ。
