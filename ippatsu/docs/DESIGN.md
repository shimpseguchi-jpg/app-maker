# いっぱつ しょうかん（仮） 要件定義メモ

小学1年生むけ。**テストをうけると召喚獣がつよくなり、ボスを「いっぱつ」でたおす** カードゲーム。

- 発想：「テストの点で召喚獣がつよくなる」×「かけ算」×「ワンターンキル（一撃で決める）」
- 対象：小学1年生（ひらがなが読める〜読みはじめ。漢字は1年生で習う80字まで）
- 遊ぶ場所：家の iPad（横画面）。1日10〜15分
- ねらい：国語・算数・英語を **毎日すこしずつ、3教科まんべんなく** やりたくなる

## 決定事項

| 項目 | 決定 |
|---|---|
| 国語のテスト | HP（＝山札のカードの枚数）がふえる |
| 算数のテスト | かけられる数（＝パワー）がふえる |
| 英語のテスト | かける数（＝れんげき）がふえる |
| 3教科そろえる | トロフィーがもらえ、特殊な効果のカード（スペシャルカード）がふえる |
| 対象 | 小学1年生 |

数値・名前・細かいルールはすべて仮。まだ決まっていないことは 11章。

---

## 1. 1年生むけの前提（いちばん大事）

- **かけ算はまだ習っていない**（九九は2年生）。いきなり「×」を見せず、**「💪3 が 👊4かい」→ 3、6、9、12 と数えながら当たる** 演出にする。
  - これは2年生の教科書の「1つ分の数 × いくつ分」そのもの。**かけられる数＝1回のパワー（1つ分）、かける数＝れんげき（いくつ分）** とすると、教科書の意味とぴったり合う。
  - 式「3×4＝12」は小さく添える（2年生のかけ算の予告）。数える演出は1年生の「2とび・5とび」の数え方にもつながる。
- **英語は学校で習っていない**（外国語活動は3年生から）。文字は読ませず、**音を聞いて絵をえらぶ** だけにする。
- 文字はひらがな中心で、**問題・選択肢・ボタンをすべて読み上げる**。🔊 ボタンでいつでももう一度聞ける。
- 1年生は120くらいまでの数を習う。本編のボスのHPは **100まで** にする（大きな数は「おまけ」で）。
- 操作はタップだけ（ドラッグや長押しが要る操作は置かない）。1画面で1つのことだけ。
- 負けても何も失わない。「💪パワーが たりない！ さんすうで きたえよう」のように、**どの教科をやれば勝てるか** を教えてテストにつなげる。

## 2. コアループ

```
がっこう（ホーム）
  → テストをうける（国語／算数／英語。1回5問）
  → 点数で召喚獣がつよくなる（山札・パワー・れんげき）
  → その日に3教科そろうとトロフィー → スペシャルカードを1まいえらぶ
  → ボスにちょうせん（ためて、いっぱつ！）
  → 勝てない → ヒントの教科でまたテスト
```

**かけ算なので、1つだけ伸ばすより両方伸ばすほうが強い**（5×1＝5 より 3×3＝9）。
3教科をまんべんなくやる理由がルールそのものに入っている。試算では、同じ山札10まいでも「3×3」は HP30 のボスに77%勝てるが、「6×1」は50%にとどまる。

## 3. 召喚獣とステータス

| ステータス | 中身 | 伸ばす教科 | はじめ（仮） |
|---|---|---|---|
| 📚 たいりょく | 山札のカードの枚数。これがHP | 国語 | 6まい |
| 💪 パワー（かけられる数） | 1回のこうげきのつよさ | 算数 | 1 |
| 👊 れんげき（かける数） | こうげきの回数 | 英語 | 1 |

**ダメージ ＝ パワー × れんげき**

- 最初に3つのタマゴから1つえらぶ（見た目だけで、強さは同じ）。名前をつけられる。
- 3つのステータスの合計で見た目が進化する（3段階）。
- 召喚獣のキャラクターと世界観はすべてこのゲームのために作る（12章）。

## 4. テスト

### 4.1 共通

- 1回5問。1問20点の **100点満点**。点数を大きく見せる（「100てん！」の演出）。1回2〜3分。
- 答え方：国語と英語は絵の選択肢（3〜4択）、算数はテンキー（アルカナンバーの「うでだめし」と同じ）。
- **🤔 わからない** ボタンを置く。押すと答えをやさしく見せて、次はやさしい問題にする（まちがいの音は鳴らさない）。
- まちがえたら正解とひとことの解説を見せる。最後に「まちがえた問題をもう一度」ができる（点数は変わらない）。
- 正解するとむずかしく、まちがえるとやさしくなる（アルカナンバーの「うでだめし」と同じ適応型）。

### 4.2 点数とごほうび（仮）

点数はそのまま **けいけんち** になり、メーターがたまるとその教科のステータスが +1。
はじめは100点1回でレベルアップし、レベルが上がるほど要る点数がふえる。

| | 国語 | 算数 | 英語 |
|---|---|---|---|
| レベルアップ | 📚 山札 +1まい | 💪 パワー +1 | 👊 れんげき +1 |
| 100点のとき | 「100てん！」演出とけいけんちのおまけ | 同じ | 同じ |
| 0点でも | うけただけで けいけんち +10（「がんばったね」） | 同じ | 同じ |

国語でふえる山札のカードは「💪パワー+1」と「👊れんげき+1」をかわりばんこに入れる（6章）。

### 4.3 問題の中身（1年生）

**国語**（絵をみて えらぶ）

| 段階 | 問題 |
|---|---|
| 1 | 絵にあう ことばをえらぶ（ひらがな。「ねこ」「いぬ」） |
| 2 | 小さい「っ」「ゃ・ゅ・ょ」、のばす音（「きって／きて」「でんしゃ／でんしや」） |
| 3 | カタカナのことば（「パン」「バス」） |
| 4 | 漢字のよみ（1年生の80字。山・川・日・月・火・水 …） |
| 5 | はんたいのことば・なかまのことば |
| 6 | 「は・を・へ」えらび（「わたし（は）がっこう（へ）いく」） |

**算数**（テンキーで こたえる。アルカナンバーのうでだめし レベル1〜4を流用）

| 段階 | 問題 |
|---|---|
| 1 | かずをかぞえる（10まで。絵が5こずつ並ぶ） |
| 2 | いくつといくつ（10になる組み合わせ） |
| 3 | 10までのたし算・ひき算 |
| 4 | くり上がり・くり下がり（20まで） |
| 5 | 大きな数（120まで）・とけい（なんじ・なんじはん） |

**英語**（音をきいて 絵をえらぶ）

| 段階 | 問題 |
|---|---|
| 1 | いろ（red, blue, yellow …） |
| 2 | どうぶつ（cat, dog, lion …） |
| 3 | かず（one〜ten） |
| 4 | くだもの・たべもの |
| 5 | あいさつ（Hello. / Good morning. → 場面の絵をえらぶ） |
| 6 | アルファベットの大文字（音をきいて文字をえらぶ） |

## 5. トロフィーとスペシャルカード

- 条件：**同じ日に** 国語・算数・英語のテストをそれぞれ1回以上うける（1日1こまで。11章で相談）。
- ホームに3教科のスタンプ欄があり、終わった教科に はなまる がつく。
- トロフィーの色は、その日の3教科のいちばん良い点の合計で決まる：300点＝金、200点以上＝銀、それ以外＝銅。
- トロフィーをもらうと、**スペシャルカード3まいから1まいえらんで** 山札に入れる（金だと めずらしいカードが出やすい）。
- トロフィーは「トロフィーだな」に並ぶ。何日つづけたかもわかる。

### スペシャルカード（案）

| カード | こうか | ねらい |
|---|---|---|
| ✨ ばいばい | パワーが 2ばい | |
| 🌀 ダブル | れんげきが 2ばい | |
| 🌈 みんな+1 | パワーもれんげきも +1 | |
| ✋ 5のまとまり | パワー +5 | 1年生の「5・10のまとまり」 |
| 🔄 いれかえっこ | パワーとれんげきを入れかえる（ダメージはかわらない！） | 2年生で習う「かける数とかけられる数を入れかえても答えは同じ」。「かたい」ボス対策になる |
| 🛡️ まもり | つぎのボスのこうげきを1回ふせぐ | |
| 🍀 おかわり | すぐにもう1まいめくる（ボスはこうげきしない） | |
| 📖 しおり | すてられたカードを3まい山札にもどす | |
| 🐣 がんばりのたまご | 山札がのこり3まい以下なら パワー +3 | 逆転 |

## 6. バトル：ためて、いっぱつ！

### 6.1 ルール

1. 山札をまぜる。ボスが出る（HP・こうげき・とくせいを見せる）。
2. 自分の番に **「めくる」か「ひっさつ！」** をえらぶ。
   - **めくる**：山札の上から1まいめくる。カードのこうかは このバトルのあいだずっとつづく（💪パワー+1 など）。そのあとボスのこうげき：**山札の上から1まい（ボスによって2まい）すてられる**。
   - **ひっさつ！**：パワー × れんげき のダメージ。れんげきの回数だけ、1回ずつ数えながら当てる。
3. ボスのHPが0になれば かち。山札が0になれば まけ（召喚獣が つかれて もどってくる）。

- 画面にはいつも「いま ひっさつすると ○ ダメージ」と「ボスのHP ○」を並べて出す。**2つの数を比べて、どちらが大きいか** で決められる（1年生の学習の範囲）。
- ひっさつでたおしきれなかったとき（推し案）：ボスのHPは減ったまま、ためたこうかはリセットされて、続けられる。
- 評価：★ かち ／ ★★ 山札が半分以上のこった ／ ★★★ **ひっさつ1回でたおした（ワンターンキル！）**
- れんげきが多いと演出が長くなるので、5回目からは速くする（タップでとばせる）。

### 6.2 試算（`めくる`ほど山札がへる「チキンレース」）

方針「いまのダメージがボスのHP以上ならひっさつ」で2万回ずつ試した。山札はパワー+1とれんげき+1が半々。

| 強さ（山札・パワー×れんげき） | ボスHP | 勝つ割合 |
|---|---|---|
| はじめ（6まい・1×1） | 5 | 81% |
| はじめ | 10 | 0%（勉強しないと勝てない） |
| 8まい・2×2 | 15 | 94% |
| 10まい・3×3 | 30 | 77% |
| 10まい・6×1（かたより） | 30 | 50% |
| 10まい・3×3、ボスが2まいすてる | 30 | 0%（国語で山札をふやす必要） |
| 18まい・7×6 | 100 | 100% |

数値はつくるときに自動プレイ（`tools/sim.mjs`）で調整する。

## 8. おうちのひと向け

- 入り方：ボタンを3秒長押しして、大人むけの計算を1問とく（子どもが入りにくくする）。
- 教科ごとの点数の移り変わり、まちがえた問題、続けた日数。
- 設定：1日のテストの回数の上限、トロフィーの条件、読み上げの速さ、文字のモード、データの書き出し／読みこみ。

## 9. 非機能要件

- iPad の Safari・横画面が基準。スマホでも最低限遊べる。
- ブラウザだけで動く（インストール・ビルド不要）。ホーム画面に追加すればオフラインでも遊べる（PWA）。学校の iPad 用に Google Apps Script 版も作れるようにする（`gas/` と同じ）。
- セーブはブラウザ内（localStorage）に自動保存。書き出し／読みこみでバックアップできる。
- 個人情報を外に送らない。広告・課金・外部との通信なし（フォントの読みこみは除く）。
- 読み上げは Web Speech API（端末の音声）。英語は英語の声を使う。端末に声がないときは画面で知らせる。
- ボタンは指で押しやすい大きさ（目安 64px 以上）。1回のテストもバトルも5分以内で区切れる。
- 作りはこのリポジトリのほかのゲームと同じ：素の JavaScript（ES Modules）、絵は絵文字と SVG、音は WebAudio。
- ルール（バトル・成長・問題の生成）は画面から分けて、Node でテストと自動プレイができるようにする。
- 流用するもの：`js/text.js`（ひらがな／漢字の切りかえ）、`js/audio.js`、アルカナンバーの「うでだめし」の問題生成と適応のしくみ。

## 12. 権利について

- 「テストの点で召喚獣がつよくなる」という仕組みはアイデアとして借りる。もとの作品の名前・キャラクター・学校名・用語は使わない。
- 召喚獣・ボス・世界観・カードの名前は、すべてこのゲームのために作る。
