# アイドル迷宮（仮）

アイドルマスターのアイドルと楽曲を題材にした、エルミナージュ風のダンジョンRPG（開発準備中・非公式の二次創作）。

- アイドルは「イメージカラー：赤系」「高校生」「スポーツ好き」「インテリ」などの**属性**を持つ。属性は単体では効果がなく、パーティ内での**重複**や**組み合わせ**でシナジー（能力アップ・特殊能力）が発動する
- **楽曲**を装備すると、曲名にちなんだ特殊能力が付く

企画と設計は [`docs/DESIGN.md`](docs/DESIGN.md)。

## 今あるもの

- `index.html`：パーティ編成プロトタイプ。アイドルを選び、楽曲を装備すると、発動中のシナジー・あと少しで発動するシナジー・最終能力値が見られる
- `js/data/`：属性タグ・アイドル（765PRO ALLSTARS 13人）・シナジー・楽曲のデータ
- `js/engine/`：シナジー判定と能力値計算（画面から独立。Node でも動く）

## 動かしかた

リポジトリのルートで：

```sh
npx http-server -p 8123 -c-1 .
# → http://localhost:8123/idoldungeon/
```

## テスト

```sh
node idoldungeon/tools/test_synergy.mjs
```

データの整合性（未定義タグ、効果の形式、1人では発動しないこと など）、シナジー判定、能力値計算を確かめる。
