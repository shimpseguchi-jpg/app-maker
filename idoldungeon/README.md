# アイドル迷宮（仮）

アイドルマスターのアイドルと楽曲を題材にした、エルミナージュ風のダンジョンRPG（開発準備中・非公式の二次創作）。

- アイドルは「イメージカラー：赤系」「高校生」「スポーツ好き」「インテリ」などの**属性**を持つ。属性は単体では効果がなく、パーティ内での**重複**や**組み合わせ**でシナジー（能力アップ・特殊能力）が発動する
- **楽曲**を装備すると、曲名にちなんだ特殊能力が付く

企画と設計は [`docs/DESIGN.md`](docs/DESIGN.md)。

## 今あるもの

- `explore.html`：**迷宮探索**。エルミナージュ風の一人称ワイヤーフレーム迷宮を歩ける。オートマップ、扉・一方通行・シークレットドア・鍵・スイッチ・ダークゾーン・呪文禁止エリア・ピット・シュート・ワープ・泉、徘徊する敵・ルームガーダー・固定敵・ボス
- **戦闘**：エルミナージュ風のコマンド戦闘（戦う・呪文・ライブ・守る・かばう・逃げる・おまかせ）。射程 S/M/L、不確定名、先制・不意打ち、経験値とレベルアップ
- **街**：酒場（パーティ編成・楽譜の装備・まとめて鑑定）、宿屋（泊まるとレベルアップ）、商店（売買・鑑定）、寺院（蘇生・死体回収・寄付）、訓練所（転職・昇格）、城（モンスター図鑑）、記録（記録枠・書き出し）
- `party.html`：パーティ編成の試し場。アイドルと楽曲を自由に選んで、シナジー・能力値を確かめられる（冒険のパーティは街の酒場で組む）
- `js/data/`：属性タグ・アイドル（765PRO ALLSTARS 13人）・シナジー・楽曲・クラス（下位職15・上位職22）・昇格アイテム・ボス・ダンジョンのマップ・敵・呪文
- `js/engine/`：シナジー判定・能力値計算・転職と昇格・蘇生・ボスの再戦・探索と戦闘のルール（画面から独立。Node でも動く）

操作：↑/W 前進、←→/A D 向きを変える、↓/S 後ろを向く、Q E 横歩き、Space/F 調べる、Enter 階段

## 動かしかた

リポジトリのルートで：

```sh
npx http-server -p 8123 -c-1 .
# → http://localhost:8123/idoldungeon/
```

## テスト

```sh
node idoldungeon/tools/test_synergy.mjs   # シナジー・能力値・転職と昇格・昇格アイテム・ボスの再戦・蘇生
node idoldungeon/tools/test_dungeon.mjs   # マップの検査（外周の穴・階段のずれ・全マスに行けるか）と探索ルール
node idoldungeon/tools/test_battle.mjs    # 戦闘ルール（射程・逃げる・かばう・呪文・状態異常・特殊能力・経験値）
node idoldungeon/tools/test_town.mjs      # 街（酒場・宿屋・商店・寺院・訓練所・城・記録）と全滅・死体回収
node idoldungeon/tools/sim_battle.mjs     # 自動対戦で全滅率を測る（バランス調整用）
node idoldungeon/tools/e2e_explore.mjs    # ブラウザで入口からボスまで通しで遊ぶ（Playwright と http-server が必要）
```
