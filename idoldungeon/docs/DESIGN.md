# アイドル迷宮（仮） 企画・設計メモ

アイドルマスターのキャラクターと楽曲を題材にした、エルミナージュ（1・2・3）風のダンジョンRPG。
非公式の二次創作として、個人で楽しむ範囲で作る。

- ジャンル：3D疑似視点（一人称・グリッド移動）のダンジョンRPG。パーティ制・ターン制
- モチーフ：エルミナージュ 〜闇の巫女と神々の指輪〜／II 〜双生の女神と運命の大地〜／III 〜暗黒の使徒と太陽の宮殿〜
- 独自要素：**属性シナジー**（アイドルの属性の重複・組み合わせ）と**楽曲装備**（曲名にちなんだ特殊能力）
- 世界観：アイドルたちが演じる**作中劇**という建てつけ。プロデューサーは登場人物にもパーティにも入らない
- 登場アイドル：まず 765PRO ALLSTARS の13人。ゆくゆくは 765PRO 以外のブランドにも広げる

## 決定事項

| 項目 | 決定 |
|---|---|
| クラスと転職 | エルミナージュを踏襲。さらにファイアーエムブレム 聖魔の光石のクラスを加え、**下位職と上位職**を設ける（7章） |
| 登場アイドル | ゆくゆくは 765PRO 以外も入れる |
| プロデューサー | パーティに入れない。冒険は作中劇の一環 |
| 戦闘不能 | エルミナージュを踏襲。ただし**ロストはなし**（8章） |
| 持ち歌ボーナス | 765PRO 以外に広げるときに入れる。**個人曲・ユニット曲・全体曲**でボーナスに濃淡をつける（5章） |
| 昇格アイテム | **ボスのドロップと店売り**（7.5） |
| ボス | ダンジョンクリア後も、**強化されて再出現**する（9章） |
| フロアマスター | 入れない（見える敵の徘徊・追跡は省く） |
| 1つめの本番ダンジョン | 「奈落の大劇場（仮）」地下5階・20×20。最初の小さな迷宮のボスを倒すと行ける（10.4） |

## 1. コアループ

```
街で編成・装備・鑑定・休息
  → ダンジョン探索（地図を埋める・罠・宝箱・イベント）
  → 戦闘（6人パーティ vs 敵グループ）
  → 戦利品（未鑑定の楽譜・装備・ゴールド）を持ち帰る
  → 成長（レベルアップ・クラスチェンジ）→ さらに深い階層へ
```

## 2. エルミナージュから引き継ぐ要素

| エルミナージュ | 本作での形 | 状態 |
|---|---|---|
| 6人パーティ・前列3／後列3 | そのまま。前列だけが近接攻撃を受ける・行う | `party.js` で前列/後列を判定済み |
| 種族×職業×性格（光・中立・闇） | アイドルは固定キャラ。**属性タグ**が種族・性格の役割を担う | 属性タグ定義済み |
| 職業・転職 | エルミナージュ式の転職＋聖魔の光石式の昇格（下位職→上位職） | `classes.js` に定義済み |
| 呪文の回数制（休むまで回復しない） | 楽曲の**ライブスキル**（`uses` 回／休息まで） | データ定義済み |
| 未鑑定アイテム・鑑定 | 「？？？の楽譜」として拾い、街の店（有料）か酒場のビショップ（無料）が鑑定すると曲名がわかる | 済（12章） |
| 宝箱の罠・解除 | そのまま（盗賊役＝いたずら好き系のクラス） | 未着手 |
| ワイヤーフレームの迷宮・オートマッピング | Canvas で一人称視点＋マップ | 未着手 |
| ダークゾーン・回転床・テレポーター・落とし穴 | そのまま。楽曲やシナジーで対策できる（例：蒼い鳥で落とし穴無効） | 済（10章） |
| 召喚（モンスターを仲間に） | サマナー（上位職）、「いきものがかり」シナジーのペット召喚 | 効果テキストのみ |
| 死亡・灰・ロスト | 死亡と灰はそのまま。**ロストはなし**（灰の蘇生に失敗しても灰のまま） | `revive.js` に定義済み |
| 年齢 | 扱わない（アイドルの年齢は固定） | 方針 |
| 時代・世界の移動（III） | 章ごとにテーマの違うステージ（ダンジョン）を巡る構成 | 案のみ |

## 3. 能力値

エルミナージュの6能力をアイドル風に読み替える（`js/engine/party.js`）。

| 本作 | 対応 | 主な使い道 |
|---|---|---|
| パワー `pow` | 力 | 物理攻撃（`atk`）、HP |
| ボーカル `vo` | 知恵 | 魔法攻撃（`mat`） |
| メンタル `men` | 信仰 | 魔法防御（`res`）、回復 |
| スタミナ `sta` | 生命力 | HP、防御（`def`） |
| ダンス `dan` | 素早さ | 行動順（`spd`）、命中、回避 |
| ビジュアル `vis` | 運 | 会心、回避、魅了系の成功率 |

派生ステータス：HP・攻撃・魔力・防御・魔防・命中・回避・素早さ・会心。式は仮（戦闘エンジンを作るときに調整）。

## 4. 属性シナジー（本作の中心）

### 4.1 属性タグ

アイドルはそれぞれ複数の属性タグを持つ（`js/data/tags.js`, `js/data/idols.js`）。**タグ単体には効果がない**。

| 分類 | 例 |
|---|---|
| イメージカラー（1人1つ） | 赤系・青系・緑系・黄系・紫系・桃系・白系・黒系 |
| 学年区分（1人1つ） | 中学生・高校生・大人 |
| 性格・趣味 | 元気・クール・インテリ・スポーツ好き・お嬢様・天然・料理上手・双子 … |
| 出身 | 南国育ち |
| ユニット | 竜宮小町 |

### 4.2 シナジーの種類（`js/data/synergies.js`）

| 種類 | 発動条件 | 例 |
|---|---|---|
| `count` 重複 | 同じタグを持つメンバーが n 人以上。人数が増えると段階が上がる | 赤系2人「紅蓮のカラー」攻撃+10% → 3人で+20%と炎属性 |
| `combo` 組み合わせ | 違うタグを**別々のメンバー**がそろえる（1人で全部持っていても不成立） | スポーツ好き＋インテリ「文武両道」、お嬢様＋家庭的「身分違いの友情」 |
| `distinct` 多様性 | ある分類のタグが何種類そろったか | イメージカラー5色以上「虹色ステージ」全能力+1 |

- 「同じ色でそろえて特化する」か「全員バラバラの色で虹色ステージを狙う」かで、編成の方向性が分かれるようにする。
- 効果の届く範囲：全員（party）／条件を満たしたメンバー（holders）／前列（front）／後列（back）。
- 能力値の補正（`stat`）と、戦闘・探索で参照する特殊能力（`ability`）の2種類。特殊能力の中身は戦闘エンジンで実装する。
- 画面には「あと1人（あと1タグ）で発動」も出して、編成を考える手がかりにする。

### 4.3 今のロスターでの注意

紫系・桃系・白系・黒系は 765PRO の13人ではそれぞれ1人しかいないため、同色シナジーは発動しない（`node idoldungeon/tools/test_synergy.mjs` が警告を出す）。
組み合わせ（例：白系＋黒系「モノクローム」）では使える。アイドルを追加する（他ブランドなど）と発動できるようになる。

## 5. 楽曲装備（`js/data/songs.js`）

- 各アイドルに**楽曲スロットが1つ**。曲名のイメージにちなんだ効果が付く。歌詞は扱わず、曲名だけを使う。
- 効果の形はシナジーと同じ（`stat` / `ability`。範囲は self・party・front・back）。
- 一部の曲には**ライブスキル**（休むまで `uses` 回使える技。エルミナージュの呪文回数制にあたる）。
- ランク（★1〜5）で、出現する階層と価格の目安にする。

| 曲名 | 効果のイメージ |
|---|---|
| READY!! | 戦闘1ターン目は必ず先手 |
| GO MY WAY!! | 素早さアップ・逃走しやすい |
| おはよう!!朝ご飯 | 休息明けのHP上乗せ |
| 蒼い鳥 | 回避アップ・落とし穴やダメージ床が無効 |
| 太陽のジェラシー | 通常攻撃が炎属性 |
| エージェント夜を往く | 暗闇で不意打ちされない・罠解除 |
| 自分REST@RT | 探索中に1度だけ自動復活 |
| CHANGE!!!! | 行動を消費せずに隊列を入れ替える |
| THE IDOLM@STER | 発動中の「人数で段階が上がる」シナジーを1人分多く数える |

（全21曲は `songs.js` 参照）

**持ち歌ボーナス**（765PRO 以外のアイドルを加えるときに入れる）：
- 原曲を歌ったアイドルが装備すると効果が強まる。曲に `credit: { type, singers }` を持たせる予定
- 強さに濃淡をつける：**個人曲（ソロ）＞ ユニット曲 ＞ 全体曲**（例：効果量 +50% ／ +30% ／ +15%。数値は仮）
- 全体曲は歌い手が多いので、ボーナスを受けられる人は多いが効果は控えめ、という釣り合い

今後の案：
- **未鑑定の楽譜**：拾った直後は「？？？の楽譜」。鑑定で曲名がわかる（12章で実装）
- **セットリスト**：パーティ全員の曲の並びで追加効果（例：同じアルバムの曲がそろう）

## 6. 世界観：作中劇

- 冒険はアイドルたちが演じる劇（作中劇）という建てつけ。アイドルは役（クラス）を演じる
- プロデューサーは登場しない。パーティにも入らない。街の施設（宿・店・寺院など）はすべて劇中の世界のもの
- 死亡・灰などの言葉もエルミナージュのまま使う（劇中の出来事なので、アイドルを本当に失う要素は置かない）

## 7. クラス（`js/data/classes.js`, `js/engine/classes.js`）

エルミナージュの転職を土台にして、聖魔の光石の「下位職から2択で上位職へ昇格」を加える。

### 7.1 転職（エルミナージュ式）

- 基本能力が**クラスごとの条件**を満たせば、街で転職できる（下位職すべてと、エルミナージュの上級職：侍・忍者・ロード）
- 転職すると **Lv1・経験値0 に戻り、基本能力はアイドル本来の値に戻る**
- **覚えた魔法は引き継ぐ**（罠解除などのクラス技能は引き継がない）

### 7.2 昇格（聖魔の光石式）

- 下位職で **Lv10 以上**になり、今のクラスに合う昇格アイテムを使うと、**2つの上位職から1つ**を選んで昇格できる
- 昇格すると Lv1・経験値0 に戻るが、**基本能力はそのまま残り、上位職ごとの昇格ボーナスが足される**
- HP や攻撃力の計算には「実質のレベル」＝今のクラスのレベル＋これまでのクラスで積んだレベル（上限20）を使う。昇格・転職で Lv1 に戻っても弱くなりすぎない（`js/engine/party.js` の power）
- 魔法は引き継ぐ。踊り子は昇格しない特別職

## 8. 戦闘不能と蘇生（`js/engine/revive.js`）

エルミナージュを踏襲し、ロストだけを取り除く。

| 状態 | 戦えるか | 治しかた |
|---|---|---|
| 毒・睡眠 | 戦える（睡眠中は行動できない） | 魔法・薬・時間 |
| 麻痺・石化 | 戦えない | 回復魔法・寺院 |
| 死亡 | 戦えない | 蘇生魔法・寺院。**失敗すると灰** |
| 灰 | 戦えない | 寺院。**失敗しても灰のまま**（お金だけ失う。ロストはしない） |

- 蘇生の成功率はスタミナ（エルミナージュの生命力）で上がる。数値は仮
- 全員が戦えなくなると全滅。死体はその場に残り、寺院の死体回収（有料）か、別のアイドルで組んだパーティで回収しに行く（12章）

## 9. ボスと再戦（`js/data/bosses.js`, `js/engine/boss.js`）

各ダンジョンの最深部にボスがいる。倒してダンジョンをクリアした後も、**強化されて再出現**する。

| 再戦 | 強さ | 追加の特性（例） | 報酬 |
|---|---|---|---|
| 初戦 | 基準 | なし | 系統別の昇格アイテム（確定）、マスタープルフ（10%）、ゴールド、楽曲 |
| 1回目 | 能力 +30%、Lv +5 | 連続行動 | マスタープルフ 20%、ゴールド +50%、楽曲ランク +1 |
| 2回目 | 能力 +60%、Lv +10 | ＋状態異常・即死が効かない | マスタープルフ 30%、… |
| 3回目以降 | さらに上昇 | ＋取り巻きを呼ぶ | マスタープルフは最大 50%、楽曲ランクは★5まで |

- 強化の倍率・確率はすべて仮。戦闘エンジンとあわせて調整する
- 再戦は、昇格アイテムを集める場、育ったパーティの腕試しの場にする
- 何回倒したかはボスごとに記録する（セーブデータに持たせる）

## 10. ダンジョン探索（`js/data/floors.js`, `js/engine/dungeon.js`）

エルミナージュ1・2・3を土台にする。参考：
[1（PSP）](https://spoiler.sakura.ne.jp/srv/el1psp/)・[2（DS）](https://spoiler.sakura.ne.jp/srv/el2ds/)・[3](https://spoiler.sakura.ne.jp/srv/el3/) の攻略 wiki

### 10.1 参考サイトから拾ったエルミナージュの特徴

- 格子状のマップを一人称で歩く。位置は **X・Y 座標**（例：X05 Y00 が入口）で示される。1つの階はおよそ 18〜20 マス四方
- 1F の入口から地下へ潜る。階段は上下の階で同じ座標にある
- 扉、**一方通行の扉**、**シークレットドア**（盗賊の技能で見つかる。片側からしか見つからないものもある）、**鍵のかかった扉**、**スイッチで開く扉**
- **ダークゾーン**（照明・マップが使えず、戦闘中も敵が見分けられない）、**呪文禁止エリア**
- **ワープ**（当たり・はずれがある）、**シュート**（下の階へ落ちる）、**ピット**（落とし穴）
- **回復の泉**（マイナス効果の泉もある）、イベントのマス
- 敵：**ワンダリングモンスター**（歩くとランダムに出る。宝箱なし）、**ルームガーダー**（部屋で待ち伏せ。必ず宝箱）、**何度でも戦える固定敵**、ボス、フロアマスター（見える敵。徘徊や追跡をする。**本作では入れない**）、モンスタージェネレーター
- 「天使の小窓」（合成で作るアイテム）を持つとミニマップが常に表示される
- 全滅すると死体はその場に残る。寺院の死体回収（有料）か、救助隊を組んで回収する
- 帰還は徒歩か、帰還・転移の呪文

### 10.2 実装したもの

| 要素 | 本作での扱い |
|---|---|

## 11. 戦闘（`js/engine/battle.js`, `js/data/enemies.js`, `js/data/spells.js`）

エルミナージュ1（PSP）の攻略 wiki の初心者ガイドを参考にした。

### 11.1 流れ

1. 敵は1〜4グループで現れる。正体が分かるまでは**不確定名**（例：「黒い人影」）。知恵（ボーカル）が高いほど、ビショップ（鑑定）がいるほど分かりやすい。ダークゾーンでは分からない
2. ときどき**先制**（敵が1ターン動かない）や**不意打ち**（こちらが1ターン動けない）が起きる。パーティの素早さの平均が敵より高いほど先制しやすく、不意打ちされにくい（先制 4〜30%、不意打ち 3〜25%）。ボスは不意打ちしない
3. 全員のコマンドを決めてから、**素早さ＋運の順に1人ずつ行動する**。行動順は毎ターン決め直し、「素早さ＋0〜10 の乱数」が大きい順。素早さが 10 以上違えば速いほうが必ず先に動き、近ければ入れ替わることもある。「守る」「かばう」は行動順に関係なく、ターンの最初から効く。「おまかせ」で残り全員の行動を自動で決められる
   - 素早さ＝ダンス×2＋レベル（敵は固定）。コマンドを選ぶときに、その人の素早さを表示する
   - 画面では、エルミナージュのように行動を1人ずつ見せる。いま動いている人（敵）を光らせ、与えた・受けたダメージの数字を出し、左上に**そのターンの行動順**を並べる（済んだ人は暗く）。画面を押す・Space・Enter で次へ、「とばす」・Esc でターンの終わりまで飛ばす
4. 敵を全滅させると、経験値は**生き残った人で山分け**、ゴールドは全額。ルームガーダーは宝箱（ゴールドと、ときどき未鑑定の楽譜）、ボスは昇格アイテムと未鑑定の楽譜。経験値はためておき、**宿屋に泊まったときにレベルが上がる**

### 11.2 コマンド

| コマンド | 内容 |
|---|---|
| 戦う | 射程の届く敵グループを選んで攻撃。戦士系はレベルとともに攻撃回数が増える（8 レベルで1回ぶん。そのあいだは確率でなめらかに） |
| 呪文 | 覚えた呪文（系統ごとの回数制。宿屋で全快）。呪文禁止エリア・沈黙中は効かない |
| ライブ | 装備した楽曲のライブスキル（休むまでの回数制） |
| 守る | 自分の受けるダメージを半分に |
| かばう | 仲間1人を選び、その仲間への攻撃を代わりに受ける |
| 逃げる | **選んだ人だけが逃げる**。残った人で戦闘は続き、全員逃げると終わる。ボス戦は逃げられない |
| 踊る | 踊り子のみ。仲間1人がもう一度攻撃する |
| ユニットライブ | 竜宮小町の3人がそろって動けるとき、1戦闘に1回。敵全体に大ダメージ |

### 11.3 射程（エルミナージュ準拠。武器を作るまではクラスで決める）

| 射程 | 届く敵 | クラス |
|---|---|---|
| S | 目の前のグループだけ | 戦士・剣士・盗賊・魔法職など |
| M | 2グループ目まで | アーマーナイト・ソシアルナイト・ペガサスナイト・ドラゴンナイトと、その上位職 |
| L | すべて | アーチャー・ウォーリア・スナイパー・レンジャー |

- **後列からは1つ短くなる**（後列の S は届かない、後列の M は1グループ目だけ）
- 前のグループを全滅させると、後ろのグループが繰り上がる
- 敵の通常攻撃は前列をねらう（前列が全員倒れると後列）

### 11.4 呪文（本作オリジナルの名前）

| 系統 | Lv1 | Lv2〜3 | Lv4〜 |
|---|---|---|---|
| 理魔法（魔道士など） | 炎の矢 | 吹雪（Lv3） | 流星（Lv7） |
| 回復魔法（僧侶など） | 癒やし | 浄化（Lv2） | 祝福の光（Lv5）・蘇生（Lv9。失敗すると灰） |
| 闇魔法（シャーマンなど） | 闇の矢 | 眠りの霧（Lv2） | 沈黙の帳（Lv4） |
| 錬金術（錬金術師） | 毒ガス | 撤収の煙（Lv3。全員確実に逃げる） | 酸の雨（Lv6） |

### 11.5 状態異常

毒（ターンごと・歩くたびに減る）、睡眠（行動できない。攻撃されると起きる）、沈黙（呪文・ライブが使えない）、麻痺・石化（戦えない）、死亡、灰。敵には混乱（仲間を攻撃する）もある。

### 11.6 戦闘で働くシナジー・楽曲・クラスの特殊能力

| 能力 | 出どころ | 効果 |
|---|---|---|
| ツインアタック | 双子（亜美・真美） | 2人が同じグループを攻撃すると威力 1.5 倍 |
| かばう | 王子様とお姫様 | お嬢様への攻撃を、ボーイッシュなメンバーが 50% で代わりに受ける |
| 芽吹き | 緑系3人 | 毎ターン HP 5% 回復 |
| 雷のステップ | 黄系3人 | 先制しやすい |
| 不思議空間 | ミステリアス＋天然 | 戦闘開始時、敵1グループを 30% で1ターン封じる |
| ユニットライブ | 竜宮小町 | 上の表 |
| スタンバイOK／スタートダッシュ | READY!!／スタ→トスタ→ | 1ターン目に必ず先に動く |
| ふるふる | ふるふるフューチャー☆ | 25% で2回攻撃 |
| 目が逢う瞬間・ときめき | 楽曲・桃系3人 | 攻撃時 10% で敵を混乱 |
| リスタート | 自分REST@RT | 探索中1度だけ、倒れても HP1 で立ち上がる |
| ポジティブ | ポジティブ！ | 眠らない |
| となりで | 隣に… | 同じ列の隣の仲間への攻撃を 30% で代わりに受ける |
| 首切り・瞬殺 | 忍者・アサシン | 5% で即死 |
| 貫通 | ワイバーンナイト | 15% で防御を無視 |
| 索敵 | レンジャー | 不意打ちされない |

属性攻撃（炎・氷など）、ペット召喚、見守りなど、まだ効果のない能力もある（敵に属性を持たせるときに入れる）。

### 11.7 バランス

2つの道具で調整する。

- `tools/sim_battle.mjs`：おまかせ作戦の自動対戦をくり返して、休まず5連戦したときの全滅率を測る
- `tools/sim_play.mjs`：Lv1 から最後のボスまで、ゲームのルールどおりに自動で遊ぶ（街で治療・宿屋・昇格、レベルに見合う階まで潜って戦い、危なければ逃げ、HP が減れば引き返す。全滅したら寺院か救助隊で回収）

| 相手 | 目安のレベル | 全滅率（5連戦。ボスは1戦） |
|---|---|---|
| 劇場地下迷宮 1F / B1F / B2F | Lv1 / Lv4 / Lv7 | 約11% / 13% / 20% |
| 迷宮の番人 | Lv7 | 約16% |
| 奈落の大劇場 1F / B1F / B2F / B3F / B4F | Lv10 / 12 / 12〜14 / 15 / 17 | 約12% / 11% / 27〜2% / 17% / 17% |
| 奈落の怪人 | Lv20 / 22 | 約39% / 4% |

自動プレイ（6回）では、どれも最後のボスまで倒せた。迷宮の番人は戦闘100〜250回ほど・平均 Lv7〜12 で、奈落の怪人は奈落の大劇場で戦闘130〜250回ほど・実質 Lv23〜27 で倒している（自動プレイは慎重に引き返すので、人が遊ぶより時間がかかる）。

調整のなかで、次も決めた。

- 能力値から攻撃力・HP などを出す式（`js/engine/party.js` の `derive`）は「Lv1 は控えめで、レベルとともに伸びる」
- 経験値の表は Lv2 に 50、Lv10 に 2,610、Lv20 に 11,210（`js/engine/growth.js`）
- 攻撃回数は確率でなめらかに増やす（ある Lv で急に強くなる段差をなくした）
- 詰み防止：馬小屋でも HP が1割戻る。だれも動けずお金もないときは、寺院が1人だけ無料で蘇生・回収してくれる（寺院の慈悲）

## 12. 街（`js/engine/town.js`, `js/ui/town.js`, `js/save.js`）

エルミナージュ1・3 の攻略 wiki の「街・施設」を参考にした。施設はタブで切り替える。

| 施設 | できること |
|---|---|

| 宿屋 | 馬小屋（無料・HP 1割と呪文・ライブの回数）、エコノミー（1人10G・HP半分と毒）、スイート（1人40G・HP全快と毒）。**ためた経験値で、泊まるとレベルが上がる** |

| 遊び方 | 冒険の流れ、装備（楽譜）、昇格アイテム、パーティの組み方、2つのモード、戦闘、全滅したときの説明。タイトルの「遊び方」（`explore.html#help`）からも開ける |

- **全滅**すると、死体はその場に残る。取り残された仲間は酒場でパーティに入れられない。寺院でお金を払うか、別のアイドルで組んだパーティでその場所へ行けば連れて帰れる（パーティに空きが必要）

- 最初は楽譜「READY!!」「おはよう!!朝ご飯」を持っている
- 各施設の板のいちばん上に、その施設でできることを1行で出す
- パーティの組み替えなどで最大 HP が上がったときは、今の HP も同じだけ上がる（下がったときは最大値に合わせる）

エルミナージュ ORIGINAL・ゴシックのストアページのスクリーンショット（Steam）を見て、画面の組み立て方だけを借りる。絵や素材は使わない。

- **迷宮**：一人称の絵を画面いっぱいに出し、その上に重ねる
  - 左上：小さな地図（こげ茶の方眼に、歩いたマスをオレンジで塗る）。押すと大きい地図（座標の数字つき）。M キーでも開く
  - 地図の横：方角（針と「北・東・南・西」。ダークゾーンでは「？」）
  - 右上：場所の札（迷宮の名前と階・座標）
  - 下：6人の顔の札（名前・顔・状態・Lv・大きな数字の HP とゲージ）
- **メッセージ**：画面の下に枠つきの窓。街では施設の人の名札とひとこと
- **コマンド**：斜めに切った青緑の帯（選んでいるものは明るく）。街の施設も、戦闘のコマンドもこの形

- **顔アイコン**：公式の絵の代わりに、イメージカラーの丸い光と髪型の形（リボン・眼鏡・ツインテールなど）だけで描く

## 17. 2つのモード：DRPGモードとカードモード

迷宮は2つの遊び方で挑める。じっくり歩いて地図を埋める **DRPGモード**（今までの迷宮）と、Reigns のようにカードを左右に振って進む **カードモード**。街・パーティ・お金・アイテム・セーブは共通で、迷宮に入るときにモードを選ぶ。

### 17.1 解放と報酬

- カードモードは迷宮ごとに、**その迷宮のボスを DRPGモードで倒すと**遊べるようになる
- **DRPGモードのボーナス**：経験値・お金・楽譜の見つかる確率が、カードモードの **1.5倍**
  - 今までの数値（11.7 で調整済み）を DRPGモードの値とし、カードモードはその 2/3 にする（調整し直さずに済む）
  - 戦闘の結果に「DRPGボーナス」の内訳を出す（例：経験値 90 ずつ（ボーナス ＋30））

### 17.2 DRPGモード

今までの迷宮（10章・11章）。スマホでは「DS二画面型」の画面にする。

- 上：迷宮の絵（場所の札・方角・メッセージを重ねる）
- 中：6人の帯（名前・顔・HP・ゲージ。いつも見える）
- 下：さわる画面。地図と、所持金・持ち物・ボタンを左右に並べ、その下に操作ボタン。操作するものはすべて下半分（親指の届く範囲）に置く
- 出発は街の「迷宮へ」から。迷宮ごとに DRPGモード／カードモードのボタンを並べる
- 戦闘：上に敵、下にコマンドを2列の大きなボタンで
- 街：施設の中身だけスクロールし、施設のボタンは下に固定
- 画面の高さを端末に合わせ（100dvh・セーフエリア）、探索と戦闘ではページをスクロールさせない

### 17.3 カードモード（Reigns 型。`js/data/cards.js`, `js/engine/cards.js`）

1回の挑戦で、迷宮の1階から最下階のボスまで進む。見せ方はテキストだけ（カードに絵は使わない）。

- **1つの階**：決まった枚数のカードを引くと階段が出る（劇場地下迷宮は 3階×7枚、奈落の大劇場は 5階×7枚）。最下階では階段の代わりにボス
  - 階段カード：左＝この階をもっと探る（3枚増える）、右＝下りる
  - 道順カードで選んだ道の手がかりに合うカードが、次に出やすくなる（5倍）
- **上のゲージ**：パーティの残り HP（％）1本。答えのボタンに指をのせる・カードを傾けると、HP が動く答えならゲージの上に点が出る（大きさ＝量。増えるか減るかは見せない）
- **相談に来るアイドル**：内容に合うクラス・属性の子が来やすい（宝箱は盗賊、泉は僧侶など）。台詞はイベントごとに1つで、名前だけ差し替える

| カード | 左 | 右 | 内容 |
|---|---|---|---|
| 道順 | 左の道 | 右の道 | 手がかり：水の音（泉・穴・食材）、足音（敵・番人）、かすかな光（宝箱・小部屋・舞台）、冷たい風（紋様・ダークゾーン・呪文禁止）、話し声（迷子・謎かけ・猫）、崩れる音（瓦礫・鍵の扉・穴） |
| 敵 | 避ける | 戦う | 敵は DRPG のその階と同じ出現表。避けるのは素早さの差で判定（15〜90%）。失敗すると不意打ち |
| 番人 | 通り過ぎる | 挑む | その階のルームガーダー（DRPG と同じ強さ）。勝つと宝箱。1つの階に1回まで |
| ボス | 街へ戻る | 挑む | 勝てば踏破。拾った物は全部持ち帰る |
| 宝箱 | そっとしておく | 開ける | 盗賊系がいれば罠を外す。いなければ 35% で爆発（全員に小ダメージ） |
| 泉 | 飲まない | 飲む | 70% で HP 回復、30% で濁った水（小ダメージ）。僧侶系がいれば濁った水を見分けて飲まない |
| 穴 | 回り道 | 飛び越える | 飛べる子は落ちない。ほかはダンスで判定して、落ちると大ダメージ。回り道は1枚に数えない |
| 鍵の扉 | 通り過ぎる | 鍵を開ける | 盗賊系なら開いて宝。いなければ半分で開かず、半分で物音を聞いた敵が来る |
| 小部屋 | 先を急ぐ | 休む | HP 25% 回復。25% で襲われる（不意打ち） |
| ダークゾーン | 手探りで進む | 歌で照らす | 歌（ライブの回数）を1つ使えば明るくなる。ダークゾーンの3枚は手がかりも敵の正体も見えず、戦闘も暗がり |
| 呪文禁止 | 回り道 | 突っ切る | 3枚のあいだ、戦闘で呪文が使えない |
| 光る紋様 | 避ける | 乗る | 半分で2枚先へ、半分で2枚戻される |
| 瓦礫 | 回り道 | 押し通る | 元気・スポーツ好きが2人いれば押しのけて宝。いなければ手を痛める |
| 迷子 | 先を急ぐ | 送り届ける | お姉さん・家庭的・しっかり者がいればお礼。いなければ一緒に迷う（小ダメージ） |
| 謎かけ | やめておく | 解く | インテリ・天才肌・メガネがいれば宝。いなければ電撃（ダメージ） |
| 小さな舞台 | 通り過ぎる | 歌う | 歌好きがいれば HP 回復とライブの回数が1つ戻る |
| 食材 | やめておく | 料理する | 料理上手・家庭的がいれば HP 大回復。いなければ半分でお腹をこわす |
| 猫 | 放っておく | ついていく | 動物好きがいれば宝のありかを教えてくれる |
| 仲間の死体 | 置いていく | 連れて帰る | カードモードのこの階で全滅した仲間。空きのぶんだけ連れて帰れる（死亡のまま） |

- **戦闘**：すべて1人1枚のコマンドカード。右＝戦う（届くいちばん前のグループ）、左＝守る、上＝呪文・ライブ（一覧から選ぶ）、下＝その他（いつものコマンド一覧）。全員ぶん振るとターンが始まり、素早さ順に1人ずつ見せる（11.1）。中身は11章の戦闘と同じ
- **報酬**：DRPGモードの 2/3（17.1）。カードモードだけの報酬はない（短い時間で遊べるのが利点）
- **ボス**：倒すたびに強くなる（9章）のはカードモードでも同じ。昇格アイテムは DRPG より出にくい（それぞれ 1/3 の確率で落とす）
- **帰還**：いつでも「街へ戻る」で戻れる。ただし**その挑戦で拾ったお金・楽譜・アイテムの半分を失う**。ボスを倒したときは全部持ち帰る
- **全滅**：死体はカードモードのその迷宮・その階に残る（ロストはしない）。別のパーティでその迷宮のカードモードに入ると、その階に必ず「仲間の死体」カードが出る。寺院でお金を払って回収してもらうこともできる。その挑戦で拾った物はすべて失う
- **中断**：1枚進むごとに記録する。アプリを閉じても続きから
- **操作**：カードを指（マウス）で左右に振る。答えのボタンを押しても、← → キーでもよい。戦闘のコマンドカードは ↑ ↓ も使う

### 17.4 カードモードのバランス（`tools/sim_cards.mjs`）

全快のパーティ（真・響・春香／律子・千早・雪歩）で、カードモードが解放された直後（ボスは1回倒されて1段階強い）に挑み、街に戻らずボスまで進んだときの踏破率。

| 劇場地下迷宮 | 12 | 51% | 26枚 | 9.5回 |
| 劇場地下迷宮 | 14 | 95% | 26枚 | 9.0回 |
| 奈落の大劇場 | 24 | 1% | 43枚 | 15回 |
| 奈落の大劇場 | 28 | 24% | 〃 | 〃 |
