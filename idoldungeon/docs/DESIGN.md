# アイドル迷宮（仮） 企画・設計メモ

アイドルマスターのキャラクターと楽曲を題材にした、エルミナージュ（1・2・3）風のダンジョンRPG。
非公式の二次創作として、個人で楽しむ範囲で作る。

- ジャンル：3D疑似視点（一人称・グリッド移動）のダンジョンRPG。パーティ制・ターン制
- モチーフ：エルミナージュ 〜闇の巫女と神々の指輪〜／II 〜双生の女神と運命の大地〜／III 〜暗黒の使徒と太陽の宮殿〜
- 独自要素：**属性シナジー**（アイドルの属性の重複・組み合わせ）と**楽曲装備**（曲名にちなんだ特殊能力）

---

## 1. コアループ

```
街（事務所）で編成・装備・鑑定・休息
  → ダンジョン探索（地図を埋める・罠・宝箱・イベント）
  → 戦闘（6人パーティ vs 敵グループ）
  → 戦利品（未鑑定の楽譜・装備・ゴールド）を持ち帰る
  → 成長（レベルアップ・クラスチェンジ）→ さらに深い階層へ
```

## 2. エルミナージュから引き継ぐ要素

| エルミナージュ | 本作での形 | 状態 |
|---|---|---|
| 6人パーティ・前列3／後列3 | そのまま。前列だけが近接攻撃を受ける・行う | `party.js` で前列/後列を判定済み |
| 種族×職業×性格（光・中立・闇） | アイドルは固定キャラ。**属性タグ**が種族・性格の役割を担う | 属性タグ定義済み |
| 職業・転職 | クラス（センター／ボーカル／ダンス／ヒーラー など）と転職 | 案のみ（未決事項） |
| 呪文の回数制（休むまで回復しない） | 楽曲の**ライブスキル**（`uses` 回／休息まで） | データ定義済み |
| 未鑑定アイテム・鑑定 | 「？？？の楽譜」として拾い、事務所で鑑定すると曲名がわかる | 未着手 |
| 宝箱の罠・解除 | そのまま（盗賊役＝いたずら好き系のクラス） | 未着手 |
| ワイヤーフレームの迷宮・オートマッピング | Canvas で一人称視点＋マップ | 未着手 |
| ダークゾーン・回転床・テレポーター・落とし穴 | そのまま。楽曲やシナジーで対策できる（例：蒼い鳥で落とし穴無効） | 効果テキストのみ |
| 召喚（モンスターを仲間に） | 「いきものがかり」シナジーのペット召喚 | 効果テキストのみ |
| 年齢・ロスト | 扱わない方向（キャラクターを失う要素は題材に合わないため）。戦闘不能は事務所で回復 | 方針案 |
| 時代・世界の移動（III） | 章ごとにテーマの違うステージ（ダンジョン）を巡る構成 | 案のみ |

## 3. 能力値

エルミナージュの6能力をアイドル風に読み替える（`js/engine/party.js`）。

| 本作 | 対応 | 主な使い道 |
|---|---|---|
| パワー `pow` | 力 | 物理攻撃（`atk`）、HP |
| ボーカル `vo` | 知恵 | 魔法攻撃（`mat`） |
| メンタル `men` | 信仰 | 魔法防御（`res`）、回復 |
| スタミナ `sta` | 生命力 | HP、防御（`def`） |
| ダンス `dan` | 素早さ | 行動順（`spd`）、命中、回避 |
| ビジュアル `vis` | 運 | 会心、回避、魅了系の成功率 |

派生ステータス：HP・攻撃・魔力・防御・魔防・命中・回避・素早さ・会心。式は仮（戦闘エンジンを作るときに調整）。

## 4. 属性シナジー（本作の中心）

### 4.1 属性タグ

アイドルはそれぞれ複数の属性タグを持つ（`js/data/tags.js`, `js/data/idols.js`）。**タグ単体には効果がない**。

| 分類 | 例 |
|---|---|
| イメージカラー（1人1つ） | 赤系・青系・緑系・黄系・紫系・桃系・白系・黒系 |
| 学年区分（1人1つ） | 中学生・高校生・大人 |
| 性格・趣味 | 元気・クール・インテリ・スポーツ好き・お嬢様・天然・料理上手・双子 … |
| 出身 | 南国育ち |
| ユニット | 竜宮小町 |

### 4.2 シナジーの種類（`js/data/synergies.js`）

| 種類 | 発動条件 | 例 |
|---|---|---|
| `count` 重複 | 同じタグを持つメンバーが n 人以上。人数が増えると段階が上がる | 赤系2人「紅蓮のカラー」攻撃+10% → 3人で+20%と炎属性 |
| `combo` 組み合わせ | 違うタグを**別々のメンバー**がそろえる（1人で全部持っていても不成立） | スポーツ好き＋インテリ「文武両道」、お嬢様＋家庭的「身分違いの友情」 |
| `distinct` 多様性 | ある分類のタグが何種類そろったか | イメージカラー5色以上「虹色ステージ」全能力+1 |

- 「同じ色でそろえて特化する」か「全員バラバラの色で虹色ステージを狙う」かで、編成の方向性が分かれるようにする。
- 効果の届く範囲：全員（party）／条件を満たしたメンバー（holders）／前列（front）／後列（back）。
- 能力値の補正（`stat`）と、戦闘・探索で参照する特殊能力（`ability`）の2種類。特殊能力の中身は戦闘エンジンで実装する。
- 画面には「あと1人（あと1タグ）で発動」も出して、編成を考える手がかりにする。

### 4.3 今のロスターでの注意

紫系・桃系・白系・黒系は 765PRO の13人ではそれぞれ1人しかいないため、同色シナジーは発動しない（`node idoldungeon/tools/test_synergy.mjs` が警告を出す）。
組み合わせ（例：白系＋黒系「モノクローム」）では使える。アイドルを追加する（他ブランドなど）と発動できるようになる。

## 5. 楽曲装備（`js/data/songs.js`）

- 各アイドルに**楽曲スロットが1つ**。曲名のイメージにちなんだ効果が付く。歌詞は扱わず、曲名だけを使う。
- 効果の形はシナジーと同じ（`stat` / `ability`。範囲は self・party・front・back）。
- 一部の曲には**ライブスキル**（休むまで `uses` 回使える技。エルミナージュの呪文回数制にあたる）。
- ランク（★1〜5）で、出現する階層と価格の目安にする。

| 曲名 | 効果のイメージ |
|---|---|
| READY!! | 戦闘1ターン目は必ず先手 |
| GO MY WAY!! | 素早さアップ・逃走しやすい |
| おはよう!!朝ご飯 | 休息明けのHP上乗せ |
| 蒼い鳥 | 回避アップ・落とし穴やダメージ床が無効 |
| 太陽のジェラシー | 通常攻撃が炎属性 |
| エージェント夜を往く | 暗闇で不意打ちされない・罠解除 |
| 自分REST@RT | 探索中に1度だけ自動復活 |
| CHANGE!!!! | 行動を消費せずに隊列を入れ替える |
| THE IDOLM@STER | 発動中の「人数で段階が上がる」シナジーを1人分多く数える |

（全21曲は `songs.js` 参照）

今後の案：
- **持ち歌ボーナス**：原曲を歌ったアイドルが装備すると効果が強まる（歌唱クレジットを確認してから入れる）
- **未鑑定の楽譜**：拾った直後は「？？？の楽譜」。鑑定で曲名がわかる
- **セットリスト**：パーティ全員の曲の並びで追加効果（例：同じアルバムの曲がそろう）

## 6. 画面とファイル構成（予定）

既存の「かずまほ」「アルカナンバー」と同じく、依存ライブラリなしの素の JavaScript（ES Modules）で作る。データと計算（`js/data`, `js/engine`）は画面から切り離して、Node だけでテストできるようにする。

```
idoldungeon/
  index.html, style.css   今はパーティ編成プロトタイプ（シナジー確認用）
  js/main.js              プロトタイプ画面
  js/data/tags.js         属性タグ
  js/data/idols.js        アイドル（13人）
  js/data/synergies.js    シナジー
  js/data/songs.js        楽曲（装備）
  js/engine/synergy.js    シナジー判定
  js/engine/party.js      能力値計算
  tools/test_synergy.mjs  データ整合性・判定・計算のテスト
  （予定）js/data/classes.js, enemies.js, items.js, floors.js
  （予定）js/engine/battle.js, dungeon.js, save.js
  （予定）js/ui/town.js, dungeon.js（一人称視点の描画）, battle.js
```

## 7. マイルストーン

1. **準備（この段階）**：企画メモ、データの形、シナジー判定と能力値計算、編成プロトタイプ、テスト
2. **ダンジョン探索**：グリッドのマップデータ、一人称ワイヤーフレーム描画、移動・回転・扉・オートマップ
3. **戦闘**：敵グループ、前列/後列、行動順、物理・魔法・ライブスキル、シナジーの特殊能力の実装
4. **街**：事務所（編成・休息）、ショップ、鑑定、セーブ
5. **成長**：経験値・レベル、クラスと転職
6. **コンテンツ**：地下5階程度の1つめのダンジョンとボス。バランス調整用の自動プレイ（`tools/sim.mjs`）

## 8. 未決事項

- クラス一覧（案：センター＝万能前衛／ダンス＝物理前衛／ボーカル＝攻撃魔法／ヒーラー＝回復／トリックスター＝盗賊／プロデューサー＝司教・鑑定／テイマー＝召喚／ミステリアス＝特殊魔法）。アイドルごとに初期クラスを持たせ、転職できるようにするか
- 登場アイドルの範囲（765PRO から始めて、他ブランドを追加するか）
- 年齢・学年区分の基準（作品ごとに設定が違う。`idols.js` の `verify: true` は要確認）
- 主人公（プロデューサー）をパーティに入れるか、指揮役（パッシブ効果）にするか
- 戦闘不能・ロストの扱い
- 見た目（キャラクター画像は使わず、イメージカラーと文字・図形で表現する想定）
