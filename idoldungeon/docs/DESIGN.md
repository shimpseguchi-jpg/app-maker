# アイドル迷宮（仮） 企画・設計メモ

アイドルマスターのキャラクターと楽曲を題材にした、エルミナージュ（1・2・3）風のダンジョンRPG。
非公式の二次創作として、個人で楽しむ範囲で作る。

- ジャンル：3D疑似視点（一人称・グリッド移動）のダンジョンRPG。パーティ制・ターン制
- モチーフ：エルミナージュ 〜闇の巫女と神々の指輪〜／II 〜双生の女神と運命の大地〜／III 〜暗黒の使徒と太陽の宮殿〜
- 独自要素：**属性シナジー**（アイドルの属性の重複・組み合わせ）と**楽曲装備**（曲名にちなんだ特殊能力）
- 世界観：アイドルたちが演じる**作中劇**という建てつけ。プロデューサーは登場人物にもパーティにも入らない
- 登場アイドル：まず 765PRO ALLSTARS の13人。ゆくゆくは 765PRO 以外のブランドにも広げる

## 決定事項

| 項目 | 決定 |
|---|---|
| クラスと転職 | エルミナージュを踏襲。さらにファイアーエムブレム 聖魔の光石のクラスを加え、**下位職と上位職**を設ける（7章） |
| 登場アイドル | ゆくゆくは 765PRO 以外も入れる |
| プロデューサー | パーティに入れない。冒険は作中劇の一環 |
| 戦闘不能 | エルミナージュを踏襲。ただし**ロストはなし**（8章） |
| 持ち歌ボーナス | 765PRO 以外に広げるときに入れる。**個人曲・ユニット曲・全体曲**でボーナスに濃淡をつける（5章） |
| 昇格アイテム | **ボスのドロップと店売り**（7.5） |
| ボス | ダンジョンクリア後も、**強化されて再出現**する（9章） |
| フロアマスター | 入れない（見える敵の徘徊・追跡は省く） |

## 1. コアループ

```
街で編成・装備・鑑定・休息
  → ダンジョン探索（地図を埋める・罠・宝箱・イベント）
  → 戦闘（6人パーティ vs 敵グループ）
  → 戦利品（未鑑定の楽譜・装備・ゴールド）を持ち帰る
  → 成長（レベルアップ・クラスチェンジ）→ さらに深い階層へ
```

## 2. エルミナージュから引き継ぐ要素

| エルミナージュ | 本作での形 | 状態 |
|---|---|---|
| 6人パーティ・前列3／後列3 | そのまま。前列だけが近接攻撃を受ける・行う | `party.js` で前列/後列を判定済み |
| 種族×職業×性格（光・中立・闇） | アイドルは固定キャラ。**属性タグ**が種族・性格の役割を担う | 属性タグ定義済み |
| 職業・転職 | エルミナージュ式の転職＋聖魔の光石式の昇格（下位職→上位職） | `classes.js` に定義済み |
| 呪文の回数制（休むまで回復しない） | 楽曲の**ライブスキル**（`uses` 回／休息まで） | データ定義済み |
| 未鑑定アイテム・鑑定 | 「？？？の楽譜」として拾い、街の店かビショップが鑑定すると曲名がわかる | 未着手 |
| 宝箱の罠・解除 | そのまま（盗賊役＝いたずら好き系のクラス） | 未着手 |
| ワイヤーフレームの迷宮・オートマッピング | Canvas で一人称視点＋マップ | 未着手 |
| ダークゾーン・回転床・テレポーター・落とし穴 | そのまま。楽曲やシナジーで対策できる（例：蒼い鳥で落とし穴無効） | 効果テキストのみ |
| 召喚（モンスターを仲間に） | サマナー（上位職）、「いきものがかり」シナジーのペット召喚 | 効果テキストのみ |
| 死亡・灰・ロスト | 死亡と灰はそのまま。**ロストはなし**（灰の蘇生に失敗しても灰のまま） | `revive.js` に定義済み |
| 年齢 | 扱わない（アイドルの年齢は固定） | 方針 |
| 時代・世界の移動（III） | 章ごとにテーマの違うステージ（ダンジョン）を巡る構成 | 案のみ |

## 3. 能力値

エルミナージュの6能力をアイドル風に読み替える（`js/engine/party.js`）。

| 本作 | 対応 | 主な使い道 |
|---|---|---|
| パワー `pow` | 力 | 物理攻撃（`atk`）、HP |
| ボーカル `vo` | 知恵 | 魔法攻撃（`mat`） |
| メンタル `men` | 信仰 | 魔法防御（`res`）、回復 |
| スタミナ `sta` | 生命力 | HP、防御（`def`） |
| ダンス `dan` | 素早さ | 行動順（`spd`）、命中、回避 |
| ビジュアル `vis` | 運 | 会心、回避、魅了系の成功率 |

派生ステータス：HP・攻撃・魔力・防御・魔防・命中・回避・素早さ・会心。式は仮（戦闘エンジンを作るときに調整）。

## 4. 属性シナジー（本作の中心）

### 4.1 属性タグ

アイドルはそれぞれ複数の属性タグを持つ（`js/data/tags.js`, `js/data/idols.js`）。**タグ単体には効果がない**。

| 分類 | 例 |
|---|---|
| イメージカラー（1人1つ） | 赤系・青系・緑系・黄系・紫系・桃系・白系・黒系 |
| 学年区分（1人1つ） | 中学生・高校生・大人 |
| 性格・趣味 | 元気・クール・インテリ・スポーツ好き・お嬢様・天然・料理上手・双子 … |
| 出身 | 南国育ち |
| ユニット | 竜宮小町 |

### 4.2 シナジーの種類（`js/data/synergies.js`）

| 種類 | 発動条件 | 例 |
|---|---|---|
| `count` 重複 | 同じタグを持つメンバーが n 人以上。人数が増えると段階が上がる | 赤系2人「紅蓮のカラー」攻撃+10% → 3人で+20%と炎属性 |
| `combo` 組み合わせ | 違うタグを**別々のメンバー**がそろえる（1人で全部持っていても不成立） | スポーツ好き＋インテリ「文武両道」、お嬢様＋家庭的「身分違いの友情」 |
| `distinct` 多様性 | ある分類のタグが何種類そろったか | イメージカラー5色以上「虹色ステージ」全能力+1 |

- 「同じ色でそろえて特化する」か「全員バラバラの色で虹色ステージを狙う」かで、編成の方向性が分かれるようにする。
- 効果の届く範囲：全員（party）／条件を満たしたメンバー（holders）／前列（front）／後列（back）。
- 能力値の補正（`stat`）と、戦闘・探索で参照する特殊能力（`ability`）の2種類。特殊能力の中身は戦闘エンジンで実装する。
- 画面には「あと1人（あと1タグ）で発動」も出して、編成を考える手がかりにする。

### 4.3 今のロスターでの注意

紫系・桃系・白系・黒系は 765PRO の13人ではそれぞれ1人しかいないため、同色シナジーは発動しない（`node idoldungeon/tools/test_synergy.mjs` が警告を出す）。
組み合わせ（例：白系＋黒系「モノクローム」）では使える。アイドルを追加する（他ブランドなど）と発動できるようになる。

## 5. 楽曲装備（`js/data/songs.js`）

- 各アイドルに**楽曲スロットが1つ**。曲名のイメージにちなんだ効果が付く。歌詞は扱わず、曲名だけを使う。
- 効果の形はシナジーと同じ（`stat` / `ability`。範囲は self・party・front・back）。
- 一部の曲には**ライブスキル**（休むまで `uses` 回使える技。エルミナージュの呪文回数制にあたる）。
- ランク（★1〜5）で、出現する階層と価格の目安にする。

| 曲名 | 効果のイメージ |
|---|---|
| READY!! | 戦闘1ターン目は必ず先手 |
| GO MY WAY!! | 素早さアップ・逃走しやすい |
| おはよう!!朝ご飯 | 休息明けのHP上乗せ |
| 蒼い鳥 | 回避アップ・落とし穴やダメージ床が無効 |
| 太陽のジェラシー | 通常攻撃が炎属性 |
| エージェント夜を往く | 暗闇で不意打ちされない・罠解除 |
| 自分REST@RT | 探索中に1度だけ自動復活 |
| CHANGE!!!! | 行動を消費せずに隊列を入れ替える |
| THE IDOLM@STER | 発動中の「人数で段階が上がる」シナジーを1人分多く数える |

（全21曲は `songs.js` 参照）

**持ち歌ボーナス**（765PRO 以外のアイドルを加えるときに入れる）：
- 原曲を歌ったアイドルが装備すると効果が強まる。曲に `credit: { type, singers }` を持たせる予定
- 強さに濃淡をつける：**個人曲（ソロ）＞ ユニット曲 ＞ 全体曲**（例：効果量 +50% ／ +30% ／ +15%。数値は仮）
- 全体曲は歌い手が多いので、ボーナスを受けられる人は多いが効果は控えめ、という釣り合い

今後の案：
- **未鑑定の楽譜**：拾った直後は「？？？の楽譜」。鑑定で曲名がわかる
- **セットリスト**：パーティ全員の曲の並びで追加効果（例：同じアルバムの曲がそろう）

## 6. 世界観：作中劇

- 冒険はアイドルたちが演じる劇（作中劇）という建てつけ。アイドルは役（クラス）を演じる
- プロデューサーは登場しない。パーティにも入らない。街の施設（宿・店・寺院など）はすべて劇中の世界のもの
- 死亡・灰などの言葉もエルミナージュのまま使う（劇中の出来事なので、アイドルを本当に失う要素は置かない）

## 7. クラス（`js/data/classes.js`, `js/engine/classes.js`）

エルミナージュの転職を土台にして、聖魔の光石の「下位職から2択で上位職へ昇格」を加える。

### 7.1 転職（エルミナージュ式）

- 基本能力が**クラスごとの条件**を満たせば、街で転職できる（下位職すべてと、エルミナージュの上級職：侍・忍者・ロード）
- 転職すると **Lv1 に戻り、基本能力はアイドル本来の値に戻る**
- **覚えた魔法は引き継ぐ**（罠解除などのクラス技能は引き継がない）

### 7.2 昇格（聖魔の光石式）

- 下位職で **Lv10 以上**になり、今のクラスに合う昇格アイテムを使うと、**2つの上位職から1つ**を選んで昇格できる
- 昇格すると Lv1 に戻るが、**基本能力はそのまま残り、上位職ごとの昇格ボーナスが足される**
- 魔法は引き継ぐ。踊り子は昇格しない特別職

### 7.5 昇格アイテム（`js/data/items.js`）

聖魔の光石と同じく、系統ごとのアイテムと、どの下位職にも使えるマスタープルフがある。使うとなくなる。

| アイテム | 使える下位職 | 入手 |
|---|---|---|
| ヒーローの証 | 戦士・傭兵・剣士 | ボス（確定ドロップの候補）・店（いつでも） |
| ナイトプルフ | アーマーナイト・ソシアルナイト | 同上 |
| オリオンの矢 | アーチャー | 同上 |
| 天空のムチ | ペガサスナイト・ドラゴンナイト | 同上 |
| 導きの指輪 | 魔道士・シャーマン・僧侶・トルバドール・錬金術師 | 同上 |
| オーシャンシール | 盗賊 | 同上 |
| マスタープルフ | すべて | ボス（確率。再戦ほど出やすい）・店（ボスを倒すたびに1つ入荷） |

- 系統別のアイテムは店でいつでも買えるが高い（仮：3000G）。ボスを倒すと系統別のどれか1つが確定で手に入る

- アイテム名は聖魔の光石準拠。要確認

## 8. 戦闘不能と蘇生（`js/engine/revive.js`）

エルミナージュを踏襲し、ロストだけを取り除く。

| 状態 | 戦えるか | 治しかた |
|---|---|---|
| 毒・睡眠 | 戦える（睡眠中は行動できない） | 魔法・薬・時間 |
| 麻痺・石化 | 戦えない | 回復魔法・寺院 |
| 死亡 | 戦えない | 蘇生魔法・寺院。**失敗すると灰** |
| 灰 | 戦えない | 寺院。**失敗しても灰のまま**（お金だけ失う。ロストはしない） |

- 蘇生の成功率はスタミナ（エルミナージュの生命力）で上がる。数値は仮
- 全員が戦えなくなると全滅。迷宮に残されたメンバーは、別のアイドルで組んだパーティで回収しに行く

## 9. ボスと再戦（`js/data/bosses.js`, `js/engine/boss.js`）

各ダンジョンの最深部にボスがいる。倒してダンジョンをクリアした後も、**強化されて再出現**する。

| 再戦 | 強さ | 追加の特性（例） | 報酬 |
|---|---|---|---|
| 初戦 | 基準 | なし | 系統別の昇格アイテム（確定）、マスタープルフ（10%）、ゴールド、楽曲 |
| 1回目 | 能力 +30%、Lv +5 | 連続行動 | マスタープルフ 20%、ゴールド +50%、楽曲ランク +1 |
| 2回目 | 能力 +60%、Lv +10 | ＋状態異常・即死が効かない | マスタープルフ 30%、… |
| 3回目以降 | さらに上昇 | ＋取り巻きを呼ぶ | マスタープルフは最大 50%、楽曲ランクは★5まで |

- 強化の倍率・確率はすべて仮。戦闘エンジンとあわせて調整する
- 再戦は、昇格アイテムを集める場、育ったパーティの腕試しの場にする
- 何回倒したかはボスごとに記録する（セーブデータに持たせる）

## 10. ダンジョン探索（`js/data/floors.js`, `js/engine/dungeon.js`）

エルミナージュ1・2・3を土台にする。参考：
[1（PSP）](https://spoiler.sakura.ne.jp/srv/el1psp/)・[2（DS）](https://spoiler.sakura.ne.jp/srv/el2ds/)・[3](https://spoiler.sakura.ne.jp/srv/el3/) の攻略 wiki

### 10.1 参考サイトから拾ったエルミナージュの特徴

- 格子状のマップを一人称で歩く。位置は **X・Y 座標**（例：X05 Y00 が入口）で示される。1つの階はおよそ 18〜20 マス四方
- 1F の入口から地下へ潜る。階段は上下の階で同じ座標にある
- 扉、**一方通行の扉**、**シークレットドア**（盗賊の技能で見つかる。片側からしか見つからないものもある）、**鍵のかかった扉**、**スイッチで開く扉**
- **ダークゾーン**（照明・マップが使えず、戦闘中も敵が見分けられない）、**呪文禁止エリア**
- **ワープ**（当たり・はずれがある）、**シュート**（下の階へ落ちる）、**ピット**（落とし穴）
- **回復の泉**（マイナス効果の泉もある）、イベントのマス
- 敵：**ワンダリングモンスター**（歩くとランダムに出る。宝箱なし）、**ルームガーダー**（部屋で待ち伏せ。必ず宝箱）、**何度でも戦える固定敵**、ボス、フロアマスター（見える敵。徘徊や追跡をする。**本作では入れない**）、モンスタージェネレーター
- 「天使の小窓」（合成で作るアイテム）を持つとミニマップが常に表示される
- 全滅すると死体はその場に残る。寺院の死体回収（有料）か、救助隊を組んで回収する
- 帰還は徒歩か、帰還・転移の呪文

### 10.2 実装したもの

| 要素 | 本作での扱い |
|---|---|
| マップ | 文字で描く平面図（`floors.js` 冒頭に記号の一覧）。座標は X 東・Y 北、左下が (0,0) |
| 移動 | 前進・左右を向く・後ろを向く・横歩き。キーボード（↑←→↓ / WASD / Q E）と画面のボタン |
| 一人称表示 | Canvas のワイヤーフレーム（`js/ui/view3d.js`）。扉・鍵の扉・仕掛け扉を描き分ける |
| オートマップ | 歩いたマスと壁を記録（`js/ui/automap.js`）。ダークゾーンは記録されず、中では座標も分からない |
| 扉の種類 | 扉・一方通行（裏側からは壁に見える）・シークレットドア（「調べる」で発見。盗賊系がいれば必ず、いなければ 1/3）・鍵の扉・スイッチで開く扉 |
| 床の仕掛け | ダークゾーン・呪文禁止エリア・ピット（飛行できる人はかわす）・シュート・ワープ・泉（回復／毒）・イベント |
| 敵 | 徘徊する敵（階ごとの遭遇率）・ルームガーダー（街に戻るまで1回）・固定敵（何度でも）・ボス（街に戻ると強化されて再出現） |
| 全滅 | 寺院の回収係が街へ運ぶ（所持金の半分）。救助隊はまだ |
| 街 | 宿屋・寺院（蘇生）・店（昇格アイテム）・パーティの組み直し |

- 戦闘は 11章
- 仮のダンジョン「劇場地下迷宮（仮）」は 12×12 マスの3階層。どの仕掛けも一度は出てくるように置いた
- `tools/test_dungeon.mjs` が、マップの書き損じ（外周の穴、岩盤への通路、階段の位置ずれ）と、鍵・スイッチを使えば全マスに行けることを確かめる
- `tools/e2e_explore.mjs` は、ロボットが画面を操作して入口からボスまで行き、街へ戻るまでを通しで確かめる

## 11. 戦闘（`js/engine/battle.js`, `js/data/enemies.js`, `js/data/spells.js`）

エルミナージュ1（PSP）の攻略 wiki の初心者ガイドを参考にした。

### 11.1 流れ

1. 敵は1〜4グループで現れる。正体が分かるまでは**不確定名**（例：「黒い人影」）。知恵（ボーカル）が高いほど、ビショップ（鑑定）がいるほど分かりやすい。ダークゾーンでは分からない
2. ときどき**先制**（敵が1ターン動かない）や**不意打ち**（こちらが1ターン動けない）が起きる。ボスは不意打ちしない
3. 全員のコマンドを決めてから、素早さ＋運の順に行動する。「おまかせ」で残り全員の行動を自動で決められる
4. 敵を全滅させると、経験値は**生き残った人で山分け**、ゴールドは全額。ルームガーダーは宝箱、ボスは昇格アイテム

### 11.2 コマンド

| コマンド | 内容 |
|---|---|
| 戦う | 射程の届く敵グループを選んで攻撃。戦士系は Lv9・17… で攻撃回数が増える |
| 呪文 | 覚えた呪文（系統ごとの回数制。宿屋で全快）。呪文禁止エリア・沈黙中は効かない |
| ライブ | 装備した楽曲のライブスキル（休むまでの回数制） |
| 守る | 自分の受けるダメージを半分に |
| かばう | 仲間1人を選び、その仲間への攻撃を代わりに受ける |
| 逃げる | **選んだ人だけが逃げる**。残った人で戦闘は続き、全員逃げると終わる。ボス戦は逃げられない |
| 踊る | 踊り子のみ。仲間1人がもう一度攻撃する |
| ユニットライブ | 竜宮小町の3人がそろって動けるとき、1戦闘に1回。敵全体に大ダメージ |

### 11.3 射程（エルミナージュ準拠。武器を作るまではクラスで決める）

| 射程 | 届く敵 | クラス |
|---|---|---|
| S | 目の前のグループだけ | 戦士・剣士・盗賊・魔法職など |
| M | 2グループ目まで | アーマーナイト・ソシアルナイト・ペガサスナイト・ドラゴンナイトと、その上位職 |
| L | すべて | アーチャー・ウォーリア・スナイパー・レンジャー |

- **後列からは1つ短くなる**（後列の S は届かない、後列の M は1グループ目だけ）
- 前のグループを全滅させると、後ろのグループが繰り上がる
- 敵の通常攻撃は前列をねらう（前列が全員倒れると後列）

### 11.4 呪文（本作オリジナルの名前）

| 系統 | Lv1 | Lv2〜3 | Lv4〜 |
|---|---|---|---|
| 理魔法（魔道士など） | 炎の矢 | 吹雪（Lv3） | 流星（Lv7） |
| 回復魔法（僧侶など） | 癒やし | 浄化（Lv2） | 祝福の光（Lv5）・蘇生（Lv9。失敗すると灰） |
| 闇魔法（シャーマンなど） | 闇の矢 | 眠りの霧（Lv2） | 沈黙の帳（Lv4） |
| 錬金術（錬金術師） | 毒ガス | 撤収の煙（Lv3。全員確実に逃げる） | 酸の雨（Lv6） |

### 11.5 状態異常

毒（ターンごと・歩くたびに減る）、睡眠（行動できない。攻撃されると起きる）、沈黙（呪文・ライブが使えない）、麻痺・石化（戦えない）、死亡、灰。敵には混乱（仲間を攻撃する）もある。

### 11.6 戦闘で働くシナジー・楽曲・クラスの特殊能力

| 能力 | 出どころ | 効果 |
|---|---|---|
| ツインアタック | 双子（亜美・真美） | 2人が同じグループを攻撃すると威力 1.5 倍 |
| かばう | 王子様とお姫様 | お嬢様への攻撃を、ボーイッシュなメンバーが 50% で代わりに受ける |
| 芽吹き | 緑系3人 | 毎ターン HP 5% 回復 |
| 雷のステップ | 黄系3人 | 先制しやすい |
| 不思議空間 | ミステリアス＋天然 | 戦闘開始時、敵1グループを 30% で1ターン封じる |
| ユニットライブ | 竜宮小町 | 上の表 |
| スタンバイOK／スタートダッシュ | READY!!／スタ→トスタ→ | 1ターン目に必ず先に動く |
| ふるふる | ふるふるフューチャー☆ | 25% で2回攻撃 |
| 目が逢う瞬間・ときめき | 楽曲・桃系3人 | 攻撃時 10% で敵を混乱 |
| リスタート | 自分REST@RT | 探索中1度だけ、倒れても HP1 で立ち上がる |
| ポジティブ | ポジティブ！ | 眠らない |
| となりで | 隣に… | 同じ列の隣の仲間への攻撃を 30% で代わりに受ける |
| 首切り・瞬殺 | 忍者・アサシン | 5% で即死 |
| 貫通 | ワイバーンナイト | 15% で防御を無視 |
| 索敵 | レンジャー | 不意打ちされない |

属性攻撃（炎・氷など）、ペット召喚、見守りなど、まだ効果のない能力もある（敵に属性を持たせるときに入れる）。

### 11.7 バランス

`node idoldungeon/tools/sim_battle.mjs` で、おまかせ作戦の自動対戦をくり返して全滅率を測る。休まず5連戦したときの全滅率で見ている（今の目安）。

| 相手 | 目安のレベル | 全滅率 |
|---|---|---|
| 1F の徘徊する敵（5連戦） | Lv1 | 約16% |
| B1F の徘徊する敵（5連戦） | Lv4 | 約5% |
| B2F の徘徊する敵（5連戦） | Lv6〜7 | 約40%〜18% |
| ボス（初戦） | Lv6〜7 | 約33%〜9% |
| ボス（再戦1回目） | Lv11 | 約21% |

能力値から攻撃力・HP などを出す式（`js/engine/party.js` の `derive`）も、戦闘にあわせて「Lv1 は控えめで、レベルとともに伸びる」形に変えた。

## 13. マイルストーン
