# Google Apps Script（GAS）で公開する

GitHub Pages（github.io）がフィルターで開けない環境向けに、ゲームを **HTML 1ファイル** にまとめたものです。
GAS の「ウェブアプリ」として公開すると、`https://script.google.com/...` のURLで遊べます。

| ファイル | 中身 |
|---|---|
| `Code.gs` | ゲームを表示する短いプログラム |
| `arcanumber.html` | アルカナンバー（JS・CSS をすべて中に入れた1ファイル。約3700行） |
| `kazumaho.html` | かずまほ（入れなくてもよい） |
| `manabi.html` | まなびサクセス（仮）（入れなくてもよい。試作版） |
| `keisan.html` | けいさんオリパ（入れなくてもよい。セーブをサーバーに保存できる） |
| `appsscript.json` | clasp を使う人むけの設定（手作業なら不要） |

## 手順（パソコンで1回だけ）

1. https://script.google.com を開いて「新しいプロジェクト」。左上の名前を「アルカナンバー」などに変える
2. 最初からある `コード.gs` の中身を全部消して、[`Code.gs`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/ccr-a96fc02a-yijbz1/gas/Code.gs) の中身を貼る
3. 左の「ファイル」の **＋** →「HTML」→ 名前を **`arcanumber`** にする（`.html` は自動でつく）
   中身を全部消して、[`arcanumber.html`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/ccr-a96fc02a-yijbz1/gas/arcanumber.html) を開いて「すべて選択 → コピー」したものを貼る
   - かずまほも入れるなら、同じように名前 **`kazumaho`** で [`kazumaho.html`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/ccr-a96fc02a-yijbz1/gas/kazumaho.html) を貼る
4. 保存（💾 または Ctrl+S / ⌘+S）
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類の選択（⚙️）で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：
     - 学校の Google アカウントで作った場合 →「（学校・自治体名）内の全員」
     - 個人の Gmail で作って、子どもは学校のアカウントで開く場合 →「全員」
6. 「デプロイ」を押す。承認を求められたら自分のアカウントで許可する（このプログラムは Google ドライブやメールなどには一切アクセスしません）
7. 表示された **ウェブアプリのURL**（`…/exec` で終わる）を iPad の Safari で開く
   - かずまほは URL の最後に `?game=kazumaho` をつける（まなびサクセスは `?game=manabi`）
   - 共有ボタン →「ホーム画面に追加」で、アイコンから開けるようになる

## ゲームを新しくしたとき

1. `arcanumber.html`（や `kazumaho.html`）の中身を新しいものに貼り替えて保存
2. 「デプロイ」→「デプロイを管理」→ ✏️（編集）→ バージョンを「新バージョン」→「デプロイ」

URL は変わりません。セーブデータもそのまま残ります。

## けいさんオリパを入れる（セーブをサーバーに残す）

けいさんオリパは、GAS のウェブアプリとして開いたときだけ、セーブ（コインと取得カード）をこのスクリプトの **スクリプト プロパティ** にも保存します。
iPad のブラウザ内のセーブ（localStorage）が消える環境でも、コインとカードが残ります。**端末ごとに1セーブ**です（子どもごと・クラス共有ではありません）。

### 追加の手順（すでにアルカナンバーを公開している場合）

1. GAS のエディタで `コード.gs` の中身を全部消して、新しい [`Code.gs`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/ccr-a96fc02a-yijbz1/gas/Code.gs) の中身に貼り替える（`loadKeisan` / `saveKeisan` と `?game=keisan` の表示が入った版）
2. 左の「ファイル」の **＋** →「HTML」→ 名前を **`keisan`** にする（`.html` は自動でつく）。中身を全部消して、[`keisan.html`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/ccr-a96fc02a-yijbz1/gas/keisan.html) を「すべて選択 → コピー」して貼る
3. 保存（💾）
4. 「デプロイ」→「デプロイを管理」→ ✏️（編集）→ バージョンを **「新バージョン」** →「デプロイ」。承認を求められたら許可する（スクリプト プロパティを使うための許可で、ドライブやメールにはさわりません）
5. ウェブアプリのURL（`…/exec`）の最後に **`?game=keisan`** をつけて開く
   - Google サイトにのせるときは「挿入」→「埋め込む」→「**URL で埋め込む**」に、この `…/exec?game=keisan` を貼る
   - 「コードを埋め込む」に `keisan/index.html` を貼る従来の方法でも遊べますが、その場合はサーバー保存は働きません（ブラウザ内のセーブだけ）

### 端末ID（先生用）

- はじめて開いたとき、端末ごとにランダムな **端末ID**（英数字12文字。例 `7gwg-2mfn-xddv`）が作られ、ホーム画面の **左下のすみ** に小さく表示されます。セーブはこのIDで見分けます
- ブラウザのデータが全部消えると端末IDも消え、新しいIDで最初から始まります。もとに戻すには、次のどちらかを使います
  - ホーム画面左下の小さな「ID …」をタップ → もとの端末IDを入れて「よみこむ」
  - URL に端末IDをつけて開く：`…/exec?game=keisan&dev=7gwg2mfnxddv`（ハイフンはあってもなくてもよい）。端末ごとにこのURLをホーム画面やブックマークに入れておくと、データが消えても自動でもとに戻ります
- そのため、**端末IDは端末ごとに控えておいてください**（台帳に書く、URL に入れておく など）
- 同じ端末IDを2台で同時に使うと、あとから保存したほうで上書きされます

### しくみと注意

- 保存：コインやカードが変わるたびに、1.5秒まとめてからサーバーへ送ります。送れなかったときもゲームは止まらず、次の保存のときにもう一度送ります
- 起動：サーバーのセーブと端末内のセーブを比べ、更新時刻（`updatedAt`）が新しいほうを使います。サーバーにまだ無いときは、端末内のセーブをサーバーへ上げます（これまで遊んでいたデータは消えません）。サーバーが8秒こたえないときは、端末内のセーブで始めます
- サーバーは、端末IDの形式、データの大きさ（8KBまで）、コインの範囲、カード・箱の形を確かめてから保存します
- 保存先はスクリプト プロパティの `keisan:端末ID` です。1台あたり 0.3〜1KB ほどで、スクリプト プロパティ全体の上限（約500KB）をランキングと分け合います。数百台までが目安です
- セーブを消したいとき：エディタ左の ⚙️「プロジェクトの設定」→「スクリプト プロパティ」で `keisan:端末ID` を削除

## 「きょうの ちょうせん」のランキング

`Code.gs` には、日替わりスコアアタックのランキングを保存するしくみが入っています（`getDaily` / `submitDaily`）。
スコアはこのスクリプトの **スクリプト プロパティ** に日付ごとに保存され、8日たつと自動で消えます。

- `Code.gs` を新しくしたあとの最初のデプロイで「承認が必要です」と出たら、自分のアカウントを選び、「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」で進めてください（スコアの保存のために、このスクリプト自身の保存領域を使う許可です。ドライブやメールにはさわりません）
- ランキングを消したいとき：エディタ左の ⚙️「プロジェクトの設定」→ 下の「スクリプト プロパティ」で `daily:日付` と `dailytags:日付` を削除
- だれでもスコアを送れるしくみなので、ありえない点数（99999点より上など）は切り捨てています

## Google サイトにのせる場合

Google サイトの編集画面で「挿入」→「埋め込む」→「URL で埋め込む」に、上のウェブアプリのURLを貼ります（`Code.gs` で埋め込みを許可済み）。
ゲームは横長（iPad 横向き）なので、埋め込みの枠はページの横幅いっぱい・高さも大きめに広げてください。
「コードを埋め込む」に HTML を直接貼る方法は、ファイルが大きい（約360KB）ためおすすめしません。

## 知っておくとよいこと

- けいさんオリパの `keisan.html` も同じ方法（base64）で作っています。もとの `keisan/index.html` は1ファイルですが、スクリプトが約50KBあるため、そのままのコピーではなく、ほかのゲームと同じ詰め方にそろえました
- GAS は配信するときに大きなスクリプトを書き換えてしまい、`SyntaxError` で真っ暗になることがあります。そのため JS と CSS は **base64（英数字だけの文字列）** にして HTML の中に入れ、ブラウザの中で元に戻してから動かしています。HTML の中に英数字だけの行がたくさん並んでいるのは正常です

- セーブは iPad のブラウザの中に残ります（GitHub Pages 版とは別々）。けいさんオリパだけは、上のとおりサーバーにも保存します
- 個人の Gmail で公開すると、画面の上に「Google Apps Script のユーザーによって作成されました」という帯が出ることがあります
- 文字の書体は Google Fonts から読み込みます。読み込めなくても iPad の書体で遊べます
