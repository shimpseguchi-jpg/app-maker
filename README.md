# かずまほ 〜カードでのぼるまほうのとう〜

> 姉妹作：本格デッキ構築ゲーム **[アルカナンバー](arcanumber/)**（`arcanumber/` フォルダ）もあります。
> ほかに、栃木・千葉・茨城・群馬・埼玉の **[道の駅チェック](michinoeki/)**（`michinoeki/` フォルダ）もあります。
> 開発準備中：アイドルマスター題材のダンジョンRPG **[アイドル迷宮（仮）](idoldungeon/)**（`idoldungeon/` フォルダ）。

小学1〜3年生むけの **ローグライク × デッキ構築** ゲームです。
カードを「じゅもんの わく」に並べると、**数が 0 から左→右の順に計算**され、できた数で敵を攻撃します。
iPad の横画面を基準に作っていて、ブラウザだけで動きます（インストール・ビルド不要）。

## あそびかた（3行で）

1. 手札のカードをタップして、じゅもんの わくに並べる（ドラッグで並べかえ、長押しでカードの説明）
2. 「じっこう」の前に **こたえを予想** する。当たると「ひらめき！」でダメージ 1.5 倍
3. マップで道を選び、3かいのボス「ゼロの まおう」を倒せばクリア

## ゲームのなかの学び

| ねらい | ゲームでの形 |
|---|---|
| 四則演算 | カードが `+3` `×2` `÷2` `−2` などの演算。順番で答えが変わる（`+3 → ×2 = 6`、`×2 → +3 = 3`） |
| 暗算・見通し | 「よそう チャレンジ」：途中の数は隠れていて、頭の中で計算して答えを入れると威力アップ |
| ぴったりの数を作る | 敵の 🎯 の数と同じ数で攻撃すると 2 倍。足す・引く・かけるを組み合わせて目標の数を作る |
| 九九・倍数 | 敵の 💥 じゃくてん「3のだん」など。3, 6, 9 … の数で攻撃すると 2 倍（1年生は「5とび」「10とび」） |
| 図形 | さんかく＝かど3つ、しかく＝4つ、はちのす＝6つ。**となりに並べると「がったい」**（さんかく＋さんかく＝しかく、しかく＋さんかく＝いえの形＝ごかっけい） |
| 生き物・身の回りの知識 | 足の数（にわとり2・ねこ4・こんちゅう6・くも8・いか10）、1しゅうかん＝7日、1cm＝10mm、1L＝10dL、さいころの表と裏の和はいつも7 など。**カードには数が書いていない**ので、知っていると有利 |
| シナジーと知識 | 「むしとりあみ」「むしめがね」は **こんちゅうだけ** に効く（くもは足が8本なので こんちゅうではない！） |
| プログラミング的思考 | 順次（左から実行）・くりかえし（もう一度／さいしょから／次を3回）・条件分岐（もし10いじょうなら）・変数（メモする／メモを足す） |
| 文章題・時計・お金・単位 | マップの「ふしぎ」マスで学年別のクイズ（時計の読み、おつり、足の数、きまり探し、ひよこの道順パズル など） |

学年（1・2・3ねんせい）を選ぶと、出てくるカード・敵の強さ・🎯の数の大きさ・クイズの内容が変わります。
1年生は たし算・ひき算・かたち・10のまとまり、2年生から かけ算（九九）・時計・はこの形、3年生から わり算・あまり・円 が加わります。

一度使ったカードの知識は「ずかん」の「ちしき」に記録され、よそうの正解数・計算した回数などは「きろく」に残ります。

## 文字の表示

最初の起動時と「せってい」から選べます。

- **ひらがな**：すべてひらがな（分かち書き）
- **漢字（ふりがな）**：漢字にルビつき
- **漢字**：ルビなし

## iPad で遊ぶ

このフォルダを HTTPS で配信すれば動きます（例：GitHub Pages で `main` ブランチのルートを公開）。
Safari で開いて「共有 → ホーム画面に追加」すると、全画面のアプリとして起動し、オフラインでも遊べます。
セーブはブラウザ内（localStorage）に自動で保存されます。

github.io がフィルターで開けない環境（学校の iPad など）では、**Google Apps Script のウェブアプリ** として公開できます。
1ファイル版と手順は [`gas/`](gas/README.md) にあります（アルカナンバー・かずまほ の両方）。

ローカルで試すとき：

```sh
npx http-server -p 8123 -c-1 .
# → http://localhost:8123/
```

## つくり

依存ライブラリなしの素の JavaScript（ES Modules）です。絵は絵文字と SVG、音は WebAudio でその場で合成しています。

```
index.html            入口
css/style.css         見た目
js/main.js            起動・画面の大きさ合わせ・タイトル・設定・ずかん・冒険の流れ
js/text.js            ひらがな／漢字の切りかえ（{漢字|かんじ} 記法）
js/audio.js           効果音と BGM（WebAudio で合成）
js/data/cards.js      カード（62種）と がったいの組み合わせ
js/data/enemies.js    モンスター・出現パターン・学年ごとの強さ
js/data/relics.js     たからもの（24種）
js/data/events.js     学年別クイズの生成と「ふしぎ」イベント
js/engine/chain.js    じゅもん（カードの列）の計算エンジン
js/engine/battle.js   たたかいのルール（画面と分離）
js/engine/run.js      マップ生成・報酬・お店
js/ui/*.js            各画面とエフェクト
tools/                開発用（バランス検証・自動プレイ・スクリーンショット）
```

### 開発用ツール

- `node tools/sim.mjs` … AI が全学年で何百回も冒険してクリア率・戦闘ターン数を出す（バランス調整用）
- `node tools/test_chain.mjs` / `node tools/test_quiz.mjs` … 計算エンジンとクイズ生成のチェック
- `node tools/e2e.mjs` … ブラウザ上でロボットが最初から最後まで遊ぶ通しテスト（Playwright が必要）
