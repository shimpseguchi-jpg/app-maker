# かたちづくり（小学1年 算数）

教科書の単元「かたちづくり」を参考にした、タブレット・PC 向けの練習ゲームです。
**`index.html` 1ファイルだけ**で動き、外部の画像・フォント・ライブラリを使わないので、Google サイトの「コードを埋め込む」にそのまま貼りつけられます。

## レベル（3だんかい）

**ゲーム（単元）をえらぶ → レベル（1ねんせい・2ねんせい・3ねんせい）をえらぶ → 問題をえらぶ** の順です。
レベルはゲームごとに分かれていて、2ねんせい・3ねんせいは 🔒 がかかっています。**そのゲームのひとつ前のレベルを全部クリアすると開きます**（たとえば「いろいた」の1ねんせいを全部クリアすると「いろいた」の2ねんせいが開く。ほかのゲームには影響しない）。
ホーム画面の各ゲームには、レベルごとの進み具合（「1ねん ✅」「2ねん 3/6」「3ねん 🔒」）が出ます。

| レベル | いろいた | うごかそう | てんつなぎ | ぼう | 合計 |
|---|---|---|---|---|---|
| 1ねんせい | 7問（ますめの線が見える） | 6問（1まい） | 6問（最後は自由にかく） | 6問（8→0・6・9・5・3、田→大きなしかく） | 25問 |
| 2ねんせい | 6問（形の中の線が見えない） | 6問（1〜2まい） | 6問 | 6問（8→2・4・7・1、田→ながしかく など） | 24問 |

## 4つのゲーム

| ゲーム | 内容 | 教科書との対応 |
|---|---|---|
| 1. いろいたで つくろう | さんかくの色板を右からドラッグして（またはマスをタッチして）灰色のシルエットを作る。置いた色板はドラッグで移動・タッチで回転・外に出すと取れる。ヒントあり | 色板ならべ（1・2） |
| 2. いろいたを うごかそう | 決められたまい数だけ色板を動かして（向きも変えられる）、お手本の形にかえる。形ができれば場所はどこでもよい | 「1まいだけ うごかして」（5） |
| 3. てんを つなごう | 点と点をタッチ（またはなぞる）で線をつなぎ、お手本と同じ形をかく。どこにかいても正解。かいた線をもう一度なぞると消える | 点つなぎ（4） |
| 4. ぼうを とろう | 決められた本数のぼうを取って、お手本の形にする（ますめの形は回転・裏返しでも正解） | ぼうならべ・ぼうを とって（3・6） |

### ★ ボーナス ステージ：りったいの かたちを つくろう

2年生「はこの かたち」の、ひごとねんど玉で箱の骨組みを作る活動を3Dにしたものです。最初から遊べます（7問）。

- 立体のます目の点をタッチ（またはなぞる）して、ぼうでつなぐ。点と点のあいだにぼうが入り、はしにねんど玉がつく
- 何もないところを指でひっぱると、形をぐるっと回していろいろな向きから見られる（「🔄 みかた」で元の向き）
- 右下の小さな立方体（まえ・うえ・みぎ…と書いてある）を上下左右にひっぱっても回せる。面をタッチするとその向きから見る（「うえ」なら真上から）。まわりの ▲▼◀▶ をタッチすると少しずつ回る
- ぼうをタッチすると取れる。同じぼうをもう一度なぞっても取れる。「ひとつ もどす」で元に戻せる
- お題：さいころ・ながい はこ・ひらたい はこ・おおきな さいころ・ピラミッド・おうち・じゆうに つくろう。お手本はくるくる回って表示される
- 作っている間「ぼう ○ほん・ねんどだま ○こ」を数えて表示（箱の形は ぼう12本・ねんど玉8こ）
- 向きや置き場所がちがっても、同じ形なら正解（短いぼうをつないで長い辺を作っても正解）

1ねんせいレベルの各ゲームの①を開くと、ふくろう せんせいが遊び方を教えてくれます（ぜんぶ ひらがな）。どの問題でも「❓ やりかた」で見直せます。

できた問題には ⭐ がつきます（ブラウザに保存。保存できない環境では開いている間だけ覚えています）。
🔊 ボタンで効果音のオン・オフができます。

## Google サイトに埋め込む方法

1. `index.html` をテキストエディタで開き、中身を **すべてコピー** する
2. Google サイトの編集画面で、右の「挿入」→「**埋め込む**」→「**コードを埋め込む**」を選ぶ
3. コピーした内容を貼りつけて「次へ」→「挿入」
4. 挿入された枠の角をドラッグして、**横いっぱい・高さ 700px くらい** に広げる（枠が小さいとスクロールが出ます）
5. 「公開」する

> GitHub Pages などで公開している場合は、「埋め込む」→「URL」で `…/katachi/` のアドレスを入れても使えます。
