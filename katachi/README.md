# かたちづくり（小学1年 算数）

教科書の単元「かたちづくり」を参考にした、タブレット・PC 向けの練習ゲームです。
**`index.html` 1ファイルだけ**で動き、外部の画像・フォント・ライブラリを使わないので、Google サイトの「コードを埋め込む」にそのまま貼りつけられます。

## 4つのゲーム

| ゲーム | 内容 | 教科書との対応 |
|---|---|---|
| 1. いろいたで つくろう | さんかくの色板の「むき」を選んでマスをタッチし、灰色のシルエット（しかく・さんかく・リボン・おうち・さかな・おやま・ヨット・ロケット）を作る。ヒントあり | 色板ならべ（1・2） |
| 2. 1まいだけ うごかそう | 並んだ色板を1まいだけ取って置き直し（向きも変えられる）、お手本の形にかえる | 「1まいだけ うごかして」（5） |
| 3. てんを つなごう | 点と点をタッチ（またはなぞる）で線をつなぎ、お手本と同じ形をかく。どこにかいても正解。最後は自由にかけるモード | 点つなぎ（4） |
| 4. ぼうを とろう | 「8」から決まった本数のぼうを取って 0・6・9・5・3・2・4 にする。「田」から ぼうを取って大きな しかく などにする（回転・裏返しでも正解） | ぼうならべ・ぼうを とって（3・6） |

できた問題には ⭐ がつきます（ブラウザに保存。保存できない環境では開いている間だけ覚えています）。
🔊 ボタンで効果音のオン・オフができます。

## Google サイトに埋め込む方法

1. `index.html` をテキストエディタで開き、中身を **すべてコピー** する
2. Google サイトの編集画面で、右の「挿入」→「**埋め込む**」→「**コードを埋め込む**」を選ぶ
3. コピーした内容を貼りつけて「次へ」→「挿入」
4. 挿入された枠の角をドラッグして、**横いっぱい・高さ 700px くらい** に広げる（枠が小さいとスクロールが出ます）
5. 「公開」する

> GitHub Pages などで公開している場合は、「埋め込む」→「URL」で `…/katachi/` のアドレスを入れても使えます。

## ローカルで試す

`index.html` をブラウザで直接開くだけで遊べます。
