# まなびサクセス（仮） 要件定義書

小学生向けの **育成シミュレーション型 学習ゲーム**。
パワプロの「サクセス」と、シャニマスの「WING」を手本にして、
算数・国語・英語の問題を解いて能力値を上げ、ミニゲームでスキルカードを集め、学期末の **テスト** に挑む。
テストは「問題を6問解く → その結果を持って、ライバル3人と同じステージを走る **2Dアクション**（マリオ風）」の2段構え。
合格すると次の学期（次の周）へ進み、後期のテストで1位になればクリア。落ちると育成終了だが、能力の一部とカードを次のプレイに引き継げる。

- 文書の位置づけ：この文書が **正本**。決まったことは「決定事項」、まだ決めていないことは「未決事項」にまとめる（9章）
- 表記：UI に出す文言は ひらがな基調で書く（既存作と同じ `{漢字|かんじ}` 記法で3モード切替）
- 数値：「仮」と付いたものは実装後に `tools/sim.mjs`（自動プレイ）で調整する前提の初期値

## 1. 概要

| 項目 | 内容 |
|---|---|
| 仮題 | まなびサクセス（仮）。正式名は未決（9.2） |
| ジャンル | **育成シミュレーション（ターン制）× 学習ドリル × 2Dアクション**。週ごとにコマンドを選んで能力を上げる（サクセス）、学期（シーズン）ごとにテストで競い落ちたら終了（WING）、テスト本番は **4人同時の横スクロールアクション**（マリオ＋マリオカートの妨害）。カードゲーム・RPG は既存作と重なるので、本作の「試合」はアクションにする |

| 学習範囲 | 算数・国語・英語の3教科。学習指導要領の学年配当に沿う（5.5）。英語は3教科対等に扱い、1・2年は音と絵中心の易しい内容にする |
| 1回のプレイ時間 | 1周（前期・後期の2学期、各4週＋テスト）で **約15分**（育成 8週 ≒ 8分、テスト 2回 ≒ 3.5分ずつ）。周回型。いつでも中断・再開できる（自動セーブ） |
| プラットフォーム | ブラウザ（iPad 横画面基準・PWA・オフライン可）。既存作と同じ構成（6章） |
| 手本 | パワプロ サクセス（週ごとのコマンド選択、能力値、体力・やる気、イベント、特殊能力）、シャニマス WING（シーズン制、3種の能力、ライバルとの順位、落ちたら終了）、スーパーマリオ（横スクロールの走る・跳ぶ・踏む・？ブロック）、マリオカート（アイテムで先行と妨害） |

### 1.1 ねらい（この順に優先）

1. **続けて遊べる**：問題を解くこと自体がゲームの進行（能力値アップ）になっていて、ドリルを「やらされている」感じがしない
2. **勝ち筋が学習と一致する**：テストで勝つには、能力値（＝これまで解いた量）、問題フェーズの正解（＝理解）、ステージの操作（＝ゲームの腕）の3つが要る。重みは **学習：操作＝半々**。問題を解かずに操作だけで勝つことも、操作をせずに問題だけで勝つこともできない
3. **短く、もう一回**：1周15分。落ちても能力の一部とカードが残り、「つぎは勝てる」と思える
4. **失敗がこわくない**：不正解は得点が減るだけ。必ず解説が出る。時間切れはない
5. **学年と弱点に合う**：学年選択＋適応難易度。間違えた問題は復習に回る

## 2. 手本から取り入れる要素

| 手本 | 要素 | 本作での形 |
|---|---|---|
| サクセス | 週ごとにコマンドを選ぶ | **週コマンド**：レッスン（算数・国語・英語）／ミニゲーム／きゅうけい／おでかけ／ふくしゅう（5.4） |
| サクセス | 練習で能力が上がる。成功・大成功・失敗 | レッスン＝問題5問。正解数で **大成功／せいこう／いまいち** が決まり、獲得量が変わる |
| サクセス | 体力とやる気。無理をすると怪我 | 体力とやる気を持つ。**怪我はなし**。体力が少ないと獲得量が半分・0なら強制きゅうけい（5.3） |
| サクセス | 特殊能力（金特・青特） | **スキルカード**のパッシブ（持っているだけで効く）（5.6） |
| サクセス | ランダムイベント・キャラクターイベント | おでかけ・きゅうけい時のイベント。選択肢つき。先生・ライバル（5.7） |
| サクセス | 能力値のランク表示（G〜S） | 教科ごとに 0〜999 ＋ ランク G〜S（5.3） |
| サクセス | 試合で成果を試す | ＝テスト（5.8） |
| サクセス | 完成した選手が残る | **せいせきひょう**と称号がアルバムに残る。次の周への引き継ぎポイントになる（5.9・5.10） |
| WING | シーズン制（予選→準決勝→決勝） | **前期 → 後期** の2回のテスト。後期は合格条件が上がる（5.9） |
| WING | Vo／Da／Vi の3能力 | 算数／国語／英語 の3能力 |
| WING | ライバルアイドルと順位を競う | **選ばなかった主人公候補3人**がライバル。同じステージを走ってゴール順で合否 |
| WING | 思い出アピール | スキルカードのアクティブ（ステージで1回使える切り札）（5.6） |
| マリオ | 横スクロール。走る・跳ぶ・敵を踏む・？ブロック | テストの **ステージフェーズ**。4人が同じステージを同時に走る。？ブロック＝**もんだいブロック**（問題フェーズで正解した分だけ中身が入る） |
| マリオカート | アイテムで先行・妨害。順位が常に見える | もんだいブロックから出るアイテム（ダッシュ・シールド・なげる）。画面上に4人の位置バー |
| WING | 審査に落ちると育成終了 | **同じ。落ちたら育成終了**。ただし成績表が残り、能力の一部とカード1枚を次に引き継ぐ（5.9） |
| WING | コミュで能力・メンタルが動く | イベント（5.7）。会話は短く、1イベント3〜5吹き出し |
| ローグライク | 3枚から1枚を選んで手札を組む | ミニゲームの成績で **3枚から1枚** 選ぶ。デッキ上限5枚（5.6） |

取り入れないもの：サポートカード・ガチャ・課金要素、怪我、問題の制限時間（時間切れ）、相棒マスコット（キャラは先生3人と主人公候補4人に絞る）、ステージでの脱落（HP が 0 でも復活する）。

## 3. ゲームの流れ

### 3.1 コアループ

```
タイトル
 → はじめから（学年・主人公を選ぶ・引き継ぎポイントを振り分ける・持ち込みカードを1枚選ぶ）／つづきから
 → 前期（4週）
     毎週：コマンドを1つ選ぶ
       レッスン（算数／国語／英語）… 問題5問 → 能力値アップ、体力ダウン
       ミニゲーム                 … 遊んで スキルカードを3枚から1枚もらう、やる気アップ
       きゅうけい                 … 体力回復（イベントが起きることも）
       おでかけ                   … イベント（選択肢。能力・やる気・カードが動く）
       ふくしゅう                 … 間違えた問題を解き直す（獲得量 高め・体力消費 小）
 → 前期テスト
     問題フェーズ：6問（算数2・国語2・英語2）を解く → 正解した分だけステージの もんだいブロックに中身が入る
     ステージフェーズ：ライバル3人と同じ横スクロールステージを走る（約2分）。ゴール順が順位
     合格 → 後期（4週）→ 後期テスト
     不合格 → 育成終了 → せいせきひょう → 引き継ぎ → タイトル
 → 後期テストで1位 → クリア：せいせきひょう・称号・アルバム → 引き継ぎ → タイトル
```

### 3.2 1周の構成（仮）

| 期間 | 週（ターン）数 | 終わりのテスト | 合格条件（仮） | 目安時間 |
|---|---|---|---|---|
| 前期 | 4 | 前期テスト（問題6問＋ステージ1・約2分） | 2位以内 | 7分 |
| 後期 | 4 | 後期テスト（問題6問＋ステージ2・約2.5分） | **1位** | 8分 |

- 「もう1周」はこの文書では **学期** と呼ぶ。1学期分が WING の「1シーズン」に当たる
- 週数・問題数・ステージの長さ・合格条件は `sim.mjs` で合格率とプレイ時間を見て調整する（9.1）

## 4. 用語

| 用語 | 意味 |
|---|---|
| 学年 | プレイヤーが選ぶ出題学年（1〜6）。ゲーム内の「学期」とは別 |
| 学期 | 1周の半分。4週＋テスト。前期・後期 |
| 週 | 1ターン。コマンドを1つ選ぶ |
| 能力値 | 算数・国語・英語 の3つ。0〜999 |
| 体力 | 0〜100。レッスンで減り、きゅうけいで戻る |
| やる気 | 5段階（😢😐🙂😄🤩）。獲得量の倍率に効く |
| スキルカード | ミニゲームで手に入るカード。テスト中に使う **アクティブ** と、持っているだけで効く **パッシブ** |
| デッキ | 今の周で持っているカード。上限5枚 |
| レッスン | 問題5問を解くこと。教科ごと |
| テスト | 学期末の本番。問題フェーズとステージフェーズ |
| 問題フェーズ | テストの前半。6問を解く。正解した教科・数が、ステージのもんだいブロックの中身になる |
| ステージフェーズ | テストの後半。4人同時の横スクロールアクション。ゴール順が順位 |
| もんだいブロック | ステージの？ブロック。教科ゾーンごとに2つ。問題フェーズでその教科を正解した数だけ、叩くとアイテムが出る |
| ゾーン | ステージを3つに分けた区間（算数・国語・英語）。ゾーンの終わりがチェックポイント |
| HP | ステージでのハート。敵・トラップ・ライバルのアイテムで減る。0 でチェックポイントから復活 |
| アイテム | もんだいブロックから出る。1つだけ持てて、アイテムボタンで使う（ダッシュ・シールド・なげる など） |
| 先生 | 出題と解説の担当。ステージでは実況・審判 |
| ライバル | テストで競うクラスメイト3人（選ばなかった主人公候補） |
| せいせきひょう | 周が終わると残る成績表（能力値・ランク・称号・正答率） |
| 引き継ぎポイント | 前の周の能力値から計算され、次の周の初期能力に振り分けるポイント |

## 5. 機能要件

優先度：**必須**（最初の版に入れる）／**推奨**（第2段階）／**任意**（余裕があれば）。ID は実装・テストから参照するための番号。

### 5.1 はじめかた・設定

| ID | 要件 | 優先度 |
|---|---|---|
| F-101 | 「はじめから」で **学年（1〜6）** を選ぶ。最初の版では 1〜3 のみ選べる | 必須 |
| F-102 | 学年の代わりに「うでだめし」（アルカナンバーの適応テスト 5問）で自動判定できる。算数以外の教科は学年に従う | 推奨 |
| F-103 | **主人公を4人の候補から選ぶ**（5.2）。選ばなかった3人がその周のライバルになる | 必須 |
| F-104 | 2周目以降は、はじめかたの中で **引き継ぎポイントの振り分け** と **持ち込みカード1枚の選択** を行う（5.9） | 必須 |
| F-105 | 文字表示 **ひらがな／漢字（ふりがな）／漢字** を初回起動時と設定から切り替える（既存 `js/text.js` を流用） | 必須 |
| F-106 | 設定：BGM・効果音の音量、読み上げの有無、問題文の文字サイズ、オートラン、かんたん操作、おうちのひとへ（5.10）、さいしょからやりなおす | 必須 |
| F-107 | 「つづきから」で中断した週・テストの途中から再開できる | 必須 |

### 5.2 キャラクター

| ID | 要件 | 優先度 |
|---|---|---|
| F-201 | **主人公候補4人**。得意教科で性格づける：算数が得意／国語が得意／英語が得意／バランス型。得意教科は初期能力 +30（仮）と、その教科の固有パッシブカード1枚（最初から持っている）で表す | 必須 |
| F-202 | 選ばなかった3人は **ライバル** としてテストに出る。能力値は学期で決まり（5.8）、得意教科はその分高い。ステージでの走り方にも個性を持つ（先行型・妨害型・安全型）。おでかけイベントにも登場する | 必須 |
| F-203 | **先生3人**（算数・国語・英語）。問題フェーズの出題者。ステージでは実況（「〇〇が せんとう！」）と審判。育成中は週の始めの一言（弱点教科を勧める）と、問題の **解説の読み手** を担う | 必須 |
| F-204 | 主人公候補・先生は名前・一言・見た目（絵文字＋SVG の顔）を持つ。外部画像は使わない | 必須 |
| F-205 | 主人公の名前は候補の名前のまま。自分の名前に変える（ひらがな6文字）こともできる | 任意 |

| ID | 要件 | 優先度 |
|---|---|---|
| F-301 | 能力値は **算数・国語・英語** の3つ。各 0〜999。初期値 50 ＋ 得意教科 +30 ＋ 引き継ぎポイントの振り分け（仮） | 必須 |
| F-302 | ランク表示：G（〜99）F（〜199）E（〜299）D（〜399）C（〜499）B（〜649）A（〜799）S（800〜）。仮。1周でまんべんなく育てると D〜C、集中すると B 前後に届く量にする | 必須 |
| F-303 | **体力** 0〜100。初期 100。レッスン −30、ミニゲーム −15、おでかけ −10、ふくしゅう −15、きゅうけい +60。学期が変わると全回復（仮）。4週のうちレッスンを4回続けると4回目は体力 10 で「つかれ」になるので、1回はきゅうけいかミニゲームを挟む判断が生まれる | 必須 |
| F-304 | 体力 20 未満のレッスンは獲得量 ×0.5 で「つかれているよ」と表示。体力 0 のときはきゅうけい・ふくしゅうだけ選べる | 必須 |
| F-305 | **やる気** 5段階。倍率 😢0.6／😐0.8／🙂1.0／😄1.2／🤩1.5（仮）。レッスン大成功 +1、いまいち −1、ミニゲーム +1、イベントで増減。学期が変わると 🙂 に戻る | 必須 |
| F-306 | 能力値の上昇は数字が **大きく飛ぶ演出**（+28！のように）で見せる。ランクが上がった瞬間は専用の演出 | 必須 |
| F-307 | 能力値はステージに2通りで効く：**3教科の平均 → 走る速さと最大HP**、**各教科の能力値 → そのゾーンのアイテムの強さ**（ダッシュの長さ・シールドの持続・なげる威力）。対応表は 5.8.4 | 必須 |

### 5.4 週コマンド

毎週、下のコマンドから1つ選ぶ。選ぶ前に「何がどれだけ動くか」の目安（体力の減り、上がる教科、もらえるもの）をボタンに表示する。

| ID | コマンド | 内容 | 優先度 |
|---|---|---|---|
| F-401 | **レッスン（算数／国語／英語）** | その教科の問題を **5問** 解く（5.5）。結果で獲得量が決まる：全問正解＝**大成功**（基本量 ×2、やる気 +1）／3〜4問＝**せいこう**（×1）／2問以下＝**いまいち**（×0.5、やる気 −1） | 必須 |
| F-402 | 基本量（仮）：前期 30、後期 40。これに やる気倍率・体力補正・大成功倍率・パッシブカードをかける。1レッスンの獲得は最大でも 120 程度 | 必須 |
| F-403 | **ミニゲーム** | 一覧から1つ選んで遊ぶ（5.6）。成績 🥉🥈🥇 に応じたレアリティの **スキルカード3枚から1枚** をもらう。やる気 +1。体力 −10。**能力値は上がらない** | 必須 |
| F-404 | **きゅうけい** | 体力 +60。30%（仮）でイベント（5.7） | 必須 |
| F-405 | **おでかけ** | 必ずイベント。選択肢で結果が変わる。能力 ±、やる気 ±、カードをもらう など | 必須 |
| F-406 | **ふくしゅう** | 「まちがえた問題」から 5問を解き直す。獲得量は基本量 ×1.5（仮）、体力 −10。間違えた問題が 5問未満のときは同じ単元の類題で埋める。0 のときは「にがて な たんげん」の問題を出す | 必須 |
| F-407 | 先生のアドバイス：週の始めに、いちばん低い教科の先生が一言。押し付けはしない | 推奨 |
| F-408 | 週の始めに体力・やる気・3能力値・デッキ（5枚）・次のテストまでの週数を常に表示する。能力値の横に「はやさ」「HP」などステージでの効き目も小さく出す | 必須 |

### 5.5 問題（出題エンジン）

#### 5.5.1 共通

| ID | 要件 | 優先度 |
|---|---|---|
| F-501 | 問題は **生成式**（乱数で数や語を選ぶ）と **データ式**（漢字・単語・短文の表）の2種類。両方を同じ形 `{ q, answer, choices?, explain, vis?, audio? }` で扱う（既存 `js/data/events.js` の QUIZ と同じ形） | 必須 |
| F-502 | 答え方（iPad 前提）：**3〜4択**、**テンキー入力**、**並べかえ**（カードをタップ／ドラッグで順に置く）、**マッチング**（ペアをタップ）。手書き入力は扱わない | 必須 |
| F-503 | 不正解のときは **必ず解説** を出す（1〜2行。その教科の先生が読む）。正解のときも短い確認（「3のだんだね！」）を出す | 必須 |
| F-504 | **わからない** ボタン：答えと解説を見せて不正解扱いにする。不正解の音は鳴らさない（アルカナンバー踏襲） | 必須 |
| F-505 | **制限時間はない**（レッスンも問題フェーズも）。問題フェーズは解く速さを評価しない（速さはステージフェーズの操作で競う） | 必須 |
| F-506 | **適応難易度**：教科ごとに難易度レベル（1〜8）を持ち、2問連続正解で +1、不正解で −1。学年ごとに動ける範囲を決める。問題フェーズでは学期に応じたレベルに固定する | 必須 |
| F-507 | **間違えた問題の記録**：教科・単元・問題の種（再生成できる情報）を保存し、ふくしゅうと問題フェーズ・テスト前の「にがて」表示、おうちのひとへに使う。正解し直すと記録から外す。記録は周をまたいで残る | 必須 |

### 5.8 テスト（問題フェーズ ＋ 2Dアクションのステージフェーズ）

学期末に行う。**問題フェーズ**で解いた結果がステージの「もんだいブロック」の中身になり、**ステージフェーズ**でライバル3人と同じ横スクロールステージを走ってゴール順を競う。育てた能力値（速さ・HP・アイテムの強さ）、問題の正解（アイテムの数）、操作の腕（走り・跳び・アイテムの使い方）の3つで勝敗が決まる。

#### 5.8.1 流れ

```
テスト開始（参加者：主人公＋ライバル3人）
 ↓ 問題フェーズ（約1分半）
   算数2問 → 国語2問 → 英語2問 の順に解く（制限時間なし。必ず解説）
   教科ごとの正解数（0〜2）が、その教科ゾーンの もんだいブロックの「中身あり」の数になる
   ライバル3人も裏で解く（正解率は学期で決まる）
 ↓ ステージフェーズ（約2分）
   3・2・1・GO！ で4人同時にスタート
   算数ゾーン → チェックポイント → 国語ゾーン → チェックポイント → 英語ゾーン → ゴール
   各ゾーンに もんだいブロック2つ。叩くと（中身ありなら）アイテムが出る。アイテムは1つ持てて、アイテムボタンで使う
   敵・トラップ・ライバルのアイテムで HP が減る。0 になるとチェックポイントから復活（3秒のロス）
 ↓
 ゴール順が順位。合格条件（5.9）と照らして合否
```

| ダッシュ | 一定時間 速さ ×1.6 | 2秒 → 3秒 |
| シールド | 一定時間 ダメージと妨害を防ぐ | 5秒 → 8秒 |
| ボール（なげる） | 前方に投げる。当たったライバルは HP −1、1秒よろける | 射程 6マス → 10マス |
| バネ | 大ジャンプ（近道に届く） | ジャンプ ×1.5 → ×1.8 |
| ハート | HP +1（上限まで） | 1 → 2 |

- 「正解が多いほどアイテムが多い」「能力が高いほど速くて丈夫でアイテムが強い」「操作がうまいほど落ちずに近道を通れる」が、同じくらいの重みで順位に効くように `sim.mjs` で調整する（9.1）

| 5 | **15分に収まらなかったときの削りどころ** | まず問題フェーズの解説表示を短く（正解時は省く）、次にレッスンを4問、最後にステージを短くする。週数（4）と問題数（6）はこれ以上減らさない |
| 6 | **ステージの見た目のテーマ** | 学校（校庭・廊下・体育館）か、教科にちなんだ世界（数の国・ことばの森・えいごの海）か |
| 7 | **ゾーンの並び** | 算数→国語→英語 の固定か、テストごとに入れ替えるか |
| 8 | **ライバルを踏めるか** | 踏めば1秒止まる。乱暴に見えるなら「追い抜くと相手が驚いて止まる」演出に替える |
| 9 | **むずかしいモードの解放条件** | 初クリア |

### 9.3 実装時に確認するもの

- 学年配当漢字（2020年施行の学習指導要領）の字数と各字の配当学年。算数・国語・英語の単元名と学年
