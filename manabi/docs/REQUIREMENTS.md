# まなびサクセス（仮） 要件定義書

小学生向けの **育成シミュレーション型 学習ゲーム**。
パワプロの「サクセス」と、シャニマスの「WING」を手本にして、
算数・国語・英語の問題を解いて能力値を上げ、ミニゲームでスキルカードを集め、学期末の **テスト**（WING のオーディション風）に挑む。
テストに合格すると次の学期（次の周）へ進み、後期のテストで1位になればクリア。落ちると育成終了だが、能力の一部とカードを次のプレイに引き継げる。

- 文書の位置づけ：この文書が **正本**。決まったことは「決定事項」、まだ決めていないことは「未決事項」にまとめる（9章）
- 表記：UI に出す文言は ひらがな基調で書く（既存作と同じ `{漢字|かんじ}` 記法で3モード切替）
- 数値：「仮」と付いたものは実装後に `tools/sim.mjs`（自動プレイ）で調整する前提の初期値

## 1. 概要

| 項目 | 内容 |
|---|---|
| 仮題 | まなびサクセス（仮）。正式名は未決（9.2） |
| ジャンル | **育成シミュレーション（ターン制）× 学習ドリル × ライトなデッキ構築**。週ごとにコマンドを選んで能力を上げる（サクセス）、学期末に審査員と★で競う（WING）、ミニゲームで集めたスキルカードを手札としてテストに持ち込む（本作の独自要素） |
| 対象 | 小学1〜6年生。**最初の版は1〜3年生**（既存作「かずまほ」「アルカナンバー」の算数出題を流用できる範囲）。4〜6年は第2段階で追加 |
| 学習範囲 | 算数・国語・英語の3教科。学習指導要領の学年配当に沿う（5.5）。英語は3教科対等に扱い、1・2年は音と絵中心の易しい内容にする |
| 1回のプレイ時間 | 1周（前期・後期の2学期、各5週＋テスト）で **約15分**。周回型。いつでも中断・再開できる（自動セーブ） |
| プラットフォーム | ブラウザ（iPad 横画面基準・PWA・オフライン可）。既存作と同じ構成（6章） |
| 手本 | パワプロ サクセス（週ごとのコマンド選択、能力値、体力・やる気、イベント、特殊能力）、シャニマス WING（シーズン制、3種の能力、審査員と★のオーディション、ライバルとの順位、落ちたら終了） |

### 1.1 ねらい（この順に優先）

1. **続けて遊べる**：問題を解くこと自体がゲームの進行（能力値アップ）になっていて、ドリルを「やらされている」感じがしない
2. **勝ち筋が学習と一致する**：テストで勝つには、能力値（＝これまで解いた量）と、その場で問題を正解すること（＝理解）の両方が要る。カードは「勝ち方の工夫」であって、問題を解かずに勝つ手段にはしない
3. **短く、もう一回**：1周15分。落ちても能力の一部とカードが残り、「つぎは勝てる」と思える
4. **失敗がこわくない**：不正解は得点が減るだけ。必ず解説が出る。時間切れはない
5. **学年と弱点に合う**：学年選択＋適応難易度。間違えた問題は復習に回る

## 2. 手本から取り入れる要素

| 手本 | 要素 | 本作での形 |
|---|---|---|
| サクセス | 週ごとにコマンドを選ぶ | **週コマンド**：レッスン（算数・国語・英語）／ミニゲーム／きゅうけい／おでかけ／ふくしゅう（5.4） |
| サクセス | 練習で能力が上がる。成功・大成功・失敗 | レッスン＝問題5問。正解数で **大成功／せいこう／いまいち** が決まり、獲得量が変わる |
| サクセス | 体力とやる気。無理をすると怪我 | 体力とやる気を持つ。**怪我はなし**。体力が少ないと獲得量が半分・0なら強制きゅうけい（5.3） |
| サクセス | 特殊能力（金特・青特） | **スキルカード**のパッシブ（持っているだけで効く）（5.6） |
| サクセス | ランダムイベント・キャラクターイベント | おでかけ・きゅうけい時のイベント。選択肢つき。先生・ライバル（5.7） |
| サクセス | 能力値のランク表示（G〜S） | 教科ごとに 0〜999 ＋ ランク G〜S（5.3） |
| サクセス | 試合で成果を試す | ＝テスト（5.8） |
| サクセス | 完成した選手が残る | **せいせきひょう**と称号がアルバムに残る。次の周への引き継ぎポイントになる（5.9・5.10） |
| WING | シーズン制（予選→準決勝→決勝） | **前期 → 後期** の2回のテスト。後期は合格条件が上がる（5.9） |
| WING | Vo／Da／Vi の3能力 | 算数／国語／英語 の3能力 |
| WING | 審査員3人。アピールで興味ゲージがたまり、満タンで★を1つ与える | **先生3人**（算数・国語・英語）。教科を選んで問題を解く＝アピール。ゲージ満タンでその先生の★を一番アピールした人に与える |
| WING | 審査員の興味（注目）が毎ターン変わる | 毎ターン1教科に「注目！」がついて得点1.5倍（仮） |
| WING | ライバルアイドルと★・得点で順位を競う | **選ばなかった主人公候補3人**がライバル。順位と★で合否 |
| WING | 思い出アピール | スキルカードのアクティブ（「2ばい」など。テスト中に使う）（5.6） |
| WING | 審査に落ちると育成終了 | **同じ。落ちたら育成終了**。ただし成績表が残り、能力の一部とカード1枚を次に引き継ぐ（5.9） |
| WING | コミュで能力・メンタルが動く | イベント（5.7）。会話は短く、1イベント3〜5吹き出し |
| ローグライク | 3枚から1枚を選んで手札を組む | ミニゲームの成績で **3枚から1枚** 選ぶ。デッキ上限5枚（5.6） |

取り入れないもの：サポートカード・ガチャ・課金要素、怪我、問題の制限時間（時間切れ）、相棒マスコット（キャラは先生3人と主人公候補4人に絞る）。

## 3. ゲームの流れ

### 3.1 コアループ

```
タイトル
 → はじめから（学年・主人公を選ぶ・引き継ぎポイントを振り分ける・持ち込みカードを1枚選ぶ）／つづきから
 → 前期（5週）
     毎週：コマンドを1つ選ぶ
       レッスン（算数／国語／英語）… 問題5問 → 能力値アップ、体力ダウン
       ミニゲーム                 … 遊んで スキルカードを3枚から1枚もらう、やる気アップ
       きゅうけい                 … 体力回復（イベントが起きることも）
       おでかけ                   … イベント（選択肢。能力・やる気・カードが動く）
       ふくしゅう                 … 間違えた問題を解き直す（獲得量 高め・体力消費 小）
 → 前期テスト（WING風・5ターン。手札のカードを使える）
     合格 → 後期（5週）→ 後期テスト
     不合格 → 育成終了 → せいせきひょう → 引き継ぎ → タイトル
 → 後期テストで1位 → クリア：せいせきひょう・称号・アルバム → 引き継ぎ → タイトル
```

### 3.2 1周の構成（仮）

| 期間 | 週（ターン）数 | 終わりのテスト | 合格条件（仮） | 目安時間 |
|---|---|---|---|---|
| 前期 | 5 | 前期テスト（5ターン） | ★1つ以上 または 2位以内 | 7分 |
| 後期 | 5 | 後期テスト（5ターン） | **1位** | 8分 |

- 「もう1周」はこの文書では **学期** と呼ぶ。1学期分が WING の「1シーズン」に当たる
- 週数・ターン数・合格条件は `sim.mjs` で合格率とプレイ時間を見て調整する（9.1）

## 4. 用語

| 用語 | 意味 |
|---|---|
| 学年 | プレイヤーが選ぶ出題学年（1〜6）。ゲーム内の「学期」とは別 |
| 学期 | 1周の半分。5週＋テスト。前期・後期 |
| 週 | 1ターン。コマンドを1つ選ぶ |
| 能力値 | 算数・国語・英語 の3つ。0〜999 |
| 体力 | 0〜100。レッスンで減り、きゅうけいで戻る |
| やる気 | 5段階（😢😐🙂😄🤩）。獲得量の倍率に効く |
| スキルカード | ミニゲームで手に入るカード。テスト中に使う **アクティブ** と、持っているだけで効く **パッシブ** |
| デッキ | 今の周で持っているカード。上限5枚 |
| レッスン | 問題5問を解くこと。教科ごと |
| テスト | 学期末の WING 風オーディション |
| 先生 | テストの審査員。教科ごとに1人 |
| ★ | 先生がテスト中に1つだけ与える評価。3つで満点 |
| ライバル | テストで競うクラスメイト3人（選ばなかった主人公候補） |

| 引き継ぎポイント | 前の周の能力値から計算され、次の周の初期能力に振り分けるポイント |

## 5. 機能要件

優先度：**必須**（最初の版に入れる）／**推奨**（第2段階）／**任意**（余裕があれば）。ID は実装・テストから参照するための番号。

### 5.1 はじめかた・設定

| ID | 要件 | 優先度 |
|---|---|---|
| F-101 | 「はじめから」で **学年（1〜6）** を選ぶ。最初の版では 1〜3 のみ選べる | 必須 |
| F-102 | 学年の代わりに「うでだめし」（アルカナンバーの適応テスト 5問）で自動判定できる。算数以外の教科は学年に従う | 推奨 |
| F-103 | **主人公を4人の候補から選ぶ**（5.2）。選ばなかった3人がその周のライバルになる | 必須 |
| F-104 | 2周目以降は、はじめかたの中で **引き継ぎポイントの振り分け** と **持ち込みカード1枚の選択** を行う（5.9） | 必須 |
| F-105 | 文字表示 **ひらがな／漢字（ふりがな）／漢字** を初回起動時と設定から切り替える（既存 `js/text.js` を流用） | 必須 |
| F-106 | 設定：BGM・効果音の音量、読み上げの有無、問題文の文字サイズ、早押しボーナスの表示、おうちのひとへ（5.10）、さいしょからやりなおす | 必須 |
| F-107 | 「つづきから」で中断した週・テストの途中から再開できる | 必須 |

### 5.2 キャラクター

| ID | 要件 | 優先度 |
|---|---|---|
| F-201 | **主人公候補4人**。得意教科で性格づける：算数が得意／国語が得意／英語が得意／バランス型。得意教科は初期能力 +30（仮）と、その教科の固有パッシブカード1枚（最初から持っている）で表す | 必須 |
| F-202 | 選ばなかった3人は **ライバル** としてテストに出る。能力値は学期で決まり（5.8）、得意教科はその分高い。おでかけイベントにも登場する | 必須 |
| F-203 | **先生3人**（算数・国語・英語）。テストの審査員。育成中は週の始めの一言（弱点教科を勧める）と、問題の **解説の読み手** を担う | 必須 |
| F-204 | 主人公候補・先生は名前・一言・見た目（絵文字＋SVG の顔）を持つ。外部画像は使わない | 必須 |
| F-205 | 主人公の名前は候補の名前のまま。自分の名前に変える（ひらがな6文字）こともできる | 任意 |

### 5.3 能力値とパラメータ

| ID | 要件 | 優先度 |
|---|---|---|
| F-301 | 能力値は **算数・国語・英語** の3つ。各 0〜999。初期値 50 ＋ 得意教科 +30 ＋ 引き継ぎポイントの振り分け（仮） | 必須 |
| F-302 | ランク表示：G（〜99）F（〜199）E（〜299）D（〜399）C（〜499）B（〜649）A（〜799）S（800〜）。仮。1周でまんべんなく育てると D〜C、集中すると B 前後に届く量にする | 必須 |
| F-303 | **体力** 0〜100。初期 100。レッスン −20、ミニゲーム −10、おでかけ −10、ふくしゅう −10、きゅうけい +50。学期が変わると全回復（仮） | 必須 |
| F-304 | 体力 20 未満のレッスンは獲得量 ×0.5 で「つかれているよ」と表示。体力 0 のときはきゅうけい・ふくしゅうだけ選べる | 必須 |
| F-305 | **やる気** 5段階。倍率 😢0.6／😐0.8／🙂1.0／😄1.2／🤩1.5（仮）。レッスン大成功 +1、いまいち −1、ミニゲーム +1、イベントで増減。学期が変わると 🙂 に戻る | 必須 |
| F-306 | 能力値の上昇は数字が **大きく飛ぶ演出**（+28！のように）で見せる。ランクが上がった瞬間は専用の演出 | 必須 |

### 5.4 週コマンド

毎週、下のコマンドから1つ選ぶ。選ぶ前に「何がどれだけ動くか」の目安（体力の減り、上がる教科、もらえるもの）をボタンに表示する。

| ID | コマンド | 内容 | 優先度 |
|---|---|---|---|
| F-401 | **レッスン（算数／国語／英語）** | その教科の問題を **5問** 解く（5.5）。結果で獲得量が決まる：全問正解＝**大成功**（基本量 ×2、やる気 +1）／3〜4問＝**せいこう**（×1）／2問以下＝**いまいち**（×0.5、やる気 −1） | 必須 |
| F-402 | 基本量（仮）：前期 25、後期 35。これに やる気倍率・体力補正・大成功倍率・パッシブカードをかける。1レッスンの獲得は最大でも 120 程度 | 必須 |
| F-403 | **ミニゲーム** | 一覧から1つ選んで遊ぶ（5.6）。成績 🥉🥈🥇 に応じたレアリティの **スキルカード3枚から1枚** をもらう。やる気 +1。体力 −10。**能力値は上がらない** | 必須 |
| F-404 | **きゅうけい** | 体力 +50。30%（仮）でイベント（5.7） | 必須 |
| F-405 | **おでかけ** | 必ずイベント。選択肢で結果が変わる。能力 ±、やる気 ±、カードをもらう など | 必須 |
| F-406 | **ふくしゅう** | 「まちがえた問題」から 5問を解き直す。獲得量は基本量 ×1.5（仮）、体力 −10。間違えた問題が 5問未満のときは同じ単元の類題で埋める。0 のときは「にがて な たんげん」の問題を出す | 必須 |
| F-407 | 先生のアドバイス：週の始めに、いちばん低い教科の先生が一言。押し付けはしない | 推奨 |
| F-408 | 週の始めに体力・やる気・3能力値・デッキ（5枚）・次のテストまでの週数を常に表示する | 必須 |

### 5.5 問題（出題エンジン）

#### 5.5.1 共通

| ID | 要件 | 優先度 |
|---|---|---|
| F-501 | 問題は **生成式**（乱数で数や語を選ぶ）と **データ式**（漢字・単語・短文の表）の2種類。両方を同じ形 `{ q, answer, choices?, explain, vis?, audio? }` で扱う（既存 `js/data/events.js` の QUIZ と同じ形） | 必須 |
| F-502 | 答え方（iPad 前提）：**3〜4択**、**テンキー入力**、**並べかえ**（カードをタップ／ドラッグで順に置く）、**マッチング**（ペアをタップ）。手書き入力は扱わない | 必須 |
| F-503 | 不正解のときは **必ず解説** を出す（1〜2行。その教科の先生が読む）。正解のときも短い確認（「3のだんだね！」）を出す | 必須 |
| F-504 | **わからない** ボタン：答えと解説を見せて不正解扱いにする。不正解の音は鳴らさない（アルカナンバー踏襲） | 必須 |
| F-505 | **制限時間はない**（レッスンもテストも）。テストでは **早く答えると得点ボーナス**（5.8）。時間は画面の端に小さく見せるだけで、焦らせる演出はしない | 必須 |
| F-506 | **適応難易度**：教科ごとに難易度レベル（1〜8）を持ち、2問連続正解で +1、不正解で −1。学年ごとに動ける範囲を決める。テスト中は学期に応じたレベルに固定する | 必須 |
| F-507 | **間違えた問題の記録**：教科・単元・問題の種（再生成できる情報）を保存し、ふくしゅうとテスト前の「にがて」表示、おうちのひとへに使う。正解し直すと記録から外す。記録は周をまたいで残る | 必須 |
| F-508 | **読み上げ**：問題文を Web Speech API（SpeechSynthesis ja-JP／en-US）で読む。1年生と英語のため。使えない端末では読み上げボタンを隠し、英語にはカタカナのよみを添える | 必須 |
| F-509 | 同じ問題（同じ数・同じ語）が同じレッスン内で2回出ない。直前のレッスンとの重複も避ける | 必須 |
| F-510 | 問題文は `{漢字|かんじ}` 記法で書き、3モードに対応する。ただし **国語の漢字問題は出題対象の漢字をそのまま出す**（モードで消えない） | 必須 |

#### 5.5.2 算数

既存「かずまほ」の `QUIZ`（arith・missing・tenComp・pattern・legs・shape・clock・money・unit など）と、アルカナンバーの「うでだめし」のレベル表を土台にする。

| 学年 | 単元（出題の種） | 形式 |
|---|---|---|
| 1年 | 20までのたし算・ひき算、10のまとまり、数のかぞえ、かたち、時計（なん時・なん時半）、長さくらべ | 択・テンキー |
| 2年 | 2けたのたし算・ひき算（筆算）、九九、時計（分）、長さ（cm・mm）、かさ（L・dL）、はこの形、ひょうとグラフ | 択・テンキー |
| 3年 | わり算（あまりあり）、3けたの計算、2けた×1けた、時間の計算、小数・分数の入門、円と球、重さ（g・kg） | 択・テンキー |
| 4年 | 大きな数、わり算の筆算、小数の計算、角度、面積、がい数、折れ線グラフ | 第2段階 |
| 5年 | 小数のかけ算・わり算、分数のたし算・ひき算（通分）、体積、割合・百分率、合同、偶数・奇数・倍数・約数 | 第2段階 |
| 6年 | 分数のかけ算・わり算、比、速さ、円の面積、拡大図・縮図、文字と式、資料の整理 | 第2段階 |

- 文章題（絵つき）を各学年 2割程度混ぜる（既存 `legs` のような絵文字の図を使う）

| 学年 | 単元（出題の種） | 形式 |
|---|---|---|
| 1年 | ひらがな・カタカナの読み（絵→ことば）、ちいさい「っ」「ゃゅょ」、のばす音、「は・を・へ」、学年配当漢字 80字の読み、反対のことば、ことばの仲間分け、文の順番（3文） | 択・並べかえ・マッチング |

- 漢字はデータ式。**1字ごとに「読み・用例の文・絵文字（あれば）」** を持たせる。学年配当（2020年施行の学習指導要領）を正本にして、字数は実装時に確認する（9.3）
- 書き取りは手書きなしのため、「正しい字を4つから選ぶ」で代える

#### 5.5.4 英語

3教科対等に扱う（テストでの重みも同じ）。ただし1・2年は学校で英語をほとんど習わないので、**音と絵で遊べる問題** に絞り、読み書きは求めない。

| 学年 | 単元（出題の種） | 形式 |
|---|---|---|
| 1〜2年 | アルファベット大文字（文字と音）、色・動物・数（1〜10）・果物・体の部分の単語（絵→英語を聞いて選ぶ、英語を聞いて絵を選ぶ）、あいさつ（Hello / Thank you / Good morning） | 択（音声つき）・マッチング |

| 4年 | 月、時刻、身のまわりの物、文房具、I have 〜 / Do you like 〜?、アルファベットの並び（辞書順） | 第2段階 |
| 5年 | 自己紹介（I can 〜 / My birthday is 〜）、教科、職業、Where is 〜?、過去形の導入 | 第2段階 |

### 5.8 テスト（WING 風）

学期末に行う。**育てた能力値**と**その場で解く正解**、そして**カードの使い方**で得点が決まる。

#### 5.8.1 流れ

```
テスト開始（参加者：主人公＋ライバル3人。先生3人が審査）
 ↓ 5ターン（仮）くりかえし
   1. 今ターンの「注目！」教科が表示される（その先生への得点 ×1.5）
   2. 主人公が教科を1つ選ぶ。アクティブカードを1枚まで同時に選べる
   3. その教科の問題を1問解く（時間切れなし。10秒以内の正解で早押しボーナス ×1.2）
   4. 得点（アピール）が決まり、その先生のゲージがたまる
   5. ライバル3人も行動する（自動）。ゲージがたまった先生は ★ を一番アピールした人に与える
 ↓
 5ターン終了：★ を出していない先生は、その時点の最多アピールの人に ★ を与える（★は必ず3つ配られる）
 ↓
 順位：★の数 → 同数なら合計得点。合格条件（5.9）と照らして合否
```

#### 5.8.2 ルール

| ID | 要件 | 優先度 |
|---|---|---|
| F-801 | 参加者 4人（主人公＋ライバル3人）、先生3人、5ターン。前期・後期ともに同じ形式で、ライバルの強さとゲージのしきい値が変わる。仮 | 必須 |
| F-802 | **得点（アピール）** ＝ 能力値 × 0.1 × 正解補正 × 注目倍率 × 早押し倍率 × カード倍率。正解補正：正解 1.0／不正解・わからない 0.3。注目 1.5。早押し（10秒以内の正解）1.2。仮 | 必須 |
| F-803 | **先生のゲージ**：その先生への全員の得点の合計でたまる。満タン（仮：前期 120、後期 200）で ★ をその先生への累計得点が最多の人に与え、その先生は以後 ★ を出さない（カード「★スティール」の例外あり） | 必須 |
| F-804 | **ライバルAI**：得意教科を優先しつつ「注目！」教科に 50% で乗る。能力値は学期で決まる（仮：前期 120〜180、後期 250〜350。得意教科は +30%）。正解率 前期 65%・後期 75%（乱数）。カードは使わない | 必須 |

| N-07 | ロジック（出題・獲得計算・テスト判定・ライバルAI・カード効果）は画面から分離し、**Node で動く**（`js/engine/`）。自動プレイでバランスを測る |
| N-08 | テスト道具：`tools/test_quiz.mjs`（全学年・全単元の問題を数千問生成して、答えが選択肢に含まれる・重複しない・解説がある ことを確認）、`tools/test_run.mjs`（週コマンド・獲得計算・カード効果・合否・引き継ぎ）、`tools/sim.mjs`（学年×戦略ごとに数百周遊んで、合格率・クリアまでの周数・プレイ時間を出す）、`tools/e2e.mjs`（Playwright でタイトルからクリアまで通す） |
| N-09 | 1周のプレイ時間 **12〜18分**（sim の問題あたり時間の仮定で測り、実機で確認） |
| N-10 | 個人情報を集めない。名前は端末内のみ。外部通信はフォント取得だけ |
| N-11 | 問題データの誤り（配当学年のずれ・誤答）を直しやすいよう、データ式の問題は1ファイル1教科にまとめ、`verify: true` の印で「要確認」を示せる（idoldungeon の流儀） |

## 9. 決定事項・未決事項

### 9.1 決定事項

| 項目 | 決定 |
|---|---|
| ジャンル | 育成シミュレーション × 学習ドリル × ライトなデッキ構築。能力はレッスン（問題を解く）で上げ、カードはミニゲームで集める |
| 対象 | 最初は1〜3年。4〜6年は第2段階 |
| 構成 | 1周＝前期・後期の2学期（各5週＋テスト）。約15分。後期1位でクリア |
| 失敗 | テスト不合格は **育成終了**（WING と同じ）。追試・やり直しなし |
| 引き継ぎ | 能力値合計の20%（上限あり）を **引き継ぎポイント** として次の周で自分で振り分ける。図鑑からカード1枚を持ち込む |
| 主人公 | 固定キャラ4人から **選択制**。選ばなかった3人がライバル。相棒マスコットはなし |
| 能力 | 算数・国語・英語（WING の Vo/Da/Vi 対応）＋体力＋やる気 |
| 英語 | 3教科対等。1・2年は音と絵中心に易しく |
| テスト | WING のオーディション形式。先生3人＝審査員、教科を選んで1問解く＝アピール、ゲージ満タンで★。**時間切れなし、早押しボーナスあり**。カードを1ターン1枚使える |
| 得点 | 能力値 × 正解補正。不正解でも 0.3 倍は入るが、正解しないと勝てない |
| ミニゲーム | 能力値は上がらない。成績に応じたカードを3枚から1枚選ぶ。学習系と純粋な遊び系を半々 |
| カード | アクティブ（テスト中・1ターン1枚・テストごとに戻る）とパッシブ（常時）。デッキ上限5枚 |
| 出題 | 生成式＋データ式。必ず解説（先生が読む）。わからないボタン。適応難易度。間違えた問題は周をまたいで記録し、ふくしゅうとテストに回す |
| 入力 | 択・テンキー・並べかえ・マッチング。手書きなし |
| 保護者画面 | 入れる（設定の奥。暗証番号なし） |
| 技術 | 既存作と同じ（素の JS・iPad 横・PWA・localStorage・3モード文字） |
| 外さないもの | 課金・ガチャ・サポートカード・外部送信・制限時間 |
