# ミッションタイマー（仮） 要件定義書

小学生向けの **スケジュールメイカー付きタイマー**。
「17時から18時」のように **はじまりとおわりの時刻** を決め、「読書・プリント・ゲーム」のように **やること・やりたいことのパネル** をドラッグで並べると、**内容に応じて時間を切ったタイムテーブル** を作ってくれる。
そのまま「ミッションかいし！」を押すと、脱出ゲームの公演のような **ブリーフィング（指令の読み上げ）** が流れ、**残り時間が見えるタイマー** が1つずつのやることを進めていく。やることが終わるごとに **カギ** が集まり、全部そろうと **脱出成功** の演出で終わる。

- 文書の位置づけ：この文書が **正本**。決まったことは「決定事項」、まだ決めていないことは「未決事項」にまとめる（9章）
- 手本：① [脱出ゲームタイマー](https://lab.shinadayu.com/riddle-timer/)（品田遊）② 市販の子ども向けタイマー・スケジュールアプリ。調査の記録と、どの要素をどう持ち込むかの判断は [RESEARCH.md](RESEARCH.md)
- 表記：UI に出す文言は ひらがな基調で書く（既存作と同じ `{漢字|かんじ}` 記法で3モード切替）
- 数値：「仮」と付いたものは実装後に `tools/test_schedule.mjs`（スケジューラの検査）と家庭での試用で調整する前提の初期値

## 1. 概要

| 項目 | 内容 |
|---|---|
| 仮題 | ミッションタイマー（仮）。正式名は未決（9.2） |
| ジャンル | **スケジュールメイカー × 見えるタイマー × 脱出ゲームの演出**。やること表を作る道具（やることカード系）と、残り時間を見せる道具（Time Timer 系）を1つにし、始まり・区切り・終わりに脱出ゲーム公演の演出をつける |
| 対象 | 小学1〜6年生。**最初の版は1〜3年生基準**（ひらがな、時計の読み、学年×10分の集中時間）。設定は子どもが自分でできる大きさにし、細かい決めごと（ゲームの上限など）は保護者モードで行う |
| 使う場面 | 放課後〜夕食前（例：17:00〜18:00）、朝の支度、休日の午前、寝る前。1回のミッションは **10分〜3時間** |
| 使い方の最短手順 | 時刻を決める（2タップ）→ パネルを3つドラッグ → 「おまかせで くぎる」→ 「ミッションかいし！」。**30秒以内** で始められること |
| プラットフォーム | ブラウザ（PWA・オフライン可）。**iPad 横画面と スマホ縦画面の両方** を基準にする（タイマーは机に立てた端末で見る）。既存作と同じ構成（6章） |
| 手本 | ①脱出ゲームタイマー（ミッション文の型・ブリーフィング・全画面の制限時間・節目アナウンス・成功の区切り）②Time Timer／時っ感タイマー（円盤で残り時間）、ねずみタイマー（比喩表示・ボタンで分数）、みえるタイマー（表示モード切替）、Gentle Timer（キャラが進む）、やることカード（絵カードを並べる・星タップ・収集）、じかんコイン（時間がごほうびになる）、Happy Kids Timer（自動で次へ・最小時間・表彰状）、Brili（全体の帯・動的再計算・保護者モード）、HoppityClock（おうちの人チェック・テンプレ） |

### 1.1 ねらい（この順に優先）

1. **始められる**：やる気の問題の大半は「取りかかれない」こと。ブリーフィングの演出で「始める瞬間」を一番楽しい瞬間にする
2. **自分で決めたと思える**：何をやるか・どの順番か・どれくらいか を子どもが並べる。アプリは「切る」「整える」「提案する」だけで、押しつけない
3. **見通しが立つ**：今やること・つぎ・全体の残りが、数字が読めなくても分かる（面積・比喩・帯）
4. **終わりが気持ちいい**：やることごとにカギがもらえ、全部そろうと扉が開く。時間切れでも「失敗」と言わない
5. **飽きない**：テーマ（世界設定）・マスコット・ブリーフィングの文言・きゅうけいのなぞなぞ が日替わりで変わり、スターで新しいテーマが解放される
6. **親の「早く！」が減る**：声かけの代わりをタイマーの合図と演出が担う。保護者が決めるのは上限とルールだけ

### 1.2 作らないもの

課金・広告・外部送信・ランキング・他の子との比較・「失敗」「ダメ」の表示・罰（スターが減るなど）・タイマーの圧迫演出（赤の点滅、低い警告音）・ティック音。

## 2. 手本から取り入れる要素

| 手本 | 要素 | 本作での形 |
|---|---|---|
| ①脱出ゲームタイマー | 「やるべきもの」を「やるべきこと」こと の型 | パネルは **もの＋どうする** の2語で表し、ブリーフィングで「プリントを 1まい おわらせること」「本を 15ふん よむこと」と読み上げる（F-303） |
| ①脱出ゲームタイマー | ホール型公演のオープニング（世界設定→役割→指令→制限時間→カウントダウン） | **ブリーフィング**：開始時 10〜20秒の全画面演出。テーマごとに文言が変わる。スキップ可（F-601） |
| ①脱出ゲームタイマー | 全画面で再生・音が鳴る | ミッション中は全画面のタイマー画面。音は最初のタップで解放（F-501） |
| ①脱出ゲームタイマー | 残り時間のアナウンス（公演の「残り10分」「残り5分」「残り1分」） | 全体と各パネルの **節目アナウンス**（F-507） |
| ①脱出ゲームタイマー | 脱出成功／失敗で体験が閉じる | **脱出成功** 演出。時間切れは「タイムアップ…でも だいじょうぶ」→ 延長ミッション。「失敗」は出さない（F-604・F-605） |
| ①脱出ゲームタイマー | 10〜120分の制限時間、スマホでも破綻しない | 10分〜3時間。スマホ縦画面を基準の1つにする（N-02） |
| ②Time Timer・時っ感タイマー | 円盤の面積で残り時間。カチカチ音なし | 基本の表示モード「えんばん」。ティック音を鳴らさない（F-503・N-06） |
| ②ねずみタイマー | 比喩（ねずみがリンゴをかじる）。分数はボタンで選ぶ | 表示モード「マスコット」（道を進む・ごちそうを食べる）。分数の変更は 5分刻みのボタン（F-503・F-405） |
| ②みえるタイマー | 円・バー・数字・絵から子どもに合わせて選ぶ | 表示モード：えんばん／バー／マスコット／すうじ。数字の非表示（F-503・F-504） |
| ②Gentle Timer | キャラが画面を横切り、着いたら時間切れ。テーマと音楽を選ぶ | マスコットが「扉までの道」を進む表示。テーマ（世界設定）ごとに見た目・音が変わる（F-606） |
| ②やることカード | 絵カードを並べるだけでやること表。読み上げ。自作カード。星タップ。魚を集める | **パネル** を「きょうの わく」にドラッグ。読み上げ。自作パネル。**星タップ**で達成。カギ・スタンプの収集（F-301〜305・F-508・F-701） |
| ②じかんコイン | がんばった時間がコインになる。交換ルールは家庭で決める | 完了したパネルの分数に応じて **スター**。ごほうびとの交換は保護者モードでルールを書く（F-701・F-801） |
| ②Happy Kids Timer | タスクが自動で次へ。最小時間。カウントダウン非表示。星→表彰状 | 時間で終わるパネルは自動で次へ。「できた！」で終わるパネルは最小時間まで待つ。数字非表示。週のまとめと「がんばりカード」（F-505・F-504・F-703） |
| ②Brili | ルーティンをプレイリストとして表示。今の位置を全体の中で見せる。遅れたら再計算。保護者モード | 画面下の **ミッションの帯**。早終わり・延長で後ろを再計算。保護者モード（F-502・F-510・F-8xx） |
| ②HoppityClock | 保護者承認。テンプレート | 「おうちの人チェック」（任意）。テンプレ：ほうかご／あさの したく／ねるまえ／きゅうじつ（F-509・F-106） |
| ②つぎなにタイマー | 「つぎに なにを するか」 | 「つぎは ◯◯」を常時表示（F-502） |
| 家庭学習の指針（学年×10分、15分単位） | 集中が続く時間の目安 | 連続する集中時間が 学年×10分（最低15分）を超えたら 5分のきゅうけいを自動で挟む（F-404） |

## 3. 流れ

### 3.1 コアループ

```
ホーム（きょうの ミッション／つくる／テンプレ／きろく／せってい）
 → スケジュールメイカー
     1. じかんを きめる   … はじまり（いまから／時刻）・おわり（+30/+45/+60/+90/+120 または 時刻）
     2. パネルを えらぶ   … 一覧から「きょうの わく」へドラッグ（タップでも入る）。数量（プリント 1まい）
     3. おまかせで くぎる … タイムテーブルができる（4.x のアルゴリズム）
     4. なおす           … ドラッグで順番、はしをひっぱって長さ、🔒で固定、「ゲームは さいごに」などの提案を1タップで採用
 → ミッションかいし！
 → ブリーフィング（10〜20秒。スキップ可）
 → ミッション中（パネル1つずつ。全画面タイマー）
     - 時間で終わるパネル（ゲーム・きゅうけい）… 1分前の合図 → 時間が来たら自動で つぎへ
     - できた！で終わるパネル（プリント・かたづけ）… 最小時間を過ぎたら「できた！」が押せる → 星タップ → つぎへ
     - 節目アナウンス（のこり 5ふん／1ぷん）、きゅうけいの なぞなぞ
     - 早く終わった → 余った時間を「つぎへ／さいごの ごほうびに たす／ちょっと きゅうけい」から選ぶ
     - 終わらない   → 「もうすこし（+5ふん）」最大2回。後ろのパネルが縮む。おわりの時刻は守る
 → 全部おわり → 脱出成功（カギが全部そろって扉が開く）→ けっか（スター・クリアタイム・スタンプ・解放）→ ホーム
```

### 3.2 1回のミッションの例

入力：17:00〜18:00、パネル＝読書・プリント（1まい）・ゲーム、2年生。

| 方式 | 読書 | プリント 1まい | ゲーム | 備考 |
|---|---|---|---|---|
| おまかせ（ひれい）… 標準 | 17:00〜17:20 | 17:20〜17:35 | 17:35〜18:00 | 基準 15・10・20 を 60分に比例配分し 5分刻みに丸める（4.3） |
| おまかせ（おなじ） | 17:00〜17:20 | 17:20〜17:40 | 17:40〜18:00 | 均等割り。ユーザー例と同じ |
| おまかせ（ひれい）で **3年生** のとき | 17:00〜17:20 | **17:20〜17:25 きゅうけい** → 17:25〜17:40 | 17:40〜18:00 | 読書20＋プリント15＝35分が 3年×10＝30分を超えるので、超える位置（プリントの前）に 5分のきゅうけいが入り、その5分は後ろのごほうび（ゲーム 25→20）から引かれる（4.3 の 5） |

## 4. 用語とスケジューラの仕様

### 4.1 用語

| 用語 | 意味 |
|---|---|
| ミッション | はじまりからおわりまでの1回分。複数のパネルからなる |
| パネル | やること1つ分の絵カード。もの＋どうする（「プリント／おわらせる」）、絵文字、種類、基準時間などを持つ |
| わく（きょうの わく） | スケジュールメイカーでパネルを並べる場所。並べた順がミッションの順になる |
| タイムテーブル | わくに時刻と長さがついたもの。ミッション中はこれに沿って進む |
| 種類 | パネルの性質。**しゅうちゅう**（学習）／**せいかつ**（支度・片づけ・食事・風呂）／**ごほうび**（ゲーム・動画・あそび）／**きゅうけい** |
| おわりかた | **じかんで おわる**（時間が来たら自動で次へ。ゲーム・きゅうけい・読書）／**できた！で おわる**（子どもが押すまで待つ。プリント・かたづけ・じゅんび） |
| 基準時間・最小・最大 | パネルの標準の長さと、おまかせが動かせる範囲。数量のあるパネル（プリント 1まい＝10分）は数量倍 |
| 固定（🔒） | おまかせが長さを変えないパネル |
| ブリーフィング | ミッション開始時の演出。テーマの文言でミッションを読み上げる |
| テーマ | 世界設定（たんてい・うちゅう など）。ブリーフィングの文言・マスコット・色・音が変わる |
| カギ | パネル1つを終えるともらえる。全部そろうと扉が開く（脱出成功） |
| スター | 終えたパネルの分数に応じてもらえるポイント。テーマの解放と、家庭のごほうびルールに使う |
| スタンプ | 1日1個。ミッションを1回でも完了した日につく |
| 保護者モード | 子どもの画面から分けた設定画面。長押しと簡単な計算で入る |

### 4.3 おまかせスケジューラ（アルゴリズム）

入力：はじまり `S`・おわり `E`（5分刻み）、わくに並んだパネルの列、学年、方式（ひれい／おなじ）。
出力：各パネルの開始・終了時刻（5分刻み）。純粋関数として `js/engine/schedule.js` に置き、Node で検査する（N-07）。

1. **合計時間** `T = E − S`（分）。`T < 10` または `T > 180` なら入力に戻す
2. **固定分を引く**：🔒のパネルと、おわりかたが「じかん」で保護者が長さを決めたパネル（例：ゲーム 20分 固定）は指定の長さ。残り `R = T − Σ固定`
3. **可変パネルの重み**：数量のあるものは `基準 × 数量`。`ひれい` は重み比で `R` を配分、`おなじ` は等分。各パネルを `[最小, 最大]` に **クリップ** し、クリップで出た差分を残りの可変パネルへ再配分（最大3回繰り返し）
4. **5分刻みに丸める**：最大剰余法で丸め、合計が `R` に一致するようにする
5. **きゅうけいを挟む**：並び順に見て、連続する「しゅうちゅう」の合計が `max(15, 学年×10)` 分を超える位置に **5分のきゅうけい** を挿入する。きゅうけいの5分は、後ろにある可変パネル（ごほうび → しゅうちゅう の順）から引く。引けない（すべて最小）ときは挿入せず「きゅうけいが はいらなかったよ」と表示する
6. **足りない・余る**：`Σ最小 > R` なら「じかんが たりないよ」と、どのパネルを外すか・おわりを延ばすかを提案。`Σ最大 < R` なら余りを「じゆうじかん」として末尾に置き、子どもに「なにに する？」と聞く
7. **提案**（採用は1タップ、しなくてもよい）：
   - ごほうびが しゅうちゅう より前にあるとき「ゲームは さいごに すると がんばれるよ」（やるべきことの後に やりたいこと。Premack の原理）
   - せいかつパネルに時刻の目安があるとき（おふろ 19:00 など保護者モードで設定）「おふろは 19:00 ごろ だね」と位置を提案
   - 同じ種類のしゅうちゅうが3つ以上並ぶとき「かんじ と けいさん を こうたいに すると あきないよ」
8. **ミッション中の再計算**（Brili の動的タイマー）：
   - 早く終わった：余り `d` 分を「つぎへ（後ろの可変パネルへ比例で足す）／さいごの ごほうびに たす（上限内）／ちょっと きゅうけい（d≤10 のとき）」から選ぶ。選ばなければ 10秒で「つぎへ」
   - 終わらない：「もうすこし（+5ふん）」を最大2回。5分は後ろの可変パネルから **ごほうび以外を先に** 縮める（ごほうびは子どもの楽しみなので最後に守る…ただし保護者モードで「ごほうびから 縮める」に切り替え可）。すべて最小になったら `E` を 5分延ばす提案を出し、保護者モードで禁止されていれば「きょうは ここまで」で終える
   - おわり `E` は **原則として動かさない**（「18時に ごはん」のような家庭の約束を守るため）

検査（`tools/test_schedule.mjs`）：合計が `T` に一致・全パネルが `[最小,最大]` 内・5分刻み・きゅうけい規則・固定の不変・方式ごとの例（3.2）を数千パターンの乱数入力で確認する。

### 5.5 ミッション中の画面（タイマー）

| F-502 | 画面構成（縦横どちらも）：上に **今のパネル**（絵文字・ミッション文・残り時間）、中央に **残り時間の表示**（F-503）、その下に「**つぎは ◯◯**」、下端に **ミッションの帯**（全パネルを長さの比で並べ、終わったものは✓、今の位置に印。全体の残り時間） | 必須 |
| F-503 | 残り時間の **表示モード**：えんばん（Time Timer 型。色の扇形が減る）／バー（横に減る）／マスコット（キャラが扉までの道を進む。テーマごと）／すうじ（大きな数字だけ）。いつでも切替可。初期は えんばん | 必須 |
| F-504 | **数字を見せない** 設定（ASD／ADHD 配慮）。見せる場合、残り時間の数字は **画面の短辺の 1/4 以上** の高さ（2m 離れて読める） | 必須 |
| F-505 | おわりかたの違い：**じかんで おわる** パネルは 1分前に合図 → 0 で自動で次へ。**できた！で おわる** パネルは **最小時間** を過ぎると「できた！」が押せる（早すぎる終わりを防ぐ）。基準時間を過ぎても押されないときは 0 で止まらず「のこり −3ふん」と表示して待つ（止めない） | 必須 |
| F-506 | 「できた！」→ **星タップ**（星が出て、子どもがタップすると光る）→ カギを1つ獲得 → 1.5秒で次のパネルのミッション文を読み上げて始まる。連打しても二重に進まない | 必須 |
| F-507 | **節目アナウンス**：各パネルの のこり 5ふん（長さ≥15分のとき）と 1ぷん、全体の のこり 10ぷん／5ふん／1ぷん。チャイム＋文字（＋読み上げ）。演出の強さ「しずか」では文字だけ | 必須 |

| F-509 | **おうちの人チェック**：保護者モードで指定したパネル（しゅくだい など）は「できた！」の後に「おうちの ひとに みせよう」と出し、保護者が✓を押す（押さなくても進める。✓があるとスター +1） | 任意 |

### 5.6 演出（飽きない仕組み）

| ID | 要件 | 優先度 |
|---|---|---|
| F-601 | **ブリーフィング**：開始時に全画面で 10〜20秒。構成は ①テーマの世界設定（1〜2文）②あなたの役割（「◯◯たんていだんの ◯◯くん」）③ミッションの読み上げ（パネルを順にミッション文で。1つ1.5秒）④せいげんじかん（「60ぷん」を大きく）⑤3・2・1 のカウントダウン ⑥開始の合図（扉が閉まる音など）。文字は1文字ずつ送る。右上「スキップ」。2回目以降は①②を短縮する設定 | 必須 |
| F-602 | ブリーフィングの文言は **テーマ** ごとに持ち、同じテーマでも **3パターン以上** を日替わりで出す。パネル名と数、合計時間、なまえを差し込む | 必須 |
| F-603 | **カギと扉**：パネル1つ完了 = カギ1本。画面の帯の端に扉があり、カギがそろうたびに鍵穴が光る。全部そろうと扉が開く | 必須 |
| F-604 | **脱出成功**：最後のパネルが終わると「だっしゅつ せいこう！」の演出（扉が開く・紙吹雪・ファンファーレ・クリアタイム表示・獲得スター）。10秒以内。そのあと **けっか画面**（パネルごとの✓、スター、スタンプ、解放されたもの、「おうちの ひとに みせる」ボタンで要約を大きく表示） | 必須 |
| F-605 | **時間切れ**：おわりの時刻を過ぎても「できた！」が残っているときは「タイムアップ…でも だいじょうぶ！ えんちょうミッション！」として 5分の延長を1回自動で与える。それでも終わらなければ「きょうは ここまで。カギは ◯本 あつまった！」で終える。**「しっぱい」「ダメ」の語は使わない**。終えたパネルのスターは必ず入る | 必須 |
| F-606 | **テーマ**（世界設定）：最初の版で **3つ**（たんてい／うちゅうステーション／まほうの とう）。各テーマは 色・マスコット・ブリーフィング文言・節目アナウンスの文言・効果音の音色・扉のデザイン を持つ。スターで新テーマを **解放**（第2段階で かいぞく／にんじゃ／おばけやしき（こわくない）を追加） | 必須（追加テーマは推奨） |

| F-608 | **きゅうけいの なぞなぞ**：低学年向けのなぞなぞ 100問をデータで持つ（`js/data/riddles.js`）。きゅうけいの最初に問題、終わりに答え。ヒントボタン。既存作の算数クイズ生成（かずまほ `events.js`）から「ちょっとした計算」を混ぜることもできる。正解入力は求めない（考えるだけ） | 推奨 |
| F-609 | **日替わりのひみつミッション**（任意参加）：ホームに1日1つ、「きょうは ブリーフィングを さいごまで みる」「きゅうけいで のびを する」のような **達成が簡単で急がせないもの** を出し、達成でスター +2。「はやく おわる」系は出さない | 任意 |
| F-610 | 演出の強さ：**しずか**（文字と小さなチャイムだけ。ブリーフィング短縮）／**ふつう**／**ドラマチック**（BGM・ナレーション文字送り・扉の音）。しゅうちゅうパネルの最中は どの強さでも **BGM を流さない**（勉強中の音は邪魔。Time Timer の静音思想） | 必須 |

| N-05 | **画面を消さない**：Screen Wake Lock API を使う。使えない端末（古い iOS）では案内を1回表示。音は最初のタップで `AudioContext` を解放（既存 `audio.js` の `unlockAudio`） |
| N-06 | **音**：ティック音なし。チャイム・ファンファーレ・扉の音は WebAudio で合成。音量 3段階と消音。しゅうちゅうパネルの最中は BGM を流さない。読み上げは SpeechSynthesis（使えなくても使える） |
| N-07 | **ロジックと画面の分離**：スケジューラ（配分・丸め・きゅうけい挿入・再計算）、ミッションの状態機械（開始・完了・延長・時間切れ・スター計算）、解放判定は `js/engine/` に置き **Node で動く**。描画と入力は `js/ui/` |
| N-08 | テスト道具：`tools/test_schedule.mjs`（4.3 の検査。乱数入力 数千件）、`tools/test_mission.mjs`（状態機械：早終わり・延長・時間切れ・スリープ復帰を時刻を進めて検査）、`tools/e2e.mjs`（Playwright でホーム→作成→ブリーフィング→ミッション→脱出成功を通す。時刻を偽装して 60分のミッションを数秒で回す）、`tools/shot.mjs`（iPad 横・iPhone 縦のスクリーンショット） |
| N-09 | **読みやすさ**：1年生でも読める分かち書き・短文。残り時間の数字は画面の短辺の 1/4 以上。色だけに頼らない（残り時間は面積＋数字＋マスコットの位置）。Zen Maru Gothic ＋ Fredoka（既存）。オフライン時はシステムフォント |
| N-10 | 個人情報を集めない。なまえは端末内のみ。外部通信はフォント取得だけ。広告なし |
| N-11 | 性能：ミッション中の描画は 1秒に1回の更新と、えんばん・マスコットの滑らかな動き（requestAnimationFrame）。古い iPad（第7世代）でも電池を無駄に使わないよう、画面が隠れている間は描画を止める |
| N-12 | ブリーフィング・アナウンスの文言はすべてデータ（`js/data/themes.js`）に置き、コードを触らずに増やせる。`{name}` `{count}` `{minutes}` `{missions}` の差し込み |

## 9. 決定事項・未決事項

### 9.1 決定事項

| 項目 | 決定 |
|---|---|
| 核になる機能 | **スケジュールメイカー**（時刻＋パネル → 5分刻みのタイムテーブル）。市販アプリは視覚タイマーかルーティン管理に寄っていて、この部分を中心に置いたものが見当たらない |
| 並び順 | **子どもが並べた順を尊重**。アプリは長さを切り、きゅうけいを挟み、提案を1タップで出すだけ。勝手に並べ替えない |
| 配分 | 基準時間の **比例配分** が標準、**均等** も選べる。最小・最大・固定・ごほうび上限を守る。5分刻み |
| きゅうけい | 連続する集中が **max(15, 学年×10)** 分を超えたら 5分を自動挿入（外せる） |
| おわりの時刻 | **原則固定**。延長は「もうすこし +5分」を最大2回、後ろのパネルを縮めて吸収。時間切れは 5分の延長ミッションを1回 |
| おわりかた | パネルごとに「じかんで おわる」「できた！で おわる」。できた！は最小時間を過ぎるまで押せない |
| ①から取るもの | ミッション文の型、ブリーフィング、全画面、節目アナウンス、成功の区切り。**「失敗」の宣告と圧迫演出は取らない** |
| ②から取るもの | 円盤表示、比喩表示、表示モード切替、数字非表示、絵カード方式、星タップ、収集、時間→スター、自動で次へ、最小時間、全体の帯、動的再計算、保護者モード、テンプレ、JSON 書き出し |
| 演出の方針 | 演出は **始まり・区切り・終わり** に集める。集中パネルの最中は BGM なし・静か |
| 失敗の扱い | 「しっぱい」「ダメ」を出さない。スターは減らない。時間切れでもカギの本数を称える |
| ごほうび | ゲーム・どうがの上限は保護者が決める。交換ルールはアプリが記録し、実行は保護者 |
| テーマ | 最初は3つ（たんてい／うちゅうステーション／まほうの とう）。スターで解放。ガチャにしない |
| 端末 | iPad 横と スマホ縦の両方を基準。絶対時刻で進め、スリープ復帰で再計算。Wake Lock |
| 技術 | 既存作と同じ（素の JS・PWA・localStorage・3モード文字・WebAudio・SVG）。スケジューラと状態機械は Node で検査 |
| 外さないもの | 課金・広告・外部送信・ランキング・比較・罰・ティック音 |
