## 1. ① 脱出ゲームタイマー（lab.shinadayu.com/riddle-timer/）

| 項目 | 内容 |
|---|---|
| 正式名 | 「脱出ゲームのときしか 頑張れない人のためのタイマー」（ページ見出し）。URL は riddle-timer |
| 作者・公開 | 品田遊（ダ・ヴィンチ・恐山）。2026-11-04 の日記で公開を報告 |
| 入力 | 「やるべきもの」を「やるべきこと」こと ＋ 制限時間（10〜120分）。入力欄はこの3つだけ |
| 出力 | 「全画面で再生する」「開始（音が鳴ります）」。終わると「最初から」「入力に戻る」 |
| 作者の意図（日記より） | ホール型脱出ゲームの公演では凝ったオープニング映像・ブリーフィングが流れ、作者はそれが大好きで「料金の15%くらいをここで楽しんでいる」。その「そこ」のモノマネをした。スマホでも破綻しないように作るのに気を使った |

### 1.1 ここから読み取れる設計

1. **やることを「ミッション文」に変換する**：自由な文章ではなく「◯を◯すること」の型に入れさせる。型があるので、どんな雑用でも「指令」の響きになる。子どもには「プリントを 1まい おわらせること」「本を 15ふん よむこと」のように、**もの＋動詞** の2語で入力させれば同じ効果が出る
2. **開始の儀式（ブリーフィング）**：やる気の問題は「始められない」ことなので、始める瞬間に最も強い演出を置く。ホール型公演のオープニングの定番構成は「世界設定の提示 → あなたたちの役割 → ミッションの読み上げ → 制限時間の宣言 → カウントダウン → 開始合図」。音と全画面で没入させる
3. **全画面の制限時間**：時間が見えること自体は普通のタイマーと同じ。「演出がついた普通のタイマー」であることが重要で、タイマー機能を複雑にしていない
4. **節目のアナウンス**：ホール型公演では「残り10分」「残り5分」「残り1分」のアナウンスが定番で、終盤の盛り上げになる。タイマーにも同じ節目を入れると「ずっと見ていなくてよい」が「終盤は分かる」になる
5. **終わりの区切り**：脱出成功／失敗の判定で体験が閉じる。ただし本作の対象は小学生なので、「失敗」をそのまま持ち込まない（要件 F-6xx）
6. **スマホで破綻しない**：タイマーは机に立てたスマホや iPad で見るものなので、縦画面・小画面での表示を最初から前提にする

### 1.2 本作に持ち込むもの・持ち込まないもの

- 持ち込む：ミッション文の型、ブリーフィング、全画面タイマー、節目アナウンス、成功の区切り、スマホ対応
- 持ち込まない：「失敗」の宣告、大人向けの緊張感（低い音・赤の点滅などの圧迫）。子ども向けには「盛り上げ」と「切り替えの合図」に使い、「追い立て」には使わない

### 2.2 市販アプリに共通する要素（本作でも必須にするもの）

1. **時間を面積・比喩で見せる**（数字が読めない・時間感覚が育っていない子のため）
2. **今・つぎ・全体** が同時に見える（見通し）
3. **達成の操作が子ども自身の手にある**（星をタップする、できた！を押す）
4. **貯まる・集まる**（星、魚、コイン、表彰状）。ただし交換ルールは家庭で決める
5. **保護者の設定を子どもの画面から分ける**（キッズモード／保護者モード）
6. **音は穏やかで、消せる**。ティック音なし
7. **広告なし・データ収集なし**（子ども向けアプリの前提）

### 2.3 市販アプリのレビューに出ていた不満（本作で先に潰すもの）

- 「同じキャラ・同じごほうび画面で飽きる」 → テーマ・マスコット・演出の種類を増やし、日替わりにする
- 「時間の選択肢が少ない（25・30・40・50分がない）」 → 5分刻み
- 「完了したら自動で次に進んでほしい」 → 自動で次へ（ただし「できた！」が必要なやることは押すまで待つ）
- 「アラームが欲しい」「時間になったら音で知らせて」 → 節目と終了の音は必須
- 「設定が子どもの画面に混ざる」 → 保護者モードを分ける
- 「端末をまたいでデータが残らない」 → JSON の書き出し・読み込み（道の駅チェックと同じ方式）

## 3. 時間の目安（スケジューラの初期値の根拠）

| 出典 | 内容 |
|---|---|
| 北海道教育委員会 保護者向けリーフレット（R7.8 改訂） | 平日の学習時間の目安：1年 20分以上、2年 30分以上、3年 40分以上、4年 50分以上、5年 60分以上、6年 70分以上。読書は「まず1日10分」。運動は1日60分。小5の生活時間の例では **17:00〜18:00 が家庭学習、18:00 夕食** |
| 大阪市（家庭学習のできる環境づくり） | 集中力が続く時間は「学年×10分」。1・2年 10〜30分、3・4年 30〜50分、5・6年 50〜70分。集中が続かない子は漢字→計算→観察のように内容を次々に変えると有効 |
| 札幌市立八軒小学校 | 「学年×10分の集中」。長時間より短時間集中。ながら勉強は効果なし |
| 進研ゼミ（2026.4） | 「学年×10分＋10分」が理想。深い集中は **15分単位** の波で変動するので、15分ごとに内容を切り替え、短い休憩を挟む |
| 学研教室 | 1〜2年 10〜20分、3〜4年 30分〜1時間、5〜6年 1〜1.5時間。集中が切れやすい子は **15分×4回** に分ける。タイマーで10分区切り→休憩を繰り返すと「ゲーム感覚で集中しやすい」 |
| 苫小牧市・多治見市根本小 | 「学年×10＋10分」。宿題を必ず、余力で自主学習 |

→ 本作の初期値：1つの集中パネルは **5分刻み**。連続する集中時間が **学年×10分（最低15分）** を超えるときは **5分のきゅうけい** を自動で挟む。読書の基準は 15分（最低10分）。ゲームなどのごほうびは保護者が1日の上限を決める（北海道教委「ゲームの時間の約束を家族で決める」）。

## 4. 本作の立ち位置（調査のまとめ）

- 市販アプリは「視覚タイマー」か「ルーティン管理」のどちらかに寄っていて、**「子どもが自分で やりたいことを並べると、時間を切ってくれる」** 機能（スケジュールメイカー）を中心に置いたものは見当たらなかった。ここが本作の核
- 脱出ゲームタイマーが示したのは「始める瞬間の演出」と「ミッション文」の力。市販アプリが示したのは「見える時間」「今・つぎ・全体」「達成の操作」「貯まる」「保護者モード」。本作はこの2系統を **1つのミッション体験** につなげる：
  **並べる（自己決定） → ブリーフィング（始めるきっかけ） → 見えるタイマー（続ける） → 星タップとカギ（達成） → 脱出成功（終わりの気持ちよさ） → スタンプ・テーマ解放（また明日）**
