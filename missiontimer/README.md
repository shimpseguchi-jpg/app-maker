# ミッションタイマー（仮）

小学生向けの **スケジュールメイカー付きタイマー**（WEB版の試作。1回のミッションを通して使える）。

- 「60ぷんかん」のように **ながさ** を決め、「読書・プリント・ゲーム」のパネルを並べると、内容に応じて時間を切ったタイムテーブルができる（時刻ではなく「◯ぷんかん」が基本。いつも「いまから」始まる）
- 「ミッションかいし！」で脱出ゲームの公演のようなブリーフィングが流れ、残り時間が見えるタイマーが1つずつ進めていく。やることが終わるごとにカギが集まり、全部そろうと脱出成功
- 手本：[脱出ゲームタイマー](https://lab.shinadayu.com/riddle-timer/)（品田遊）と、市販の子ども向けタイマー・スケジュールアプリ（Time Timer、ねずみタイマー、やることカード、じかんコイン、Happy Kids Timer、Brili ほか）

## うごかす

ブラウザだけで動きます（ビルド不要）。ルートの `js/text.js`・`js/audio.js`・`js/util.js` を使うので、**リポジトリのルート** を配信します。

```sh
npx http-server -p 8123 -c-1 .     # または python3 -m http.server 8123
# → http://localhost:8123/missiontimer/
```

iPad の横画面とスマホの縦画面の両方を基準にしています（どちらに回しても続きから動きます）。Safari の「ホーム画面に追加」で全画面・オフラインで使えます。セーブはブラウザ内（localStorage、接頭辞 `missiontimer.`）。

## できること（試作の範囲）

| 画面 | 内容 |
|---|---|
| はじめかた・ホーム | はじめては「なんねんせい？」の1タップだけ（なまえは聞かない。文字・テーマはあとから設定で）。ホームにテンプレ4つと「このまえと おなじ」「じぶんで つくる」を大きなボタンで並べる。テンプレを押すとタイムテーブルができた状態で開くので、「ミッションかいし！」まで2タップ。進行中のミッションは再読み込みしても続きから |
| スケジュールメイカー | 1画面。「なんぷんかん？」（15〜120ぷん のチップと −5／+5、初期は 60ぷん）と、ふんの目盛りの時計（60ぷんで1周）。時刻は出さない。パネルを **タップかドラッグ** で入れると、その場でおまかせで くぎってタイムテーブルになる（ひれい／おなじ、⠿で並べ替え、数量 1〜5、−5／+5、🔒、✕、きゅうけいを外す、提案の吹き出し、足りないときの直し方）。自作パネル |
| ブリーフィング | テーマの文言（3パターンを日替わり）を1文字ずつ → ミッション文の読み上げ → せいげんじかん → 3・2・1。スキップ可。2回目からは短く |
| ミッション中 | 今のパネル・残り時間（えんばん／バー／マスコット／すうじ）・大きな数字・つぎは・ミッションの帯・カギと扉。できた！（最小時間まで押せない）→ 星タップ → カギ。早く終わったとき／もうすこし（+5）／あとで／いちじていし／おわる。節目アナウンス、時間切れの延長ミッション。画面を消さない（Wake Lock） |
| だっしゅつ せいこう・けっか | 扉が開く・紙吹雪・ファンファーレ、スター・スタンプ・テーマの解放、おうちの ひとに みせる |
| きろく | スタンプのカレンダー、この1週間、がんばりカード、テーマの解放 |
| せってい・保護者モード | 表示・数字・音・読み上げ・演出の強さ。保護者モード（3秒長押し＋たし算）：ゲームの上限、もうすこしの回数、おわりの延長、縮める順、いちじていしの長押し、おふろの時刻、JSON 書き出し・読み込み、全部リセット、おうちのひとへ |

UI に出す漢字には、すべて `{漢字|かな}` でふりがなを付けています（ひらがなモードでは漢字を出しません）。
