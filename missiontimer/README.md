# ミッションタイマー（仮）

小学生向けの **スケジュールメイカー付きタイマー**（要件定義中）。

- 「17:00〜18:00」のように はじまりとおわりを決め、「読書・プリント・ゲーム」のパネルをドラッグで並べると、内容に応じて時間を切ったタイムテーブルができる
- 「ミッションかいし！」で脱出ゲームの公演のようなブリーフィングが流れ、残り時間が見えるタイマーが1つずつ進めていく。やることが終わるごとにカギが集まり、全部そろうと脱出成功
- 手本：[脱出ゲームタイマー](https://lab.shinadayu.com/riddle-timer/)（品田遊）と、市販の子ども向けタイマー・スケジュールアプリ（Time Timer、ねずみタイマー、やることカード、じかんコイン、Happy Kids Timer、Brili ほか）
