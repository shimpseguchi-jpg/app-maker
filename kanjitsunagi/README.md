# かんじ せんつなぎ

「え」→「ふでの もじ（筆書き風の漢字）」→「かんじ（教科書体風の漢字）」を線でつなぐゲームです。1年生で習う漢字 80 字すべてを入れています。
`index.html` の 1 ファイルだけで動きます（絵はファイル内の SVG）。
漢字は Google Fonts の **Klee One**（教科書体風）と **Yuji Syuku**（筆書き風）で表示し、使う 80 字ぶんだけを読み込みます。
フォントを読み込めない環境では、端末の明朝体などで表示されます。

## あそびかた

- カードをタップ → となりの段のカードをタップ、または指でなぞってつなぐ
- 線をタップすると消せる
- 「こたえあわせ」で ○（緑）/ ×（赤の点線）。全部正解で はなまる
- 「よみがな」：漢字のよみの表示／非表示（スマホ幅では自動で非表示）
- 「すぐに こたえあわせ」：つないだ瞬間に ○× が出る

## Google サイトに埋め込む

1. `index.html` を開き、中身をすべてコピー
2. Google サイトの編集画面で、右の「挿入」→「埋め込む」→「埋め込みコード」タブ
3. コピーしたものを貼りつけて「次へ」→「挿入」
4. 枠の大きさを調整（目安：横いっぱい・高さ 600px くらい。スマホ表示は狭いので 縦長でもOK）

## 問題をふやす

`index.html` の `ITEMS` に `{ id, kanji, yomi, pic }` を足すと、カードが増えます（`pic` は絵の SVG）。
80 字以外の漢字を足すときは、`<head>` の Google Fonts の URL の `text=` にもその字を足してください。セットにするときは `SETS` に漢字を 5〜6 こ並べます。
