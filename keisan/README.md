# けいさんオリパ

小学1年 算数「くりあがりの たしざん」「くりさがりの ひきざん」の計算練習ゲームです。
計算に正解してコインをため、1日1回のパック開封（オリパ風の演出）でカードを集めます。
iPad の横画面向け・`index.html` 1ファイルだけで動きます（外部の画像・フォント・ライブラリ・通信・課金なし）。

## Google サイトへの埋め込み

1. `index.html` の中身をまるごとコピーする
2. Google サイトの編集画面で「挿入」→「埋め込む」→「コードを埋め込む」に貼りつける
3. 埋め込みわくを、ページの横幅いっぱい・できるだけ縦長に広げる（画面は 1024×640 の比率で、わくに合わせて自動で拡大縮小されます）

## あそびかた

| モード | 内容 |
|---|---|
| たしざん | 1けた＋1けたの くりあがり（こたえ 11〜18） |
| ひきざん | 11〜18 − 1けたの くりさがり（こたえ 2〜9） |
| まぜまぜ | たしざんと ひきざんが まざって出る |
| ぶんしょうもんだい | ランダム生成の文章題。①だいじな ことばを タップ → ②たしざんか ひきざんかを えらぶ → ③けいさん |

- まちがえると「10の まとまり」を使う考え方（さくらんぼ計算・減加法）のヒントが出ます。
- 文章題は「あわせて／みんなで／もらうと／ぜんぶで／ふえると」（たしざん）、「のこりは／ちがいは／おおい」（ひきざん）の語に注目させます。2回まちがえると、その語が光って教えてくれます。
- 場面（りんご・ねこ・いろがみ…）と数は毎回ランダムです。助数詞（3びき・6ぴき・8ぽん など）も数に合わせて変わります。

## ごほうび（オリパ風）

- 正解で 10 コイン（文章題は合計 30 コイン）。連続正解 5 問で「フィーバー」2倍、10 問で 3倍。ときどき「ラッキーもんだい」3倍（フィーバーと重なったときは大きいほうの倍率）。
- **もんだいスロット**：計算問題は、数字と ＋− がスロットのリールで回り、左から順に止まって決まります。「7＋7」のようなゾロ目がそろうと「ゾロめ ボーナス」でコイン3倍。
- 正解した瞬間に、星・紙ふぶき・コインがはじけます。フィーバー中は画面のふちが虹色に光ります。
- **パックの開封は 1日1回**。ためたコイン 50 枚につきカード 1 枚、1パック最大 10 枚。あまったコインは翌日に持ちこせます。
- 1箱 100 口（UR 1・SSR 4・SR 15・R 30・N 50）で、残り口数が見えます。最後の1口を引くと「ラストワンしょう」。引ききると次の箱になります。
- 開封では、パックの光の色が 白→青→金→赤→虹 と「しょうかく」する演出・フラッシュ・紙ふぶきが出ます。
- カードは全 41 種類。「ずかん」で確認できます。

## 注意

- 記録はブラウザ内（localStorage）に保存します。Google サイトの埋め込みでは、ブラウザの設定（サイト越えトラッキング防止など）によって保存されず、開きなおすと最初からになることがあります。
- 「1日1回」は端末の日付で判定しています。
- 音は Web Audio で鳴らしています。ホームの「おと あり／なし」で切りかえられます。
