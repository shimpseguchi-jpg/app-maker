# 道の駅チェック（栃木・千葉・茨城・群馬）

4県の道の駅（103駅）をめぐった記録をつけるチェックリストです。ブラウザだけで動きます（ビルド不要）。

## できること

- **地図**：国土地理院の地図に全駅をプロット。高速道路（緑）と国道（赤茶）が描かれた地図で、
  広域表示では淡色地図、拡大すると標準地図（路線番号つき）に自動で切りかわります。右上で OpenStreetMap にも切りかえ可。
- **一覧**：県ごとに折りたたみできるリスト。駅名・市町村・路線で検索、未訪問／訪問済みでしぼりこみ。
- **連動**：一覧のチェックボックスと地図のプロットの色は常に同じ状態です。
  - 未訪問＝赤、訪問済み＝緑
  - 一覧でチェック → 地図の点が緑に。地図の点を押して出るポップアップでチェック → 一覧もチェック済みに。
  - 一覧の駅名を押すと地図がその駅へ移動します。地図の点を押すと一覧の該当行が光ります。
- チェックした日付を記録。進み具合は県ごと・全体で表示。
- 記録はブラウザ（localStorage）に自動保存。機種変更用に JSON で書き出し・読み込みができます。

## ファイル

```
index.html          入口
style.css           見た目（PC は地図＋右に一覧、スマホは上に地図＋下に一覧）
js/stations.js      駅データ（id は登録番号「栃木-01」など。保存キーなので変えない）
js/app.js           地図・一覧・連動・保存
```

## データについて

駅一覧と座標は Wikipedia「道の駅一覧 関東地方」と各駅の記事（CC BY-SA 4.0）から作成しました
（2025年6月に登録抹消された「南房パラダイス（千葉-20）」は含みません）。
新しい駅ができたら `js/stations.js` に1行追加してください。
