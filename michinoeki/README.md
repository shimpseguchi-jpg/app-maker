# 道の駅チェック（栃木・千葉・茨城・群馬・埼玉）

5県の道の駅（124駅）をめぐった記録をつけるチェックリストです。ブラウザだけで動きます（ビルド不要）。

## できること

### チェックリスト
- **地図**：国土地理院の地図に全駅をプロット。高速道路（緑）と国道（赤茶）が描かれた地図で、
  広域表示では淡色地図、拡大すると標準地図（路線番号つき）に自動で切りかわります。右上で OpenStreetMap にも切りかえ可。
- **一覧**：県ごとに折りたたみできるリスト。各駅に「予定」「行った」の2つのチェックボックス。
  駅名・市町村・路線で検索、未訪問／行く予定／行ったでしぼりこみ。
- **連動**：チェックの状態と地図のプロットの色は常に同じです。
  - 未訪問＝赤、行く予定＝青、行った＝緑
  - 「行った」をチェックすると「予定」は自動で外れます（どちらか一方）。
  - 一覧でも、地図の点を押して出るポップアップでも、どちらでチェックしても両方に反映されます。
- チェックした日付を記録。進み具合は県ごと・全体で表示。

### 道順モード
- 地図の道の駅を押した順に道順に入ります（もう一度押すと外れる）。ポップアップの「道順に追加」でも追加できます。
- 「行く予定」の駅をまとめて追加、↑↓で並べかえ、「回る順番を最適化」で短く回れる順に並べかえ。
- 2駅以上選ぶと、運転時間・距離・休憩こみの合計時間と、区間ごとの時間を表示し、地図に経路を描きます。
- 「現在地から出発」「各駅の休憩時間（なし〜1時間）」を選べます。
- 「Googleマップでナビを開く」で、同じ順番のルートを Google マップで開けます。
- 経路は [OSRM](https://project-osrm.org/) の公開サーバー（OpenStreetMap の道路データ）で計算した渋滞なしの目安です。
  つながらないときは直線距離からの概算（点線）を表示します。

### 保存
- 記録はブラウザ（localStorage）に自動保存。機種変更用に JSON で書き出し・読み込みができます（「行った」と「行く予定」の両方）。

### 2人で共有（合言葉方式）
同じ「同期URL」を入れて合言葉クイズ（**THE虎牙道** → 三択）に正解した端末どうしで、「行った」「行く予定」の記録が同じになります。
記録は自分の Google アカウントの Apps Script に保存されます。道順モードの駅の並びは端末ごとです。

- 開いたとき・アプリに戻ってきたとき・開いている間は30秒ごと・チェックしたときに自動で同期します。
- 駅ごとに「あとから変えたほう」が残るので、2人が同時に別の駅をチェックしても消えません。
- 共有を始める前に各端末にあった記録も、つないだときにまとめて合わさります。

#### 準備（パソコンで1回だけ・5分）
1. https://script.google.com を開いて「新しいプロジェクト」。名前を「道の駅チェック同期」などにする
2. 最初からある `コード.gs` の中身を全部消して、[`gas/Code.gs`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/ccr-a96fc02a-yijbz1/michinoeki/gas/Code.gs) の中身を貼り、保存
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類の選択（⚙️）で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（アプリから Google ログインなしで呼び出すため）
4. 「デプロイ」を押し、承認を求められたら自分のアカウントで許可（「詳細」→「（プロジェクト名）に移動」→「許可」）。
   このスクリプトは自分自身の保存領域（スクリプト プロパティ）だけを使い、ドライブやメールにはさわりません
5. 表示された **ウェブアプリのURL**（`…/exec` で終わる）をコピー
6. アプリの「2人で共有」を開き、URL を貼って、合言葉の答えを選んで「つなぐ」
7. 下に出る「相手に送るリンク」をコピーして LINE などで相手に送る → 相手はリンクを開いて合言葉に答えるだけ

#### 知っておくとよいこと
- 合言葉の正解はアプリには書いておらず、`Code.gs`（`ANSWER`）で判定しています。
  ただしこのリポジトリは公開なので、本当のカギは **ウェブアプリの URL** です。URL を2人以外に教えないでください。
- 合言葉を変えたいときは `Code.gs` の `ANSWER` と、`index.html` の選択肢を合わせて変えます（`Code.gs` を変えたら「デプロイを管理」→ 編集 → 新バージョン）。
- 共有の記録を全部消したいとき：エディタの ⚙️「プロジェクトの設定」→「スクリプト プロパティ」で `room:` で始まるものを削除。

## ファイル

```
index.html          入口
style.css           見た目（PC は地図＋右に一覧、スマホは上に地図＋下に一覧）
js/stations.js      駅データ（id は登録番号「栃木-01」など。保存キーなので変えない）
js/app.js           地図・一覧・連動・道順モード・保存・2人で共有
gas/Code.gs         2人で共有するときの保存係（Google Apps Script）
```
