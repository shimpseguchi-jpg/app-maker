# 道の駅チェック（栃木・千葉・茨城・群馬）

4県の道の駅（103駅）をめぐった記録をつけるチェックリストです。ブラウザだけで動きます（ビルド不要）。

## できること

### チェックリスト
- **地図**：国土地理院の地図に全駅をプロット。高速道路（緑）と国道（赤茶）が描かれた地図で、
  広域表示では淡色地図、拡大すると標準地図（路線番号つき）に自動で切りかわります。右上で OpenStreetMap にも切りかえ可。
- **一覧**：県ごとに折りたたみできるリスト。各駅に「予定」「行った」の2つのチェックボックス。
  駅名・市町村・路線で検索、未訪問／行く予定／行ったでしぼりこみ。
- **連動**：チェックの状態と地図のプロットの色は常に同じです。
  - 未訪問＝赤、行く予定＝青、行った＝緑
  - 「行った」をチェックすると「予定」は自動で外れます（どちらか一方）。
  - 一覧でも、地図の点を押して出るポップアップでも、どちらでチェックしても両方に反映されます。
- チェックした日付を記録。進み具合は県ごと・全体で表示。

### 道順モード
- 地図の道の駅を押した順に道順に入ります（もう一度押すと外れる）。ポップアップの「道順に追加」でも追加できます。
- 「行く予定」の駅をまとめて追加、↑↓で並べかえ、「回る順番を最適化」で短く回れる順に並べかえ。
- 2駅以上選ぶと、運転時間・距離・休憩こみの合計時間と、区間ごとの時間を表示し、地図に経路を描きます。
- 「現在地から出発」「各駅の休憩時間（なし〜1時間）」を選べます。
- 「Googleマップでナビを開く」で、同じ順番のルートを Google マップで開けます。
- 経路は [OSRM](https://project-osrm.org/) の公開サーバー（OpenStreetMap の道路データ）で計算した渋滞なしの目安です。
  つながらないときは直線距離からの概算（点線）を表示します。

### 保存
- 記録はブラウザ（localStorage）に自動保存。機種変更用に JSON で書き出し・読み込みができます（「行った」と「行く予定」の両方）。

## ファイル

```
index.html          入口
style.css           見た目（PC は地図＋右に一覧、スマホは上に地図＋下に一覧）
js/stations.js      駅データ（id は登録番号「栃木-01」など。保存キーなので変えない）
js/app.js           地図・一覧・連動・道順モード・保存
```

## データについて

駅一覧と座標は Wikipedia「道の駅一覧 関東地方」と各駅の記事（CC BY-SA 4.0）から作成しました
（2025年6月に登録抹消された「南房パラダイス（千葉-20）」は含みません）。
新しい駅ができたら `js/stations.js` に1行追加してください。
